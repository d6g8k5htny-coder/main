# Sandbox (drafts, no authority)

Git equivalent of `06_SANDBOX_FRONTIER — DRAFTS_NO_AUTHORITY`. Work here under a
task/session subdirectory freely; nothing in `sandbox/` carries canonical
authority and CI does not verify it beyond syntax. To publish, freeze a
candidate outside the sandbox, compute exact identities, write one delivery
manifest, and open a draft pull request (the claim). See
`governance/GIT_ADAPTATION.md`.
