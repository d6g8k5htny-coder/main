# Sandbox (drafts, no authority)

Git equivalent of `06_SANDBOX_FRONTIER — DRAFTS_NO_AUTHORITY`. Work here under a
task/session subdirectory freely; nothing in `sandbox/` carries canonical
authority and CI does not verify it beyond syntax. To publish, freeze a
candidate outside the sandbox, compute exact identities, write one delivery
manifest, and open a draft pull request (the claim). See
`governance/GIT_ADAPTATION.md`.

Two rules carried from the Drive's `README — Sandbox Rules` (a native Doc, held
as a reading copy under `drive/mirrors/06_SANDBOX_FRONTIER — DRAFTS_NO_AUTHORITY/`):
"Never link to a sandbox file from a live/permanent record, so a wipe can never
break anything. The entire sandbox may be wiped at any time without review."
Nothing under `docs/`, `claims/`, `registers/`, `engine/` or `research/` may
reference a path under `sandbox/`. That Drive document is dated 2026-07-25 and
names OP-PROT-012 / OP-PROT-011 as its routing basis, both HISTORICAL under R17
(2026-09-17); the current sentence is the R17 Research Home's ("Draft in
06_SANDBOX_FRONTIER. Publish immutable candidates with exact identities and one
delivery manifest"). Until 2026-09-19 this file carried neither the never-link
rule nor the date.
