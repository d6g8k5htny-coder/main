# Six suggested mechanisms: disposition after source inspection

Owner authorization supplies permission to act, not a mathematical result. This
experiment advances a concrete H3 estimate instead of installing all six ideas
as workspace-wide rules. The suggestions are useful engineering patterns, not
established novel mathematical primitives.

| Suggestion | Decision and actual scope |
|---|---|
| Bitemporal/Merkle claims | Defer global migration. Valid time means the applicability interval of an assertion, review or operational status; it is not when a timeless theorem became true. Recursive hashes are implemented only for this experiment's declared formula DAG. They prove integrity under a trusted root, not logical soundness. Cyclic logical dependencies need an explicit treatment before any forest conversion. |
| Prover/falsifier lanes | Implement bounded parameter proposal -> rigorous scalar certification and adversarial negative controls. Actual result improves the source's band lower coefficient. No failure-count-to-proof or 10k-sample budget rule. The full-law Z counterexample evaluator remains unimplemented. |
| Execution cache | Implement local content-addressed scalar reuse with source/code/context/runtime keys, immutable outputs, hash checks and optional mandatory cold replay. It is not a hermetic distributed build and never becomes source of scientific authority. Shared cache authentication and Nix/Guix pinning are deferred. |
| Dual arithmetic | Optional mpmath cross-checks are diagnostic, not certified. Arb was inspected in primary documentation but not executed in this runtime. Agreement/overlap does not validate shared formulas, conditioning, tails or scope. A disagreement identifies a consistency problem, not automatically which backend is wrong. |
| Formula-cell lineage | Trace the actual mathematical formula dependencies here, with no invented Sheets ancestry. Full formula-cell lineage needs a source census, parser, named-range/INDIRECT/volatile/external/cycle handling and changed-cell impact tests. The supplied counts were not verified and are not adopted. |
| Proof market/energy | Record actual wall time, process CPU time and achieved bound improvement. Energy is unmeasured. No hypothetical 12h/200h cost estimates, spend, token market or automatic resource grants. Prioritization must consider all unresolved AND premises and alternative OR routes, not naive descendant count. |

## Highest-value next scientific actions

A nonauthor reviewer can check the general epsilon,d adaptation and the alternate
rational kernel using the exact source and new certificate. A genuinely second
rigorous backend can then reproduce the scalar inequalities; an independent
expectation oracle would be required for the proposed full-Z falsifier. Broader
all-angle or RN work must retain its own hypotheses and gates. No automatic
replacement of the existing stronger fixed-radius consumer is justified.
