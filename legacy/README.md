# Legacy material — ZERO EVIDENTIARY AUTHORITY / INSPIRATION ONLY

This directory is the repository's zero-authority zone. It **holds** the
physics-framework content this repository originally hosted
(`complexity-physics-framework/`: the "Reconstruction of Physics from Multiscale
Retrodiction Complexity" README and its DOCX manuscript generator). It **indexes,
and does not mirror**, the two Drive lanes of the same class — nothing from
either is stored here; both are in `drive/inventory.jsonl` and their notices are
under `drive/mirrors/`:

* `03_PERSONAL_AND_EARLIER_RESEARCH — ZERO EVIDENTIARY AUTHORITY` (23 items):
  14 of the 17 pre-current-method files (RUFT, RUFL, Magneto Harmonics, RFT/CIID,
  the ECM/RH/HLV ancestor, the Λ-Dialectic framework, FIM). Its zone notice
  (mirrored byte-exact, `4a11a66b…`) states three rules: "1. **Do not quote** a
  number, parameter, coefficient, or derivation from this zone as fact. 2. **Do
  not treat confident language here as evidence.** … 3. **Do not carry a result
  from here into active q0 work** — in any form, at any confidence level."
* `02_LEGACY_Q0_ARCHIVE — INSPIRATION ONLY / REVERIFY FROM FIRST PRINCIPLES`
  (346 items): superseded *q0* work under the **current** method. The zone
  notice is explicit that this is a different stratum: "`02_LEGACY_Q0_ARCHIVE`
  says LEGACY but is **not** this stratum … Zero of the 17 live there. Different
  ontology, different rules." The Fresh Start 2.0 charter (§3) says the same and
  adds "Rule 3. Never quarantine a file for containing the token 'legacy.'
  Classify by stratum, not by string."

Until 2026-09-19 this file said it "mirrors" both lanes and folded them into one
rule set.

LEGACY MATERIAL MAY NOT SUPPLY THE ANSWER." is §1 of
`FS2_ACTIVE_RESEARCH_AND_LEGACY_QUARANTINE_CHARTER_v2.0.md` (Drive
`1KdOEc5L3vkwmvG5swNqnsYvigStc5qB9`, 6,880 B, SHA-256 `c5ab7980…`, mirrored
byte-exact under `drive/mirrors/05_FOUNDATIONS_AND_PROTOCOL_HISTORY — FRESH
START 2.0/`; "Every rule below is a consequence of that sentence"). The
03_PERSONAL zone notice repeats it, and the vault manifest
`00_DO_NOT_OPEN_MANIFEST` (Drive `1tYi29H_hsTPwi2Tj75OlYiz8sGv2JJwGT_k7FyMgNd4`,
outside the vault; a reading copy is held under `drive/mirrors/01_ACTIVE_RESEARCH_PACKAGES

addition "Vault material is stronger than legacy: do not ask it questions
either, except forensic recovery." Until 2026-09-18 this file attributed the
sentence to the charter without a source; on 2026-09-18 it was re-attributed to
the vault manifest alone, on the strength of the platform lane's

INSPIRATION ONLY / REVERIFY FROM FIRST PRINCIPLES):
