Purpose: G0 tests the auditor itself; G1 checks a root-authorized exact tracked-file manifest. This is a focused Python-stdlib command, not a Lean parser, kernel, SAT solver, Python interpreter or general framework. A successful result is `STATIC_PASS`, never CBZ-0 or proof closure.

The final federation controller supplies schema v1: exact roots, immutable tree identifiers, complete tracked-file lists, and one hash-bound classification per tracked file. Source-looking extensions cannot be relabeled documentation/data. Every source, including quarantined and negative source, is scanned. Retained negative/quarantined source must name its exact expected finding multiset; extra or absent findings fail. Quarantine additionally records an exact nonempty boundary, blocking reason, id and source hash. These records are dispositions, not clean source. Binary proofs require content-bound G2 and G4 evidence references. External files require immutable revision pin metadata; no implicit dependency trust exception exists.

A6: every lexical theorem/lemma/example has an entry keyed `name@line` (`example@line` for anonymous examples). An observation file is evidence structure/content binding, not authentication that the command actually ran. G8/controller execution receipts supply that provenance. Markdown truth and no-weakened-bound historical intent are outside lexical decidability; they require G8 and source-history review respectively.
