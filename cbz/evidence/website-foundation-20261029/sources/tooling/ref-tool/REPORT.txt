does not inspect GitHub protection/ruleset/PR APIs. Hosting protections remain
fully enforced. Use root's serial writer after repairs/PR disposition stabilize.

Default snapshot/publish/prune invocation emits JSON and performs no persistent
source or remote mutation. --execute is explicit. Snapshot writes only NEW OUT
using a temporary sibling then rename. Failed creation removes partial output.
Archive source index uses a separate GIT_INDEX_FILE. No source checkout/index is
opened. Snapshot rejects a default source tree already using reserved .cbz path.

OUT/manifest.json is exact canonical original advertised heads/tags object IDs,
peeled annotated-tag IDs, symbolic default branch, remote endpoint and frozen
protection/activity policy. The exact same bytes are embedded in archive commit
at .cbz/refs-manifest.json. OUT/receipt.json binds manifest SHA-256, archive commit
and archive tree. OUT/repository.git is a standalone full bare object archive.
The archive commit uses the original default source tree plus that manifest;
its parents are exactly all unique original branch tips. Completed archive has
NO original branch refs; detached HEAD and one pre-cbz archive tag retain all
original branch work. Original tag refs remain locally to preserve exact tag
objects and tag-only work. Tool never deletes original remote tags.

Verification checks canonical bytes/hash, commit and tree identities, exact
manifest membership, exact unique parent membership, all original objects,
peeled-tag identities, all original branch-tip reachability and full Git fsck.
A fresh independent bare fetch of the actual remote archive tag, its commit
bytes and object closure occurs after publication and before any branch delete;
it occurs again after delete. Local receipts/ls-remote alone do not authorize
deletion. Publish adds the archive tag with expected-absent lease. Prune uses
one --atomic push and explicit expected-old SHA leases for EVERY deleted head.
It performs fresh complete in-scope state checks before and immediately before
push, and exact final-state readback. Server rejection cannot partially apply
an atomic delete transaction. A failed command never returns successful cleanup.

Limits and nonclaims:
* Scope is advertised refs/heads/* and refs/tags/*, symbolic HEAD and peeled tags.
  Hidden refs, refs/pull/*, GitHub PR objects, stashes, working-copy-only changes,
  artifacts outside Git and tag disposition/quarantine indexing are root's other
  phases. No claim that this alone preserves those inputs or completes G10.
* CLI requires stdlib Python 3 plus Git supporting atomic push, exact leases and
  --no-write-fetch-head. Actual server atomic support is mandatory; no fallback.
* No server-wide lock: an unrelated concurrent change can occur after preflight;
  exact final comparison rejects it, and standalone local archive remains intact.
  A rejected final check may follow an already-applied atomic deletion; inspect
  fresh remote state and recover from the archive instead of claiming success.
* Existing local snapshots are immutable to the workflow: changed refs/default
  require a new snapshot/tag. Prune is deliberately not silently idempotent;
  a second execution after a completed prune rejects the changed original state.
* The archive manifest is not signed and cannot establish authenticity against
  coordinated malicious rewriting of archive objects, tag, manifest and receipt.
* No tool assertion certifies mathematics, axioms, kernel acceptance, Layer A,
  complete federation hygiene, PR closure or CBZ-0. Scope is tested Git safety.
