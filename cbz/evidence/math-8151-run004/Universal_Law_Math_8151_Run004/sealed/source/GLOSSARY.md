# Source-grounded glossary — formal scope, not renaming

| Workspace term | Pilot formal object | Boundary / next definition |
|---|---|---|
| Canonical fold gap | `foldPotential (s x : Real) = -(x^3)/3 + s^2*x`; difference at x=s and x=-s | Identifying this polynomial with a random-field local chart remains external |
| Contact-power factor | `(r^3/6)*(1/r^5)*r^2` in Real, r != 0 | Not a six-pin Jacobian theorem |
| Normalizer lower bound | Real inequality `cZ*r^2 <= z` with r,cZ positive | Define z as the actual normalizing integral in a later measure-theory module |
| Square-root transfer | Real inequality `n/z <= (sqrt cW/cZ)*sqrt q` under supplied hypotheses | Define measure, integrability, event and conditioning before asserting Palm meaning |
| Cubic-rate ledger | `p <= C*r^4` implies `p <= C*r^3` on [0,1], C >= 0 | Uniformity of C and interpretation of p not formalized |
| Elder selection / elder density | UNMAPPED in this pilot | Requires explicit marked critical-point process, pairing convention, Palm/disintegration objects, normalization and measurability; not automatically an ordinary conditional density |
| Candidate density | UNMAPPED in this pilot | Identify the exact intensity/density, base measure and conditioning from its pinned source |
| Lifetime coefficient | UNMAPPED in this pilot | The coefficient in the stated asymptotic must be defined from its own source; no assertion that it is a Hermite-expansion coefficient |
| Universal Law | Program label, not a mathematical type or theorem | Every public mathematical claim needs its own domain, definitions and hypotheses |

A missing mapping is a formalization obligation, not evidence of novelty or ill-definition. Existing literature and precise source definitions decide those questions. Do not alter established vocabulary by an attractive but mathematically wrong synonym.
