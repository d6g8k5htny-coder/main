`INVENTORY.json` and `INVENTORY.md` are generated by `tools/cbz_inventory.py`. For each in-scope repository, at the commit read, they record:
- the default head;
- remote branches, with whether each is merged into the default branch;
- tags, stashes, worktrees, and dirty working-tree entries;
- every open PR, with a Layer A lexical scan of the Lean files it changes;
- check-run conclusions on the default head;
- the Layer A scan of the default tree;
- which canonical status surfaces exist;
- a gate-runnability and tooling-gap table for G0–G11.

Anything not observable is recorded as `{"unavailable": reason}`, never omitted. The snapshot is not atomic: the repositories change while it runs, and `generated_at` and the per-repo heads say what was read.

Reproduce, with clones of each repository:

```
python3 -B -S tools/cbz_inventory.py --owner d6g8k5htny-coder \
  --repo main=<clone> --repo Math-=<clone> --repo governance-=<clone> \
  --repo meta-framework=<clone> --repo query-=<clone> --repo Universal-Law-Workspace=<clone> \
  --inaccessible 'google-drive=<reason>' --scope-note '<PARTIAL ...>' \
  --out-json INVENTORY.json --out-md INVENTORY.md
```
