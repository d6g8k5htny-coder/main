### 1. Exact finite-spectrum decomposition

Let Z be the full one-dimensional spectral mass and Z_J its truncation to |j|<=J. Define Gamma_J as the **exact** covariance of the normalized square-truncated spectral field, using Z_J² and the same fixed real linear observations as the full field. Then

`Gamma = alpha Gamma_J + T`, where **`alpha=(Z_J/Z)^2` and `T >= 0` in PSD order**.

Proof: if psi(k) is the observation-feature vector, the retained sum in the full covariance is `(Z_J/Z)^2 Gamma_J`; the complementary sum has quadratic form `sum_outside w(k)|a^T psi(k)|²/Z² >= 0` for each real a. Gaussian decay makes all fixed derivative sums converge. In d product dimensions the power is d, not 1. A certified `delta/Z_J <= eta`, with delta=Z-Z_J, gives `a=(1+eta)^(-2) <= alpha <=1`.

This is a covariance decomposition (or independent Gaussian sum), **not a probability mixture of conditional distributions**. Gamma_J is not an arbitrary midpoint of interval entries and is not automatically the finite image approximation. Numerical identification with this exact finite spectral law remains necessary.

### 2. Conditional covariance sandwich and mean shift

Partition pins X and soft variables Y:

```
Gamma_J = [ G_J   A_J^T ]       T = [ U   V^T ]
          [ A_J   C_J   ]           [ V   W   ]
B_J = A_J G_J^-1
S_J = C_J - A_J G_J^-1 A_J^T
R = [-B_J, I]
G = alpha G_J + U
D = V - B_J U
E = R T R^T
```

Assume **G_J positive definite**. The full G is then positive definite. For the same fixed pin value z, the exact identities are

```
B - B_J = D G^-1
mu - mu_J = D G^-1 z
S = alpha S_J + E - D G^-1 D^T
```

and therefore

**`alpha S_J <= S <= alpha S_J + E` in PSD order.**

Proof: A-B_JG=D. The congruence L=[[I,0],[-B_J,I]] sends Gamma_J to diag(G_J,S_J). The remaining block matrix

`[[G,D^T],[D,E]] = diag(alpha G_J,0) + L T L^T`

is positive semidefinite. Completing the square, or taking its Schur complement at G, proves `E-DG^-1D^T >=0`; `DG^-1D^T >=0` proves the upper bound. This argument allows singular S_J. Standard background is the quadratic-minimization identity in Boyd/Vandenberghe, *Convex Optimization*, Appendix A.5.5, p650, (A.13)-(A.14); I checked the [author-hosted page](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=664). ### 4. A precise restricted-expectation floor transfer

Now require S_J>=s I with **s>0**. Choose certified `a S_J <= S <= u S_J`; `u=1+epsilon/s` is conservative. Suppose

`||S_J^-1/2(mu-mu_J)||2 <= b`

and a fixed measurable region B lies inside

`||S_J^-1/2(y-mu_J)||2 <= R0`.

Define

```
c = u^(-q/2) * exp(-0.5*((1/a-1)*R0² + (2*R0*b+b²)/a)),
```

where q is the soft-variable dimension. Then the full and finite conditional densities satisfy **p(y)>=c*p_J(y) on B**. Consequently, for any nonnegative g,

`E[g(Y) 1_B | X=z] >= c E_J[g(Y) 1_B | X=z]`.

If a target F obeys the pointwise `F>=g*1_B` and a certified finite-law **restricted** expectation is at least L_B>=0, then **`E[F|X=z] >= c*L_B`**.

Proof: set A=S_J^-1/2 S S_J^-1/2, v=S_J^-1/2(y-mu_J), d=S_J^-1/2(mu-mu_J). The exact density ratio is

`det(A)^(-1/2) exp((||v||²-(v-d)^T A^-1(v-d))/2)`.

Use det(A)<=u^q, A^-1<=I/a, ||d||<=b and ||v||<=R0. Since a<=1, the resulting worst-case exponent is attained at the radius bound, giving c. Integration proves the claim.
