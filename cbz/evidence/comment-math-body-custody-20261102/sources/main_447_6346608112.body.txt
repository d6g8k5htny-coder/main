### 1. Exact global transfer

Let Q=N(mu0,S0), P=N(mu,S) on the same R^d, with S0,S symmetric positive definite. Let f be the **same measurable real payoff** under both laws, E_Q[f²]<infinity. Define Delta=mu-mu0 and directed chi-square by `D=E_Q[(dP/dQ-1)^2]` (P relative to Q, not the reverse).

When **K=2*S0-S is positive definite**,

```
1+D = det(S0) / sqrt(det(S)*det(2*S0-S))
      * exp(Delta^T (2*S0-S)^-1 Delta).
```

For these nondegenerate Gaussians D is finite **if and only if** that strict condition holds. Then

```
|E_P f-E_Q f| <= sqrt(Var_Q(f)*D) <= sqrt(E_Q[f²]*D).
```

Consequently, certified E_Q f>=L, E_Q f²<=M2 and D<=Dplus give

**`E_P f >= L - sqrt(M2*Dplus)`.**

Clamp the result at0 only when f>=0. A certified variance upper bound can replace M2; more generally a fixed centering constant c0 permits the budget E_Q[(f-c0)²].

**Proof of the weighted inequality:** put ell=dP/dQ. Both f and ell are in L2(Q), so E_P|f|<infinity and the expectation difference is well-defined. Since E_Q(ell-1)=0,

`E_Pf-E_Qf=E_Q[(f-E_Qf)(ell-1)]`.

Cauchy–Schwarz gives the displayed inequality with its square root intact. This requires neither payoff continuity nor a bounded good region. It does not transfer a changed payoff/event without another error budget.

### 2. Gaussian identity and its domain, derived directly

Whiten using C=S0^-1/2*S*S0^-1/2, h=S0^-1/2*Delta, v=S0^-1/2*(y-mu0). Q is standard Gaussian. The likelihood-ratio second-moment integrand is

`(2*pi)^(-d/2) det(C)^(-1) exp(-(v-h)^T C^-1(v-h)+v^Tv/2)`.

Put M=2*C^-1-I and w=2*C^-1*h. Completing the square gives exponent

`-(v-M^-1*w)^T M (v-M^-1*w)/2 - h^T C^-1 h + w^T M^-1 w/2`.

If M>0, Gaussian integration yields prefactor `det(C)^-1 det(M)^-1/2`. The determinant identity `det(C)^2 det(M)=det(C)det(2I-C)` and matrix identity

`-C^-1 + 2*C^-1*M^-1*C^-1 = (2I-C)^-1`

then give

```
1+D = [det(C)*det(2I-C)]^(-1/2)
      * exp(h^T (2I-C)^-1 h).
```

Transforming back proves the formula in section1. The commutation used here is between C and its own rational functions after whitening, **not** between the original S and S0.

For C>0, M>0 exactly when 2I-C>0, equivalently K>0. A negative eigenvalue of M makes the nonnegative integral grow quadratically along that direction. For a singular PSD M, a null direction leaves an exponential-linear or constant integrand whose full-line integral diverges. Thus absolute continuity alone is insufficient. Infinite D does not imply that a particular polynomial payoff expectation is infinite; it only prevents this L2 likelihood-ratio route.

### 3. Norm ceiling and a rational-only shortcut

Given certified `||C-I||2<=eta<1` and `||h||²<=b²`, eigenvalues of C lie in[1-eta,1+eta]. Hence

```
det(C)det(2I-C)=det(I-(C-I)^2) >= (1-eta²)^d,
h^T(2I-C)^-1 h <= b²/(1-eta),
D <= (1-eta²)^(-d/2)*exp(b²/(1-eta))-1.
```

This is a sufficient envelope, not a necessary domain test. A bad eta bound does not prove that actual K fails positivity.

For a fully rational conservative route define

`r = d*eta²/[2*(1-eta²)] + b²/(1-eta)`.

Because `-log(1-x)<=x/(1-x)` for0<=x<1, log(1+D)<=r. If **r<1**, the series comparison `exp(r)<=sum r^k=1/(1-r)` gives

**`D<=r/(1-r)` and `E_P f >= L-sqrt(M2*r/(1-r))`.**

The extra r<1 is needed only for this rational shortcut, not the exact divergence or exponential envelope. An actual computation must round the final square root upward and the resulting lower endpoint downward. The script does this by integer inequalities; no unverified floating-point exp/log is used in the worked example.
