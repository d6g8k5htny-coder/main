0. **f is a random element of E=C²(X).** P l61's partial sums are measurable maps into the separable Banach space C²(X) and converge almost surely there, so the limit (the smooth version) is measurable. Borel(E) is generated by evaluations (E2 l78–82). G(t,ω) is continuous in t and measurable in ω.
1. **Counts over compacts are measurable for every ω.** For compact C⊂D, k≥1 and m≥1, let C_{k,m}={(t_1..t_k)∈C^k: pairwise distance ≥1/m}, which is compact. Then
   {#(Z_ω∩C)≥k} = ∪_m{min_{C_{k,m}}Σ_i|G(t_i)|=0}.
   The min of a continuous random function over a compact set is attained, and it equals the inf over a countable dense subset, so this event is measurable.
2. **The finite-count event is full and measurable.** Ω_f={#(Z∩D)<∞} is measurable by step 1, and P(Ω_f)=1 because E N_0(G,D)<∞ (Thm 2.2 via H4 step 4). On Ω_f^c set N_A:=0; this changes no expectation.
3. **Borel counting sets.** Fix ω∈Ω_f. Then A_1↦#(Z_ω∩A_1) is a finite measure on Borel(D). The class of A_1 for which ω↦#(Z∩A_1)1_{Ω_f} is measurable contains the compacts, a π-system generating Borel(D). It's closed under proper differences (counts are finite on Ω_f) and increasing unions. By **Dynkin's π-λ theorem** (e.g. Kallenberg, *Foundations of Modern Probability*, 2nd ed., Thm 1.1) it is all of Borel(D).
4. **Product sets.** Borel(D×E)=Borel(D)⊗Borel(E) because D and E are separable metric spaces (Kallenberg, Lemma 1.2). For rectangles, N_{A_1×A_2}=1_{A_2}(f)·#(Z∩A_1) is measurable. For fixed ω∈Ω_f, A↦N_A(ω)=Σ_{t∈Z_ω}1_A(t,f(ω)) is a finite measure, so the measurable class is again a λ-system containing the rectangle π-system. By π-λ, N_A is measurable for all A∈Borel(D×E).
5. **Countable additivity and finiteness.** For disjoint A_k, N_{∪A_k}=Σ_kN_{A_k} pointwise. Monotone convergence then gives μ(∪A_k)=Σμ(A_k). Also μ(D×E)=E N_0(G,D)<∞, which is E2 l63.
