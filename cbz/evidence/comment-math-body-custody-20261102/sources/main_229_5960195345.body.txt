## 2. The maximum pin confines this event to a signed spectral strip

On {w>0}, K_M is negative definite. Its transverse principal block is
A_M=D_Theta^2 F_r(-ru/2), so A_M<0. The same deterministic comparison used
in [G] Step F2 and [E] F2 gives

  ||A_M-A|| <= C_0 r N.                                       (4)

One may enlarge C_0>=1 to accommodate the source norm convention. The
Rayleigh variational formula yields
lambda_max(A)<=lambda_max(A_M)+||A-A_M||<C_0 r N.
If A is not negative definite then lambda_max(A)>=0. Therefore

  {w>0,A not<0} subset {0<=lambda_max(A)<C_0 r N}.              (5)

This is a signed strip around ZERO for the largest eigenvalue; it is not the
negative-cone variable lambda_min(-A). The source Lemma D is stated precisely
for |lambda_max(A)|<tau on arbitrary symmetric matrices and thus applies.
No claim that the left event is empty is made.

## 3. Weighted spectral-strip and determinant-window estimates

Put L_tau={|lambda_max(A)|<=tau}. Conditional on the current field's J'''
(all free jets except f4 and A), [E] F5 supplies a Gaussian matrix density
with uniform upper/lower covariance bounds and mean bounded by
C(P+|J'''|). For j=0,1,2 and every fixed n>=0, [G] Lemma D implies

  E[(1+||A||)^n |Delta|^j 1_L_tau | J''']
      <= C tau^{j+1} (P+|J'''|)^{N(n,j)}.                     (6)

Indeed |Delta|<=tau ||A||^{m-1} on L_tau: one determinant factor is
lambda_max(A), regardless of sign. Apply the first inequality of Lemma D
with the increased polynomial norm weight. For j=0 use that inequality
directly. This holds for every tau>0; no inverse eigenvalue moment is used.
Boundary equality has conditional probability zero, or can be obtained by
monotone limits from larger strips.

The second inequality of [G] Lemma D, by the dyadic calculation [W](4.2),
also gives for every s>0

  E[(1+||A||)^n min(1,s/|Delta|) | J''']
     <= C s[1+log_+(1/s)] (P+|J'''|)^{N(n)}.                  (7)

For 0<s<1, partition |Delta|<s, successive dyadic shells up to1, and
|Delta|>=1. Each small shell costs at most C s, their number is
O(1+log(1/s)), and the last part costs C s times a polynomial moment.
For s>=1 the unconditional polynomial moment is <=C s times its envelope.
Set min(1,s/0)=1; the zero determinant set is null. Formula (7) will be
used globally, after dropping the strip indicator only in the last term.

## 4. Keep the actual typed window before integrating f4

By [W](4.1), with an integer n_0>=1 and C_R>=1 enlarged as necessary,

  w <= 4r^2(6kappa|Delta|+eta)^2
                 1{|Y_r|<=6kappa|Delta|+eta},

This source bound is for every actual typed pair, not just A<0, and holds
at k=0. Split N into [2^h,2^{h+1}), h>=0, and define deterministic values

  eta_h=C_R r 2^{(h+1)n_0},   tau_h=C_0 r 2^{h+1}.             (9)

Use (5) and enlarge the strip and window using (9). The layer's N^a
costs 2^{(h+1)a}. Conditional Markov, using [E] F4 with the current free

to E[N^a w 1{A not<0}] is at most

 C r^2 2^{-h(p-a)} E[(6kappa|Delta|+eta_h)^2
       1_L_tau_h 1{|Y_r|<=6kappa|Delta|+eta_h}(P+|J'|)^p].     (10)

Constants absorb 2^a. This is conditional Markov, not an independence
assertion about N and the jets. All uses of f4 and A below concern F_r's

window in (10) has length144kappa+24eta_h/|Delta|. [E](2.1), together

        min(1,144kappa+24eta_h/D)(P+|J''|)^q], D=|Delta|,      (11)

## 6. Adverse checks and a real typed example

Thus det H_M=(54/5)r^3>0 and H_M<0; det H_S=-(2/5)r^3<0.

C^9 norms on a fixed bounded coordinate box; a fixed smooth cutoff equal
