*Proof (every input named).*
1. **Desingularization**, extending P (3.1)/(3.4) to both Hessians. Apply Hermite interpolation along the pair axis:
   - (f, f_x, f_xx) at a,c → quintic → ∂_x^{0..5}f(0);

   - f_{y_iy_j} at a,c → linear → ∂_x^{0..1}f_{y_iy_j}(0).
   
   For r>0 this is an invertible T_r, with 6+4m+m(m+1) = 2(d+1)+d(d+1) rows (m = d−1). The Hermite remainder, together with the derivative moments of P l61 (or R l47's Fourier argument), gives V_r = T_r𝒢_r → V_0 in every L^p, at rate O(r) and uniformly over frames.
2. **Contact positivity.** Every functional in V_0 has transverse order ≤ 2. Write X_v = cos³θ f_xxx + 3cos²θ sinθ f_xxt + 3cosθ sin²θ f_xtt + sin³θ ∂_t³f. The first three terms lie in V_0. ∂_t³ = Σ_{|β|=3}(3!/β!)t^β∂_y^β, and no ∂_y^β lies in V_0.

   - Hence Var(X_v | V_0) = sin⁶θ·q(t)ᵀΓ_R q(t) ≥ sin⁶θ·λ_min(Γ_R)·min_t|q(t)|² > 0.
   - Γ_R is continuous in R and O(d) is compact (P l105), so the bound is uniform.
3. **Small r.** Residual variance is invariant under the invertible T_r. Cov(V_r) → Cov(V_0), which is positive definite, and Cov(X,V_r) → Cov(X,V_0). So Var(X_v|𝒢_r) → Var(X_v|V_0) uniformly, and it stays ≥ ½ of the contact value for r ≤ r_1.
