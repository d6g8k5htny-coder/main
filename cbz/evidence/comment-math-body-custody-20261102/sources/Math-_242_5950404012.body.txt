## CE-1. An exact sufficient weighted coarea bound

Let (Omega,lambda) be sigma-finite, k>0, and 0<r<r0. Suppose the nonnegative marked **intensity** error before lifetime pushforward is

    d beta = r b(r,k,omega) dr dk d lambda(omega),
    0 <= b(r,k,omega) <= C r^delta h(k,omega),
    delta >= 0,
    M_delta := integral k^(-(delta+2)/3) h(k,omega) dk d lambda < infinity.    (CE.1)

Here h is measurable and nonnegative, C finite and independent of r,k,omega. All determinant weights, pin densities, spatial factors, mark probabilities and relevant multiplicities must already be included in b. This is an intensity bound, not a bound on an unweighted event probability.

Under the exact map T(r,k,omega)=kr^3, beta_T is absolutely continuous on positive lifetimes. Its density has the representative

    nu_beta(ell) = (1/3) ell^(-1/3)
        integral 1{(ell/k)^(1/3)<r0}
                 k^(-2/3) b((ell/k)^(1/3),k,omega) dk d lambda.             (CE.2)

Consequently, for every ell>0 for this representative and almost everywhere for any density version,

    nu_beta(ell) <= (C/3) M_delta ell^((delta-1)/3),
    beta_T((0,t]) <= [C/(delta+2)] M_delta t^((delta+2)/3).                 (CE.3)

**Proof.** For a nonnegative measurable test function psi, Tonelli gives
`integral psi(kr^3) r b dr dk d lambda`.
For fixed k, use r=(ell/k)^(1/3), dr/dell=(1/3)k^(-1/3)ell^(-2/3). Thus
`r dr/dell=(1/3)k^(-2/3)ell^(-1/3)`, proving (CE.2) without differentiation of a cumulative asymptotic. Substitute (CE.1); the remaining k power is -(delta+2)/3. Integrating this bound from0 to t gives (CE.3). The bound also proves local finiteness of the pushed-forward error. No independence assumption is used. QED.

If actual finite-bar and canonical-pair lifetime measures satisfy the separate **measure-level** identification
`|mu_bars-mu_pairs| <= beta_T` (total variation of their signed difference), then their densities differ by at most nu_beta almost everywhere, provided the pair measure is absolutely continuous. This follows from Radon–Nikodym domination: a Lebesgue-null set has zero beta_T and pair mass, hence zero bar mass, and the dominated signed derivative obeys the same inequality. Establishing that measure domination requires both directions of the pairing bridge, including multiplicities and bars missed by candidates; CE-1 does not establish it.

The powers are therefore:

| Joint mark/intensity multiplier b | Error before pushforward | Density error | Cumulative error |
| --- | --- | --- | --- |
| O(1) | O(r) dr | O(ell^(-1/3)) | O(t^(2/3)) |
| O(r^3) | O(r^4) dr | O(ell^(2/3)) | O(t^(5/3)) |
| O(r^(13/4)) | O(r^(17/4)) dr | O(ell^(3/4)) | O(t^(7/4)) |

Thus a joint r^3 estimate is lower order for a leading ell^(-1/3) law. It is **not** automatically lower order for an ell^(2/3) coefficient. On this exact compact-k interface, delta=13/4 is sufficient for an O(ell^(3/4)) error; delta>3 gives o(ell^(2/3)). This is a sufficient interface, not a necessary exponent for every field decomposition: explicitly evaluated signed terms or a different proved normalization may change the calculation. The expanding-domain D.8 bounds remain a separate application requirement.

### Quantitative cubic remainders

The same sufficient conclusion survives a genuine C1-controlled cubic map. Assume delta>=1 and, uniformly on the domain,

    T(0,k,omega)=0,
    T(r,k,omega) >= a0 k r^3,
    partial_r T(r,k,omega) >= a1 k r^2,    a0,a1>0,                        (CE.4)

with T jointly measurable and, for each k,omega, continuously differentiable and strictly increasing in r. For fixed k,omega change variables through its inverse on its image. The density is r b/partial_r T there, so

    nu_beta(ell) <= [C/(a1 a0^((delta-1)/3))]
                   M_delta ell^((delta-1)/3).                            (CE.5)

Indeed r <= (ell/(a0 k))^(1/3); apply this to r^(delta-1) in r b/partial_r T. Outside the image the contribution is zero. Tonelli again justifies the integrations. For fixed k in [k_min,k_max] with k_min>0, the bounds
`|T-kr^3|<=Mr^4` and `|partial_r T-3kr^2|<=M' r^3`
imply (CE.4) with a0=1/2,a1=3/2 whenever Mr<=k_min/2 and M'r<=3k_min/2. Constants depend on the displayed fixed parameters. No uniform k-downarrow0 assertion is made. An O(r^4) bound on T's value alone is not substituted for the separate derivative bound.

## CE-2. Falsifier of the marginal-probability inference

This is an abstract marked-measure counterexample, **not a claim about the actual Gaussian field or its determinant distribution**. It proves that the stated powers and normalization alone are insufficient.

Take the canonical pair measure

    d mu = r dr dk,    0<r<=1, 1<=k<=2,
    ell=kr^3.

For 0<ell<=1 its lifetime density is

    nu_mu(ell) = c ell^(-1/3),    c=2^(1/3)-1>0.                          (CE.6)

Set R_n=2^(-2n), ell_n=R_n^3=2^(-6n), n>=1, and define the measurable bad set

    E = union_n {
        R_n/2^(1/3) <= r <= R_n,
        1<=k<=2,
        |k-ell_n/r^3| <= r^3
    }.                                                                   (CE.7)

Its radial annuli are disjoint. At each fixed r, let k be uniform on[1,2], take W_r=r^2, and Z_r=E[W_r]=r^2. Since the marked k interval has length at most2r^3,

    E[W_r 1_E] <= 2r^5,
    Q_r^W(E) = E[W_r 1_E]/Z_r <= 2r^3.                                   (CE.8)

These exactly realize the weighted numerator/denominator powers under discussion. Put beta=1_E mu. Its cumulative error is nevertheless small:

    beta_T((0,t]) <= integral_0^(t^(1/3)) r(2r^3)dr
                  = (2/5)t^(5/3),    0<t<=1.                             (CE.9)

But its density is large on entire positive-length lifetime bands, not just a choice of values at countably many points. Let

    J_n = [ell_n-ell_n^2/8, ell_n+ell_n^2/8].

For ell in J_n and r in[5R_n/6,8R_n/9], set k=ell/r^3. The central k value ell_n/r^3 lies in[(9/8)^3,(6/5)^3]. Since ell/ell_n is between7/8 and9/8,
`(9/8)^3(7/8)>1` and `(6/5)^3(9/8)<2`, so k remains in[1,2]. Also

    r^6 >= (5/6)^6 ell_n^2 > ell_n^2/8 >= |ell-ell_n|,

which is exactly the membership condition in (CE.7) after multiplication by r^3. These r lie in the nth radial annulus. Changing k to ell at fixed r has Jacobian r^(-3), hence

    nu_beta(ell) >= integral_[5R_n/6,8R_n/9] r^(-2)dr
                  = 3/(40R_n)
                  = (3/40)ell_n^(-1/3),    ell in J_n.                    (CE.10)

In particular `ell^(1/3)nu_beta(ell)>=(3/40)(7/8)^(1/3)>0` on every J_n. Thus nu_beta is not o(ell^(-1/3)), even in the essential sense; each band has positive Lebesgue measure. At ell=ell_n the entire admissible r fiber is marked, so the natural density representative actually equals (CE.6).

Finally mu_good=mu-beta is a nonnegative measure. Equations (CE.6),(CE.9) give the same leading cumulative t^(2/3) coefficient for mu_good and mu, but (CE.10) prevents their lifetime densities from agreeing at leading order. This also falsifies differentiating a cumulative o(t^(2/3)) sandwich without an additional density/regularity input. QED.

**Why concentration causes the failure:** (CE.8) averages over k at each fixed r; coarea samples k=ell/r^3. The thin bad intervals track this moving fiber. A valid field estimate must control the weighted mark after disintegration by the height/cubic parameter, or directly control its coarea integral. A fixed-r marginal bound cannot replace either.

## Exact finite controls, full source

The proofs above cover all parameters in their stated domains. The following independent standard-library controls check the rational band margins, numerator/normalizer arithmetic, two coordinate integrations and error powers. They do not execute the author's checker or verify a Gaussian theorem. Save as coarea_error_controls.py and run `python -B -S coarea_error_controls.py`, then `python -B -O -S coarea_error_controls.py`. Both actual runs returned the identical output:

    {"exact_checks": 702, "field_theorem_verified": false, "invalid_cases_rejected": 21}

```python
from fractions import Fraction as F
import json

checks = 0
rejected = 0

def check(condition):
    global checks
    if not condition:
        raise RuntimeError('exact control failed')
    checks += 1

def reject(condition):
    global rejected
    if condition:
        raise RuntimeError('invalid inference accepted')
    rejected += 1

# Uniform bounds proving the whole lifetime band stays in the marked set.
check(F(5, 6)**6 > F(1, 8))
check(F(9, 8)**3 * F(7, 8) > 1)
check(F(6, 5)**3 * F(9, 8) < 2)
check(F(6, 5) - F(9, 8) == F(3, 40))

for n in range(1, 9):
    R = F(1, 2)**(2*n)
    ell = R**3
    check(R/4 < R*F(5, 6))
    for j in range(7):
        r = R*(F(5, 6) + F(j, 6)*(F(8, 9)-F(5, 6)))
        center = ell/r**3
        lo = max(F(1), center-r**3)
        hi = min(F(2), center+r**3)
        q = max(F(0), hi-lo)
        check(q <= 2*r**3)
        check(r**2*q <= 2*r**5)
        check((r**2*q)/r**2 == q)
        for shift in [F(-1, 8), F(0), F(1, 8)]:
            lifetime = ell + shift*ell**2
            k = lifetime/r**3
            check(1 <= k <= 2)
            check(abs(k-center) <= r**3)
            check(abs(lifetime-ell) <= r**6)
    # Independent r- and k-coordinate integration over a rational cube window.
    a, b = F(9, 8), F(6, 5)
    integral_r = 1/(R/b) - 1/(R/a)
    integral_k = F(1, 3)/R * (3*b-3*a)
    check(integral_r == integral_k == F(3, 40)/R)
    reject(integral_r == (3*b-3*a)/R)  # omitted 1/3 Jacobian
    reject(F(3, 40)/R <= 2*R**2)      # false fiberwise r^3 suppression

for delta in [F(1), F(2), F(3), F(4), F(5)]:
    density_power = (delta-1)/3
    cumulative_power = (delta+2)/3
    check(density_power+1 == cumulative_power)
    check(F(1, 3)/cumulative_power == 1/(delta+2))
    reject(density_power == delta/3)  # omitted density Jacobian cost

print(json.dumps({'exact_checks': checks, 'invalid_cases_rejected': rejected,
                  'field_theorem_verified': False}, sort_keys=True))
```
