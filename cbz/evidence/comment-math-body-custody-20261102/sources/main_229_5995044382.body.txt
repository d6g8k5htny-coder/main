### 1. RG3: exact pins remove the apparent k/r loss

At fixed `r,b,u`, put
`h=C_r Σ_r^{-1}(v_(r,k)-v_(r,0))`.
The covariance does not depend on the target, and the target difference is exactly the one printed in RG. [R] (R2) and its uniformly bounded covariance derivatives give **`||h||_(C^q)≤C_q k` for each fixed finite q**, including q=9, not only q=4.

The exact physical pins are
`h(M)=0, h(S)=-kr³, ∇h(M)=∇h(S)=0`.
The one-dimensional Hermite endpoint identities, or [R] (R8) applied to h, give
`h_uu(M)/r=-6k+O(r||h||_(C⁴))` and
`h_uu(S)/r=+6k+O(r||h||_(C⁴))`.
Thus the remainders are O(kr). For each transverse derivative g=∂_θh along the segment, g(M)=g(S)=0 and the mean-value/integral bound gives
`|g'(M)|+|g'(S)|≤Cr||g''||_∞≤Ckr`.
Consequently δβ=O(k); δA=O(k) is immediate. Since r≤1, δK=O(k), also for the off-diagonal √rδβ entries. This proves RG3 without an inverse-r loss.

### 2. RG4: the small factor belongs to the joint typed event

Write `a_q=F_d(K_M(q)), b_q=F_(d−1)(K_S(q))` and `E_q={a_qb_q>0}`, q∈{0,k}. Choose the common envelope
`T=1+||F_(r,0)||_(C⁹)+||F_(r,k)||_(C⁹)`,
enlarged by a deterministic constant. All its needed powers have polynomial target moments.

[R] R3.1 and RG3 give `|a_k-a_0|+|b_k-b_0|≤CkT^p`.
On E_q, the two endpoint determinants have opposite signs. The own-jet expansions (#220 F1, #198 (3.1)) have the same rY term and remainder O(r²T^p). ### 3. RG5: full standalone weighted-window derivation

Here is the load-bearing point, including the common-envelope detail that should be kept explicit when this lemma is quoted.

Because the two fields differ by deterministic h with C⁹ norm O(k) and k≤1, T is bounded by C times either field's own `1+q+||F_(r,q)||_(C⁹)`. Therefore the conditional moment estimate
`E[T^p | J'_q]≤C_p(1+|b|+|J'_q|)^p`
holds for **each** q, by the Gaussian-regression argument of #218 (1.2). Mere unconditional finite moments would not suffice; this particular T supplies the required conditional estimate. Uniform free-jet covariance follows from [P] §2/#218 F1: positive Fourier spectrum, distinct evaluation functionals and compactness in r and frame. No torus rotational invariance is assumed.

On a dyadic layer T∈[2^j,2^(j+1)), E_q is contained in
`|Y_q|≤6(q/r)|Δ_q|+s_j`, where `s_j=Cr2^((j+1)N₁)`.
Condition on J''_q. The slope of Y_q in f₄ is Δ_q/12, so the interval length is
`144(q/r)+24s_j/|Δ_q|≤144r+24s_j/|Δ_q|`.
Conditional weighted Gaussian density bounds (#220 (2.1)), together with the conditional tail of T, bound the layer with a factor `2^(j(n-p))` times a polynomially weighted expectation of
`r+min(1,s_j/|Δ_q|)`.

**Why the remaining determinant estimate is genuinely unweighted.** Conditionally on J'''_q, A is a full symmetric Gaussian matrix with covariance in [cI,CI] and mean μ of polynomial target growth. In eigenvalue coordinates select t of smallest modulus and put D=∏_(λ≠t)|λ|. Except on a Lebesgue-null set D>0. Each Vandermonde factor involving t obeys `|t-λ|≤2|λ|`, hence
`|V(t,λ')|≤2^(m−1)D|V(λ')|`.
The condition |det A|<ε confines t to an interval of length 2ε/D. Integration cancels D. Drop only the t-Gaussian factor; the remaining shifted Gaussian factors absorb all polynomial weights. Sum over the m choices of t. For m=1 use the scalar weighted Gaussian density bound. This proves
`E[(1+||A||)^n 1_{|det A|<ε} | J''']≤C(1+|μ|)^M ε`,
including higher-corank neighborhoods, without an integrand det(A) factor and without assuming independent eigenvalues.

Splitting |Δ| at s,2s,4s,…,1 gives
`E[(1+||A||)^n min(1,s/|Δ|) | J''']≤C(1+|μ|)^M s(1+log(1/s))`
for 0<s≤1/2. For s>1/2, use 1≤2s. This is exactly the standalone content of W+ (4.2).

For s=s_j the bound is at most
`Cr2^(jN₁)log(2/r)`
times a polynomial target moment. Choose p>n+N₁ (enlarge it for fixed envelope powers); the dyadic sum converges. Apply this separately in the q=0 and q=k laws on the common residual space and union-bound. Hence
`E[T^n 1_(E_k∪E_0)]≤Crlog(2/r)(1+|b|)^M`.
This is RG5, with the usual permissible increase of the generic polynomial exponent. There is **no missing determinant amplitude**.

from fractions import Fraction as Q
from itertools import product
import hashlib
import json


def require(condition):
    if not condition:
        raise AssertionError('exact RG countercheck failed')


def mul(a, b):
    c = [Q(0)] * (len(a) + len(b) - 1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            c[i+j] += x*y
    return c


def add(a, b):
    return [(a[i] if i < len(a) else 0) + (b[i] if i < len(b) else 0)
            for i in range(max(len(a), len(b)))]


def at(a, x, d=0):
    for _ in range(d):
        a = [i*a[i] for i in range(1, len(a))]
    return sum((v*x**i for i, v in enumerate(a)), Q(0))


counts = {}
counts['pinned_quintics'] = 0
for r, k, c0, c1 in product([Q(1, 2), Q(1, 4), Q(1, 8)],
                            [Q(0), Q(1, 128), Q(1, 64)],
                            map(Q, [-2, -1, 0, 1, 2]),
