## Mathematical statement and argument

Fix dimension `d : ℕ`, a real period `L`, a proof `hL : 0 < L`, a function
`g : E d → ℝ`, and the source's literal periodicity assumption
`hperiodic : IsLPeriodic d L g`. Set

\[
q=\operatorname{torus\_proj}(d,L,hL),\qquad
F=\operatorname{descendedHeight}(d,L,hL,g,hperiodic).
\]

The candidate's general-level theorem has the exact type

```lean
theorem quotient_closedSuperlevel_lpc_of_euclidean
    (d : ℕ) (L : ℝ) (hL : 0 < L)
    (g : E d → ℝ) (hperiodic : IsLPeriodic d L g) (a : ℝ)
    (hEuclideanLPC : LocallyPathConnectedSpace {x : E d // a ≤ g x}) :
    LocallyPathConnectedSpace
      {q : torus_quotient d L hL // a ≤ descendedHeight d L hL g hperiodic q}
```

The proposed proof proceeds in four source-bound steps.

1. `TorusTopology.lean:84–88` supplies surjectivity and continuity of the actual
   projection. Its actual covering theorem at 109–113, together with pinned
   `Mathlib/Topology/Covering/Basic.lean:343–344`, supplies openness. These are
   precisely the three named fields of `IsOpenQuotientMap` at pinned
   `Mathlib/Topology/Defs/Basic.lean:182–188`.
2. Put `S = {q | a ≤ F q}`. The source's exact descent, not a rescaled or
   replacement height, satisfies `F (q x) = g x`.
   `CriticalLevelAttainment.lean:21–32` transports literal `IsLPeriodic` to the
   identical lattice formula and defines `descendedHeight`; its
   `descendedHeight_proj` is proved by `rfl`. Consequently
   `q ⁻¹' S = {x | a ≤ g x}`. Candidate lines 33–40 state and justify this set
   equality using `descendedHeight_proj` explicitly. Candidate lines 51–54 use
   the same literal identity to install the supplied Euclidean LPC proof as the
   instance for the restricted map's actual source subtype.
3. Pinned `Mathlib/Topology/LocalAtTarget.lean:98–100` says that an open quotient
   map restricted over **any** target subset is again an open quotient map:
   `IsOpenQuotientMap (S.restrictPreimage q)`. It assumes neither that `S` is open
   nor that `S` is closed. This is why it applies at the closed threshold without
   substituting a strict superlevel. Pinned `Maps/OpenQuotient.lean:38–39`
   supplies its `Topology.IsQuotientMap` proof.
4. Pinned `Mathlib/Topology/Connected/LocallyPathConnected.lean:249–251`
   transfers LPC along a quotient map, with source LPC as a typeclass hypothesis
   (the surrounding hypothesis is introduced at line 84). Applying this to the
   restricted map gives LPC of the actual quotient closed-superlevel subtype.
   It is not an appeal to inheritance by arbitrary closed subsets.

The transfer theorem does not require smoothness or Morse data. This is
appropriate because those hypotheses concern the missing Euclidean analysis,
whereas this lemma only transports an already supplied subspace property. The
source topology on the Euclidean superlevel is the inherited subtype topology;
the target topology is the inherited subtype topology on the actual torus
quotient. Neither is replaced by an arbitrary coinduced topology.

The source `E d` is literally `EuclideanSpace ℝ (Fin d)`
(`Lifetime.lean:76`), as is `torus_E d` (`TorusTopology.lean:21`). The two lattice
vectors use the same finite sum (`Lifetime.lean:84–85` and
`TorusTopology.lean:24–25`). Thus the preimage identity uses the existing
periodicity adapter and existing quotient, with no coordinate rescaling or new
notion of periodicity. Dimension is unrestricted, just as in the source; the
positivity of `L` remains explicit because the actual quotient construction
depends on it.
