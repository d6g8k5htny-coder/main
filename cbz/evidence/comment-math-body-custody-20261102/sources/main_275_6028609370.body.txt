**Model A — omitted event square root is false; Cauchy–Schwarz is sharp.**

Let Ω = {a, b} with the power-set σ-algebra and μ({a}) = 1/4, μ({b}) = 3/4. This is a probability measure. Let W(a) = 4, W(b) = 0, and A = {a}. W is measurable and bounded, hence in L²(μ). Every subset is measurable.

- q = μ(A) = 1/4
- n = ∫_A W dμ = 1
- z = ∫ W dμ = 1
- M₂ = ∫ W² dμ = 4

Then n = √M₂ √q, so `p02_lm008_event_cs` is sharp on this model. The mutation that drops √q gives √M₂ · q = 1/2 < 1 = n, so it is false. This is the probability-space realization of `p02_lm008_sqrt_counterexample`. It does not prove the inequality for a Gaussian field.

**Model B — an upper normalizer does not replace the missing lower premise.**

Let Ω = {a}, μ({a}) = 1, W = 1, A = Ω, r = 1, cW = 1, cZ = 2. Then q = n = z = M₂ = 1. The second-moment premise M₂ ≤ cW r⁴ holds. The lower-normalizer premise cZ r² ≤ z is false, because 2 ≤ 1 is false. The ratio bound asserted by `p02_lm008_measure_transfer` would say n/z ≤ (√cW / cZ) √q, that is 1 ≤ 1/2, which is false. So the upper comparison z ≤ cZ r² cannot be substituted for the required lower premise. This realizes `p02_lm008_upper_normalizer_counterexample` and does not refute the conditional transfer theorem.
