**Why this is new.** Earlier lanes could not reach Edwards's coefficient pages. Siegel 1932, the source Edwards ch. 7 presents, is openly available in English: Barkan and Sklar's translation, [arXiv:1810.05198](https://arxiv.org/abs/1810.05198) (PDF SHA-256 `588495c2…acccdffb0`). It is translated from Siegel's *Gesammelte Abhandlungen* I, pp. 275–310. The coefficients are equations (44)–(45) on translation page 17 (Ges. Abh. p. 290):
- (44): e^{iϑ} ζ(½+it) = 2 Σ_{n≤m} cos(ϑ − t log n)/√n + (−1)^{m−1} (t/2π)^{−1/4} R, with m = ⌊√(t/2π)⌋.
- R ~ C0 + C1 t^{−1/2} + C2 t^{−1} + C3 t^{−3/2} + C4 t^{−2} + ⋯
- C0 = F(δ); C1 = −F‴(δ)/(2³·3); C2 = F″(δ)/2⁴ + F⁽⁶⁾(δ)/(2⁷·3²). The translation also prints C3 and C4.
- F(x) = cos(x² + 3π/8)/cos(√(2π)·x); δ = √t − (m + ½)√(2π).
I read these from a rendered image of the page, because text extraction garbles the fractions.

**Correspondence with `stats/rs_zeta.py`** (blob `8b97a1f6`):
- The packet's p = √(t/2π) − N gives δ = √(2π)(p − ½), so F(δ) = Ψ(p) exactly. The numerator phase differs by π and so does the denominator's, so the signs cancel.
- d/dδ = (2π)^{−1/2} d/dp, so F⁽ᵏ⁾(δ) = (2π)^{−k/2} Ψ⁽ᵏ⁾(p).
- The packet expands in a^{−1} = (2π)^{1/2} t^{−1/2}, so C_k(packet) = C_k(Siegel)/(2π)^{k/2}.
- Hence C1 = −Ψ‴/(24·4π²) = −Ψ‴/(96π²), and C2 = Ψ″/(16·4π²) + Ψ⁽⁶⁾/(1152·16π⁴) = Ψ″/(64π²) + Ψ⁽⁶⁾/(18432π⁴). These are the packet's expressions. The main sum and the prefactor (−1)^{N−1}(t/2π)^{−1/4} also match (44).
