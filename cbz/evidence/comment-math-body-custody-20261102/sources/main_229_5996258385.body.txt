`∀ r ∈ (0,r₀],  p(r) ≤ C · √(q(r))`.

`∀ m > 0, ∀ η > 0, ∃ δ_q ∈ (0,r₀] such that ∀ r ∈ (0,δ_q], q(r) ≤ η · r^m`.

**Conclusion.** `∀ k > 0, p(r) = o(r^k)` as `r → 0⁺`, i.e.

`∀ k > 0, ∀ ε > 0, ∃ δ ∈ (0,r₀] such that ∀ r ∈ (0,δ], p(r) ≤ ε · r^k`.

### Proof blueprint
Fix `k > 0` and `ε > 0`.

1. **`C = 0`.** Then `p(r) = 0` on `(0,r₀]`, so `p(r) ≤ ε r^k` for every `r`. Any `δ` works. No use of the `q`-hypothesis.
2. **`C > 0`.** Set `m := 2k` and `η := (ε/C)²`. By the hypothesis, get `δ` with `q(r) ≤ (ε/C)² · r^(2k)` on `(0,δ]`. Then `√q(r) ≤ (ε/C) r^k`, hence `p(r) ≤ C √q(r) ≤ ε r^k`.

Capsule match: fix target power `p`; feed any `o(r^(2p))` rate into the square-root bound; absorb the fixed prefactor into ε.

### C = 0
Trivial: the comparison forces `p ≡ 0`. Gate the `(ε/C)²` construction behind `C > 0` so there is no division by zero.

### Fixed vs r-dependent C (load-bearing)
`C` must be independent of `r`. If `C(r)` may blow up, super-polynomial transfer can fail.

**Counterexample sketch.** Take `q(r) = exp(−1/r)`, `C(r) = 1/√q(r) = exp(1/(2r))`, `p(r) ≡ 1` on `(0,1]`. Then `p = C(r)√q` holds with equality and `q = o(r^m)` for every `m > 0`, but `p ≡ 1` is not `o(r^k)` for any `k > 0`. In P02-LM-008, `C_W` and `c_Z` are stated independent of `r`, so `C := √C_W / c_Z` is fixed.

### little-o vs big-O (do not conflate)
- `∀ m, q = o(r^m)` (with fixed `C`) ⇒ `∀ k, p = o(r^k)` (witness uses doubled power `m = 2k`).
- `∀ m, q = O(r^m)` likewise yields `∀ k, p = o(r^k)` for nonnegative `q` (pick `m = k+1`, absorb `C_m r` into ε).
- **One** rate `q = O(r^N)` yields only `p = O(r^{N/2})` — polynomial transfer (consequence A style), **not** super-polynomial preservation. PT8 needs the input at every power.
