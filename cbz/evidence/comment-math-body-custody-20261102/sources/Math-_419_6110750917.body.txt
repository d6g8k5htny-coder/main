For h ≤ b, define C(h,M) to mean that there is y in X with g(y) > b and a path from M to y contained in {x : g(x) ≥ h}. The target is:

1. Prove δ < b and that δ is an attained critical value. Finiteness as a genuine maximin death must be justified from the compact connected torus and the existence of a higher endpoint; the interface's use of a real number is not by itself that justification.
2. Prove **C(h,M) iff h ≤ δ**, including h = δ. The strict clause alone settles neither attainment at equality nor the topology of the critical level.
3. Prove that the unique **torus critical point** S with g(S) = δ has Morse index d−1 and merges the component carrying birth label b with a component carrying a strictly older birth label. Define the label tracking through prior mergers, or consume a separately proved tracking theorem. A saddle whose two attaching sectors belong to the same component does not kill H0.
4. Relate that topological merger to `I.ElderPartner g M S` on the stated Morse locus using proved quotient/lift compatibility and the interface clauses. State exactly which direction is topological construction and which direction consumes the interface.

The eventual decreasing-height label interval is **(δ,b]**, equivalently **[−b,−δ)** for increasing parameter t = −h. This convention is for {g ≥ h}; a different filtration must not silently reuse it. This task alone does **not** establish an interval decomposition, a barcode, or an endpoint-preserving bijection. ## Reconstruction of the intended mathematical obligation

The following reconstruction tests the task's coherence and the dependency boundary. It is not a substitute formal proof or a claim that the named Lean dependencies are available.

Write the periodic lift as `g_tilde : R^d -> R` and the descended function as `g : X -> R`. A chosen lift of M is needed when consuming `I.deathHeight` and `I.ElderPartner`, whose current types take Euclidean functions and points. Projection sends lifted paths to quotient paths. Conversely, a quotient path starting at M must lift from any chosen representative, with the endpoint allowed to be an arbitrary lift of its quotient endpoint. Periodicity preserves all height inequalities. The task explicitly requires this compatibility rather than treating the symbols as definitionally equal.

For a nonessential M, `essential_iff` supplies a point of height greater than b. The torus is path connected, and the continuous height on a connecting path has a minimum. Compactness of X supplies a global finite lower bound; every connecting path starts at height b, giving an upper bound b for its bottleneck. Thus the family of bottlenecks is nonempty and bounded. Identifying its supremum with the interface real number still requires the strict-path equivalence and quotient compatibility; the mere type `deathHeight : R` would not establish this interpretation.

Nondegeneracy of the local maximum gives a small isolating neighborhood of M with its boundary uniformly below b. Every path to a higher endpoint leaves that neighborhood and crosses the lower boundary. This yields a uniform strict upper bound below b on all bottlenecks and hence delta < b. A bare assertion that every individual path dips below b would be insufficient, because it would not exclude a supremum equal to b. The task's nondegenerate maximum and compact local-form obligations provide the appropriate stronger route.

The compact Morse critical set is closed and its points are isolated, so it is finite. Distinct critical values order the events. At regular bands, the required flow/deformation theorem preserves the relevant component maps. At a critical value c, the required closed-critical-level local theorem must describe the components of the level set itself, as well as the nearby regular levels. That final requirement is essential: a theorem solely comparing levels c-epsilon and c+epsilon does not by itself prove the requested witness at c.

Component labels can be tracked without first constructing a barcode. A maximum births its own label. When two distinct components merge, retain the higher birth label; handles within a component do not alter the label. Inductively, a component's surviving label is its oldest/highest maximum birth. The component containing M can absorb younger components while keeping label b. Its first connection to any point of height greater than b is exactly its first merger with a component carrying a higher birth label. This interpretation rules out mistaking an earlier merger with a younger component for M's death.

At that first elder connection the local event has to merge two components. For sublevels of -g, only an index-one handle has a disconnected attaching set capable of doing so; its g-index is d-1. A zero-handle births a component, while handles of index at least two have connected attaching sets and cannot merge two components. An index-one handle can also attach within one component, which is why the local Hessian index is necessary but not sufficient. Distinct torus critical values give one critical torus point S at the elder connection height.

The closed-critical-level theorem makes the two upper sectors connected through S at the event itself. It therefore supplies a closed-superlevel path from M to an older component and a point above b. This is the endpoint witness missing from the strict characterization alone. After this topological construction, comparison with the strict characterization identifies the event height with delta: paths at a lower closed threshold remain strictly above any still lower threshold, and no older connection exists above the event.

The exact equivalence requested in TASK 20 then has the appropriate two directions:

1. If h < delta, the strict clause already supplies a path strictly above h and hence a closed-superlevel witness at h. Equality h = delta additionally consumes the critical-level result.
2. If a closed witness exists at h > delta, choose k with delta < k < h. That same path is strictly above k, contradicting the strict characterization. This direction needs no limiting-path argument.

After constructing the actual topological elder merger, the interface's `elderPartner_iff` can be applied to the chosen lifts using the proved maximum, saddle, nonessential and height-equality facts. Conversely, an interface elder partner on this locus yields that same unique critical quotient point once the topology and lift results are established. The interface is consumed in this last identification; it must not be used to manufacture the closed-level connection in the first place. TASK 22 requires exactly this separation.
