### 1. Why CE⁺⁺ alone cannot remove an ℓ^(1/2) term

For κ=ℓ/r⁴, Proposition CE⁺⁺ gives the pointwise cusp-kernel error
`E(r,κ) <= C r(1+κ)`.
On a moving window `κ0 <= κ <= κ1`, equivalently
`r in [(ℓ/κ1)^(1/4),(ℓ/κ0)^(1/4)]`, direct integration gives

`∫ E dr <= (C/2) ℓ^(1/2)[(κ0^(-1/2)-κ1^(-1/2)) + (κ1^(1/2)-κ0^(1/2))]`.

Thus the first-order CE⁺⁺ estimate is generically **order ℓ^(1/2)** even on fixed positive κ windows. Theorem N's parity cancellation to O(r²) is essential; one cannot obtain global no-ℓ^(1/2) merely by expanding the CE⁺⁺ window.

### 2. Exact sufficient moving-window criterion

Suppose a successor proves a uniform second-order estimate on a moving cusp window of the form

`E2(r,κ) <= C r²(1 + κ^p + κ^(-q))`,  p,q >= 0,

with the same birth/direction envelope integrable uniformly. Using
`r=ℓ^(1/4)κ^(-1/4)`, `|dr|=(1/4)ℓ^(1/4)κ^(-5/4)dκ`, the integrated error is bounded by

`C' ℓ^(3/4) ∫_{κ0}^{κ1} [κ^(-7/4) + κ^(p-7/4) + κ^(-q-7/4)] dκ`.

Therefore it is enough, for κ0=κ0(ℓ)↓0 and κ1=κ1(ℓ)→∞, that

- small-κ tail: `ℓ^(1/4) κ0^(-(q+3/4)) -> 0`;
- large-κ tail when p>3/4: `ℓ^(1/4) κ1^(p-3/4) -> 0`;
- for p=3/4: `ℓ^(1/4) log κ1 -> 0`;
- for p<3/4: the large-κ contribution is automatically O(ℓ^(3/4)) once the estimate itself is valid there.

These conditions make the **moving-window second-order error o(ℓ^(1/2))**. They are not claims that existing Theorem N has such p,q; its constants currently depend on a fixed compact K.
