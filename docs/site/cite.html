The research website

Use main’s citation metadata for this public guide and reproduction surface. GitHub’s “Cite this repository” menu supplies APA and BibTeX formats.

A mathematical result

Find the result in Math-’s current proof index, then cite its exact proof, full commit and the review you used. Preserve the authorship and hypotheses stated by that object; a repository maintainer is not automatically every proof’s author. Math- has its own citing guide and citation metadata; follow them for Math- objects.

A tool or data artifact

Name the package or artifact, its version or commit, and its own citation guidance. query- identifies source bytes; it does not certify the mathematical claim they contain.

EXACT SOURCES

Give a future reader a fixed point.

Use a commit permalink for the content you read. Branch links such as main can change. Record the repository, complete Git commit and file path; include a SHA-256 or artifact identifier when the source provides one.

A source reference locates bytes. Add the source’s own authors, title and publication details when preparing a bibliography. A review should be cited separately when your argument relies on that review’s scope.

No DOI or tagged-release version is declared in main’s citation metadata (as read on 8 October 2026: CITATION.cff at main 30e5cf5c has no doi or version field, and the repository has no tags or releases). Use a commit reference now. A future archive deposit must supply its actual identifier before a DOI is advertised. Citation and archival identifiers do not establish scientific acceptance.
