THE SIDE24 COEFFICIENT EXAMPLE

One repository. No packages to install.

You need Git and Python 3.10 or later, and internet access for the source download. The calculation and its tests then run offline using Python’s standard library. Choose a new directory named side24-replay.

This shallow checkout avoids downloading the repository’s full Git history. The explicit commit below fixes the example even when the default branch advances.

git clone --depth 1 https://github.com/d6g8k5htny-coder/Math-.git side24-replay
cd side24-replay
git fetch --depth 1 origin f430fdecbb1d8802d8af40419b701f12af87c039
git checkout --detach f430fdecbb1d8802d8af40419b701f12af87c039
python3 -B -S -m unittest discover -s coefficients/side24_v1 -p "test_*.py" -v
python3 -B -S coefficients/side24_v1/coefficient.py

Select the command block above to copy manually. This page does not run commands.

On Windows, use py -3 in place of python3. No GPU, API key, account, or numerical package is needed.
