# Architecture Interface and Canvas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish an additive Astro reader of pinned graph and explicitly public evidence inputs, with source-bound cubic and finite elder teaching views and a verifiable immutable build identity.

**Architecture:** A trusted capture/projection stage produces a public-only input bundle. A hosted offline static build consumes that bundle once; browser tests and publication consume the same assembled output artifact. Original graph and native evidence records retain their distinct scope and authority; the reader is a derived view.

**Tech Stack:** Stdlib Python capture/projection controls; exact Astro/Node/npm candidates and lockfile after hosted verification; vanilla ES modules and Canvas; existing hosted Chrome tooling; GitHub Pages.

**Spec:** [Research architecture design, sections 1/4 and 7](../superpowers/specs/2026-10-08-research-architecture-design.md); [global implementation plan, Tasks 3 and 7](../superpowers/plans/2026-10-08-research-architecture-plan.md); [evidence adapter contract](2026-10-08-architecture-evidence-adapter.md).

## Global Constraints

- Scientific effect is always `NONE`; scientific status authority is exact boolean `false`. Build success, recorded review, source-relative consistency and teaching output do not promote science.
- Preserve source, review, kernel, computation and alignment as five separate axes. Preserve original classifications, records, qualifiers and unknown/stale/unavailable states. The stdin evidence adapter's custody remains `unknown`; the reader cannot convert its `current` applicability into authenticated kernel verification or declaration existence.
- The public graph may display all 49 currently pinned nodes without any guessed Artifact Index or Lean join. Artifact/node/teaching joins require exact reviewed IDs and roles; absence remains unresolved.
- Keep the complete private Artifact Index/source capture outside the public repository and publication bundle. Publish only explicitly allowed rows and columns. No private original packet, raw table, credential or unlisted field is copied into generated assets, logs or failure artifacts.
- Root retained the actual R17 Artifact Index capture and froze its observed metadata, column names, record schema, size limits and public projection boundary in the first-unit contract. Synthetic TEST fixtures exercise that boundary; they do not substitute for the retained real capture or actual public projection delivery.
- Root owns the isolated interface branch and the precise first-unit and runtime-preparation paths recorded in the pickup and amendment. Tests precede implementation, with hosted RED required before product authoring. The earlier source-only checkpoint is superseded operationally by this scoped execution claim. Standing owner authorization creates no additional user-permission checkpoint.
- No project execution or installation on the laptop. Preparation, RED/GREEN, two clean builds and browser execution occur in disposable hosted environments; network is denied during the actual build/test stage.
- PR #317 owns shared site/brand styles, release-key changes and the existing browser harness/tests. Existing `docs/site` generators and release inventory stay owner-controlled until reconciliation after that PR lands. Root currently owns the architecture producer/required-check workflows.
- New public routes use `/main/reader/`. Preserve the complete existing `/docs` publication namespace and `/main/site/*.html` routes. Pages Actions migration and navigation integration require explicit technical coordination with those owners, not renewed owner permission.
- True 500-token retrieval, lease services, routing and broader execution migration remain separate increments. All eight original requirements remain active until their actual end-to-end completion evidence exists.
