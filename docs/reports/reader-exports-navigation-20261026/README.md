# Portable figures and connected research reading

Readers can take a teaching figure into an ordinary image workflow, move through
long research readings without losing the question chooser, and make an exact
source reference directly from a saved source. These changes extend the existing
Library, comparison and Atlas; they do not replace their source authorities.

PNG exports rasterize the existing validated, fully captioned SVG at fixed2×
size. The same generation time, parameters, source identity, scope and readable
citation are retained in PNG international-text chunks. Rasterization uses local
browser fonts, so it promises fixed dimensions and preserved records rather than
identical bytes across platforms. Parameters, display geometry or theme changing
during preparation refuse the old export; failure and retry remain explicit.
SVG and manual citation stay available, with no source retrieval or theorem check.

Research adds small native question/map/source links and a return link around
seven dated readings. It generates these reading aids at runtime, preserving the
historical HTML bodies, dates, source pins and review limits. The oldest source
disclosure gets a stable runtime bookmark that the existing archive revealer
restores on reload. Missing expected markup omits only that reading's enhancement.
Maintained newer-work and Join routes now point at619 with their own as-read date;
539 and earlier boards remain linked as history.

Saved-source references use the existing Cite builder unchanged. Only known
repository, full commit, literal path and actual optional SHA-256 cross over.
Git blobs, review state, authorship and scientific applicability are not inferred.
A literal path outside the builder's narrower contract keeps the source's original
open/export/remove actions and shows an explicit per-entry unavailable note.

The [UI map](UI_MAP.md) describes the full current reader journey. The separate
[checklist](ACCEPTANCE_CHECKLIST.md) records the delivery gates. Actual commands,
exit results, browser reports and engineering findings accompany the release;
no prior release's test or scientific verdict is silently extended to new source.

The existing v24 router archive supplies a real loopback-only read-only status/SSE
API. That historical interface does not establish a current public worker service,
remote authorization, execution control or a reviewed104→49record mapping. Those
integration inputs were requested in605; no fake activity panel or inferred join
was introduced. Separate formal-source bridge and actual AT lanes retain their
own scopes and findings. This stage does not claim the complete autonomous,
spatial, formal or accessibility vision is finished.
