# Current reader experience

This is a navigation map, not an acceptance register or edit checklist.

| Start | What the reader can do | Where evidence lives |
| --- | --- | --- |
| Home | Understand landscapes and persistence, choose a question or exploration | Research readings and source records |
| Explore | Manipulate three teaching models; share settings; export a fully captioned SVG or PNG; read/copy its citation | The figure's original source identity and explicit teaching limits; PNG embeds the same metadata and citation |
| Research | Choose a question, read a dated argument, jump to its exact sources or the reading map, return to questions | Preserved dated cut text, proof/review links and scope disclosures |
| Mathematics | Inspect literal claim scope, recorded dependency routes and source evidence; switch Graph/List or optional3D | Source observation, exact source records and separately qualified formal/review fields |
| Library | Choose current discovery or dated catalog; save exact sources and searches; export/import a local reading list | Each collection's source cut and saved identity; saving acquires no document |
| Saved source → Cite | Open the existing reference builder with its known repository, commit, literal path and optional real SHA-256 | Syntax-checked text/JSON/BibTeX, with verification not performed; unsupported paths stay explicit |
| Compare snapshots | Read literal changes, source pin moves versus blob/byte changes, and coverage limits | Verified current/registry/archive payloads and separate semantic/material identifiers |
| Reproduce / source records | Obtain exact commands and inspect source/review boundaries | Pinned original records; copying a command executes nothing |

Shared behavior includes native links/history, phone layouts, light/dark views,
keyboard operation and print alternatives. Optional3D remains navigation rather
than mathematical evidence. Public pages are read-only. They do not acquire the
local engine's authority to approve proposals, run workers or certify results.
