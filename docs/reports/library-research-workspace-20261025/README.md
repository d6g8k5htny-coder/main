# Universal Law research workspace delivery

This increment advances the owner's interface goal: a newcomer can understand an example, then a serious reader can find a claim, follow recorded dependencies, inspect exact sources/evidence and resume that reading later. The existing Home, Explore, Research and optional 3D Atlas remain in place. This change makes the Library a connected workspace rather than a default jump into an older catalog.

## What changed and why

- **Choose the collection deliberately.** Library navigation opens its entrance. Current-source search is directly reachable and shared current-query URLs reveal the matching controls. The dated catalog and every existing fragment remain available with their dates and source cuts.
- **Keep a source-linked reading list.** Readers explicitly save exact source links or collection-specific searches, reopen/remove/clear entries and move their list by JSON export/import. No browsing history is collected automatically. Up to50 entries/128KiB; unavailable storage remains usable in memory with export. Coordinated cross-tab writes reread the list under Web Locks.
- **Explore actual version history.** A new Compare snapshots view checks publication metadata, registry and selected payload hashes/lengths. It separates source commit-pin movement from blob/byte changes, preserves complete edge-record multiplicity and shows literal parsed-record changes. Full versus material-only source coverage is explicit.
- **Refuse ambiguous input.** Duplicate raw JSON keys, conflicting imported identities, malformed files, digest/length mismatches and forged selections cannot silently replace records. A current observation identical to a retained archive remains selectable under a distinct role. Invalid links require an explicit valid choice to recover.

These are reading and source-consistency capabilities. Saving a link does not acquire its document. Commit-pin movement is not mathematical progress. Changed records do not establish mathematical inequivalence, correctness, acceptance or formal certification.
