## Exact mathematical construction

A declared node is one 0-cell. Each **distinct typed directed edge record** (from, to, relation, required) contributes one **unoriented 1-cell** linking the endpoints. Parallel directed edges and self-loops are separate 1-cells, not deduplicated. No 2-cells, filled triangles, or inferred mathematical proof relations exist in this diagnostic.

- beta0: number of connected components including isolated vertices, computed by exact disjoint-set union.
- beta1: E - V + beta0, the integer first-homology rank of this **one-dimensional graph CW complex**, not of a Gaussian persistence complex.
- Both metrics are computed for ALL typed edges and separately for only the edges explicitly tagged required=true; the full set of declared vertices is used in both.

A nonzero beta1 does **not** imply a directed dependency cycle, proof defect, inconsistency, mathematical obstruction, theorem acceptance, or missing obligation. An unoriented incidence cycle can exist even when the source-bound directional hard gate correctly accepts its directed dependency graph. The diagnostic never interprets classifications, proof labels, review outcomes, or scientific status.

## Dynamic, immutable snapshot comparison

The optional command tools/evidence_topology_diagnostic.py accepts a complete JSON graph path and the required SHA-256 of the exact raw graph bytes; an optional second path and separate SHA-256 produce a before/after comparison. Both sources are authenticated before analysis. Outputs include sorted node and typed-edge additions/removals, changed node attribute IDs, a metadata-change indicator, and exact beta0 and beta1 changes for both edge subsets.

Example usage (replace the angle-bracket placeholders with independently pinned digests):

    python3 -B -S tools/evidence_topology_diagnostic.py --graph GRAPH.json --sha256 <raw-graph-SHA256>

    python3 -B -S tools/evidence_topology_diagnostic.py --graph OLD.json --sha256 <old-SHA256> --compare NEW.json --compare-sha256 <new-SHA256>

The CLI makes no network request, executes no imported proof program, writes no output file, and does not load private scientific captures. Malformed types, duplicate keys or typed edges, unknown endpoints, missing source pins, changed exact bytes and nonregular/oversized inputs refuse with exit code 2 and an opaque error. Successful output is deterministic ASCII JSON; scientific_effect is NONE and scientific_status_authority is false.
