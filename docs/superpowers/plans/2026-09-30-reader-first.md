# Public experience implementation plan

> For agentic workers: use subagent-driven-development with disjoint file ownership; root integrates and publishes.

**Goal:** Give external readers an inviting mathematical front door while keeping rigorous records easy to find and agent coordination concise.
**Architecture:** Existing static HTML/CSS/ES modules on GitHub Pages; preserve source viewer under workspace.html; new local educational models; explicit operational guide.
**Tech Stack:** HTML, CSS, vanilla JavaScript modules; Python standard library and Node built-in tests.
**Spec:** [Reader-first design](../specs/2026-09-30-reader-first.md).

## Global constraints

Preserve scientific sources, STATUS, evidence JSON, exact decimal strings, existing refusal behavior, private sharing and required formal checks. No new framework, scheduler, status registry or automatic scientific promotion. Actual independent technical review does not imply organizational independence.

## Tasks

- Root: rebuild public index/README, relocate source viewer without losing old hashes, connect museum/formal/library navigation; update interaction harness target and add route/link checks.
- Model agent: implement explore.html, local deterministic model module/UI/style and meaningful algorithm/control tests; no edits to root-owned presentation files.
- Workflow agent: write concise current operating guide and update AGENTS/CLAUDE/release/site guidance, replacing stale stop-first routing with direct owner authority and explicit coordinator ownership; preserve historical source documents.
- Delivery agent: add an explicit-input immutable delivery builder and verifier with bounded archive parsing, canonical handoff validation, and adversarial tests; root uses it for this checkpoint.
- Root: integrate, execute affected checks, inspect browser views and keyboard behavior, fix findings.
- Separate reviewer: review final diff, source preservation, algorithm correctness, navigation and policy consistency; execute independent relevant checks.
- Root: one final complete applicable verification, exact-head PR and hosted CI, protected merge, deployed-byte/browser readback, compact immutable R17 delivery/release.

## Review focus

The cone, cubic-gap and finite partition demonstrations explain their own defined examples; they are not continuum certificates or scientific status changes. Keep historical snapshots explicit. Old deep links must still work. No source failures hidden by UI. Claims control integration until handoff; no repetitive source recrawl, self-review credit or stale CI reuse after changed inputs.
