# Persistence universality: research design

The owner's full objective is a reusable universality theorem, audited core
persistence mathematics, critical Lean interfaces, higher homology, marked
point-process limits, fifty distinct blinded field models and five publication
tracks. This increment establishes an executable falsification foundation and
a source-grounded route toward that objective. It does not redefine completion
as finishing this increment.

The program consumes existing theorem, graph, formal, review and numerical
records. It creates no scientific-status register and edits no other actor's
proof, formal, workflow or navigation scope. One new scoped workflow executes
and retains this suite's own controls/pilot. The current explicit request and
repository autonomy delegation authorize implementation; staged Superpowers
approval questions are unnecessary under that authorization.

## Decisions

- Bind the observable to finite ordinary superlevel H0 bars on a connected
  torus; essential and zero bars are excluded. Lifetime density and cumulative
  intensity are different estimands.
- Separate the cubic gap from the radial sampling law. Use exact rational
  pushforward controls to attack the statement that fold type alone implies
  the exponent.
- Preserve actual elder pairing separately from local-candidate counting;
  far/nonlocal short bars can contribute a bounded remainder.
- Build fifty actual finite Fourier model candidates from ten distinct
  spectral mechanisms and five circular coefficient-vector laws. The pilot
  is planar, floating point, explicitly exploratory and has no coefficient
  or continuum confirmation verdict.
- Reuse the existing exact integer H0 computation and independent connectivity
  verification on the quantized pilot grids. This verifies that discrete
  observable only; it does not certify the floating field or its input law.
- Keep prospective blinded experiments unexecuted until each field's theory,
  coupling, approximation, remainder, precision and blinding inputs exist.
- Write the mathematical admission obligations, formal dependency/assumption
  coverage and five paper gates in one program document linked to existing
  authoritative sources. Existing peer findings remain visible.

## Files and validation

Root writes the program, protocol, rational controls and tests. The model worker
writes only the model catalog, sampler, exploratory runner and their tests.
Both use Python's standard library. Run meaningful controls in normal and
optimized modes, generate all fifty laws in a deterministic tiny pilot, verify
every discrete barcode by connectivity and preserve every row/error. A fresh
reviewer assesses source fidelity, statistical scope, sampler laws and code.
Run the existing applicable repository checks and obtain required hosted checks
on the actual proposal commit. Never equate those checks with theorem proof.
