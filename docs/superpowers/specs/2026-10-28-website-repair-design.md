The owner requests implementation and resolution without repeated permission questions. This design uses the existing ESM, native HTML controls, brand palette and static verified-data architecture.

Browser evidence on Main55961773 and the actual published observation confirms: the corner Go-to covers passive source text at320/390px; repeating Reading list after collapsing its already-selected fragment leaves it closed; comparison categories require up to157 next-page activations before a byte-identity difference is reached.

## Chosen approach

Move the unchanged native Go-to disclosure into the existing Research tools strip on all11 current pages. Make that strip sticky and opaque, retaining one compact toolbar rather than adding another. Its menu opens downward in a bounded scroll area; scripted opening aligns the toolbar into view before measuring. Native links/Formal stay usable without scripts. Replace the old outside-focus hiding rule with ordinary unobscured toolbar and anchor clearance.

Repeated eligible same-document fragment activation opens every disclosure ancestor through the existing reader-shell function before native navigation. Preserve native history/default navigation; ignore prevented/modified/new-tab/download/external/different-query actions. Do not move focus programmatically or close unrelated disclosures.

Compare adds a labelled native category selector derived from the exact existing category arrays. All categories remains the default; category changes reset pagination, preserve source selection/record identity/multiplicity, retain selector focus and announce the displayed count. Empty categories remain explicitly readable. Changed/refused observations clear the category state. No new source acquisition, filter meaning, URL selection contract or scientific inference.

Alternatives considered: footer padding cannot prevent mid-document obstruction; hiding/repositioning a floating button still hides or covers content; rebuilding the application/backend would expand risk and invent unavailable worker joins. A shared existing toolbar and small reader/controller changes address the actual causes.
