# Current research site and mathematical atlas

Owner request: maintain every public GitHub Page, incorporate project advances, provide a dedicated interactive mathematical equation/dependency worktree, and update automatically. Standing authorization covers design, implementation, review, integration and deployment. Scientific effect NONE.

## Outcome

Visitors can distinguish current repository observations from preserved historical reading cuts; discover all current public source files; search equations and inspect their exact source; and traverse the actual required and contextual dependency graph. Home, Explore, Research, Library and Dependencies form the five primary destinations. All other site pages link to this current view.

## Source and generation

A standard-library static site generator resolves public `main` and `Math-` default-branch commits once per build, reads complete Git trees and required source bytes at those immutable commits, verifies Git blob identities and SHA-256, and publishes `current.json`. The payload includes observation time, both source commits, source file inventory, exact source references, the unmodified downstream GRAPH and its source identity, and equations extracted verbatim from a bounded list of current analytic proof sources. Every equation records path, lines, exact text, hash and commit. Inventory paths in legacy, quarantine, recovery, scratch and private operational material are excluded from public discovery. Existing public source snapshots are not rewritten.

The generator fails before publishing when a tree is truncated, a required source is missing, bytes disagree with the Git blob, or graph edges refer to absent nodes or required edges cycle. It never executes fetched code, infers reviews or promotes claims. Proof index, STATUS and research guide remain pinned source links. Graph classifications are reported verbatim; absent equation, formal receipt or alignment metadata is explicitly not recorded. Equations extracted from another source are an independent source collection; the UI does not invent logical edges between them and the downstream graph.

Research remains script-free: the generator inserts equivalent current navigation and source metadata into a marked section. The graph can progressively expand dependencies/dependents, collapse to focus, reset, zoom, and navigate Back/Forward. A minimap explicitly depicts only the loaded neighborhood. ## Automatic publication

A dedicated GitHub Actions workflow builds on main pushes, every 30 minutes and explicit dispatch. It checks out one main commit, runs generator controls and site release validation, downloads public source data, renders the generated current section and publishes a Pages artifact with immutable source metadata. It has read-only contents access and only the Pages/OIDC permissions required for deployment; scheduled runs cannot write repository branches. Concurrency serializes publication and a failed refresh leaves the preceding deployment intact. Pages settings must be verified before switching the deployment source to Actions. Existing required PR checks and substantive review still govern the source change.

## Evidence required

Negative controls cover truncated inventories, wrong blob, missing sources, graph dangling/cyclic required edges, unsafe paths, hostile equation text and absent fields. Browser checks cover equation selection, node traversal, progressive expansion/collapse, minimap loaded boundary, Graph/List parity, static no-JavaScript pages, query reload, keyboard focus, light/dark desktop/mobile, refusal and stale states. Two offline builds from identical payload bytes must produce identical outputs before deployment consumes that artifact. Full existing public-shop checks and historical cut identity checks must pass. Hosted workflow success and public byte readback are required to claim deployment. A local generated artifact alone is not completion.
