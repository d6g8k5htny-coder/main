# Atlas live controls accessibility repair

The existing verified Atlas, source inspector and native controls remain the interface. This bounded release repairs View's inherited disabled accessibility state and equation-search event churn. A reader must retain the URL/viewport View choice, select only exact matching excerpts, and hear the final result count after typing stops. Missing source mappings remain explicit.

Approaches considered: wholesale adoption of Cursor's `aadd04e4` assist would also rewrite historical renderers and is outside this release; debounce alone leaves repeated option destruction and stale selection risks. The chosen approach replaces the initially disabled View with an enabled equivalent after source admission, reconciles equation options by stable excerpt ID, updates the visible count immediately, and publishes a separate concise atomic announcement after 500ms of quiet. This is an engineering decision under the user's continuing implementation authorization. Cursor's observation and assist are attributed; this is a new implementation, not acceptance of that branch.

All count requests, including unchanged numeric counts, restart the announcement timer so the final query can announce after a key flush. Pending messages are replaced on input/history and suppressed while hidden; returning publishes only current state. Do not add motion or production dependencies. No source-loader, admission, graph, formal authority, historical renderer, mathematical source or security changes.
