## Approach
Implementer choice under delegated authorization: retain native HTML/modules, source admission and URL contracts. A new framework/backend would add no needed authority; a search redesign would duplicate existing verified search. An additive module imports the existing currentSnapshot promise once, reveals existing current search, and attaches explicit Save controls to admitted/current and hash-verified catalog results. No loader, builder, graph or mathematics changes.

## User experience
- Library hero offers Search current sources, Search dated catalog, and Reading list. Current source discovery remains visibly a source observation with its acquisition legend. Static complete inventory remains a no-JS path.
- Current-search fragment and nonempty source-q links reveal the existing disclosures; explicit navigation focuses the actual ready search input, or its visible enclosing summary while unavailable. Background readiness never steals focus after another reader action.
- Readers explicitly save an exact source link or a collection-specific query. No automatic tracking. Current and dated searches keep separate parameters and labels; replay queries against the next admitted observation, not frozen results.
- Reading list is collapsed when empty, with an explicit empty state. Up to50 entries; browser-local persistence, remove/clear, JSON export/import. Imports are additive and fully validated before any mutation. Conflicting identity metadata, malformed/oversize/unsafe data or capacity overflow leave the list unchanged.
- No external URL is imported. Source URLs are reconstructed from allowed repository/commit/path; query URLs are reconstructed against this Library. Imported identities remain reader-supplied notes, not newly verified custody.
- Storage access/write refusal keeps a usable in-memory list and export with visible status; unreadable existing storage is preserved and never silently overwritten. Cross-tab changes are checked before mutation to avoid lost updates.

## Integrity and presentation
Preserve every statement, class, source pin, exact hash/number, refusal and generated block. Git blobs never become SHA256. Saving establishes no document acquisition, review, applicability, acceptance or certification. Render inert text/native links only. Existing navy/blue/gold variables,44px controls, keyboard focus,320px text reflow, dark/print/no-JS. No telemetry, global single-key shortcuts, new dependencies, accounts or backend.
