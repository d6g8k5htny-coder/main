## Interface

Load/compare/retry with visible awaiting/running/refused/completed states; no silent fallback to another selection. Share selection through validated URL parameters. Native keyboard, narrow phone layout, dark/light, reduced-motion, noJS static inventory path.

## Trust and coverage
Verify current metadata→raw current payload and history-manifest digest→raw registry→each selected payload descriptor. Exact byte bounds, safe same-origin paths and explicit supported versions. Reject invalid metadata/hash/length/duplicate IDs and publication mismatch. This is a same-origin hash chain, not authenticated remote source custody or durable receipt replay. Full schema1 inventory comparison is permitted. Material-only schema2 source inventory is unretained: comparing coverage must say incomparable, never deleted. Nodes match literalID, fields compare canonicalJSON with array-order/types preserved; edges are complete-record multisets, not invented identities. Record changes do not establish mathematical inequivalence, acceptance, correctness or progress. Use supplied labels/IDs only; no inferred titles.
