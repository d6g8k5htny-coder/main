\section*{Status of this draft (for the author; remove before submission)}

\begin{itemize}[leftmargin=1.5em,itemsep=2pt]
\item \emph{What this is.} Checkpoint draft~1 of 13 October 2026, an author-side assembly of the proofs that the V3 main text cites, written as numbered statements with proofs.
  \begin{itemize}[leftmargin=1.2em,itemsep=1pt]
  \item Every statement and display is mapped to its source in the separate file \path{CONCORDANCE.md}.
  \item That file also lists each correction applied, each step added, and each issue found during assembly.
  \item The draft has not yet been read as a whole, by the author or by anyone else.

\item \emph{Part I} (\S\S\ref{sec:setting}--\ref{sec:rate}) follows the main text's proof of Theorem~2.1 and of the correction (2.10). \emph{Part II} (\S\S\ref{sec:remainder}--\ref{sec:ctwo}) states the results behind Theorem~2.3. Its proofs are given in full or condensed, as \path{CONCORDANCE.md} marks for each.
\item \emph{Author correction.} The elder mark is defined through the maximin connection level (Definition~\ref{def:selection-mark}). The two-sector formula of the 1~August supplement required $\mathfrak m_f(u_+,u_-)<h$, but the segment through $S$ gives $\mathfrak m_f(u_+,u_-)\ge h$, so that mark was identically zero as written.
\item \emph{Open issues found during assembly}, with details in \path{CONCORDANCE.md}. In the selection chain of \S\ref{sec:selection}:
  \begin{itemize}[leftmargin=1.2em,itemsep=1pt]
  \item the three witness regions should be measured from one centre;
  \item same-component and same-maximum self-attachment differ;
  \item the Gaussian factor of the fixed-distance count (main text (3.17)) is shown only for compact marks;
  \item the singular-near envelope needs the value-window constraint and a separate argument near $c=0$;
  \item there are gaps of detail in the capture--escape lemmas.
  \end{itemize}
  The selection bound itself, $1-p_r\le Cr^3$ on compact marks, is also proved for every $d\ge2$ and $L>0$ by Theorem~A of \cite{parentP}. The main text can cite that proof.
\item \emph{Review status} is not stated in this supplement. It is given result by result in \S7 of the main text.
\item \emph{References from the main text} still use the numbering of the 1~August supplement. They are updated when this supplement is adopted.
\end{itemize}
