\item \emph{Repairs in draft~2, \S\ref{sec:selection}.} The selection bound $1-p_r\le Cr^3$ on compact marks is Theorem~A of \cite{parentP} (Theorem~\ref{thm:parent-A}) for every $d\ge2$ and $L>0$, and the main text cites it. \S\ref{sec:selection} now gives a complete second proof in $d=3$ (Theorem~\ref{thm:selection-main}):
  \begin{itemize}[leftmargin=1.2em,itemsep=1pt]
  \item the three witness regions are measured from the pair midpoint;
  \item self-attachment is same-maximum self-attachment, and the remaining cases are witnesses by Lemma~\ref{lem:selection-merge};
  \item the fixed-distance count (main text (3.17)) is stated and proved on compact marks, with the conditional pin density;
  \item the singular-near envelope (main text (3.16)) is proved by Taylor's formula with the value window, for every angle (Lemma~\ref{lem:selection-envelope}; the symbolic check is \path{checks/s5_envelope_check.py}). The elimination (B.1), whose denominators vanish at $c=0$, is no longer used there;
  \item the collar count uses (B.1) only where $|c|$ is bounded below, and Hessian collision zeros near $c=0$;
  \item the capture--escape lemmas contain the five local repairs (\S\ref{ssec:selection-escape});
  \item the Morse event under the Palm law is addressed in Remark~\ref{rem:selection-morse}.
  \end{itemize}
