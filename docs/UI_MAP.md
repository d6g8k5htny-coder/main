## Presentation ownership and cascade

`docs/BRAND_STYLE.md` defines the approved navy/blue/gold identity, existing fonts, literal scope labels and distinct evidence-border patterns. `brand/tokens.json` records colors; `brand.css` owns variables, light/dark colors, focus, reduced-motion, forced-colors and print treatment. `style.css` is the legacy global structural base and reset. Later, more specific brand rules intentionally override it.

The compact shared reader shell lives in `brand.css`. Its `:is(.reader-shell, body)` header/tools selectors cover supporting pages even without `.reader-shell`; `.reader-shell` content rules apply to Home, Explore, Research and Workspace. Header and tool links use at least 44px targets. Footer navigation uses three named parent groups, each with a nested `.site-map-links` list. Desktop has three columns; below 640px the first two groups share a row and Records/tools occupies a two-column row beneath. Print returns to compact inline links. The Home footer additionally uses `home.css` for its identity/two-column layout and mobile stacking. Reader media rules stack the header and compact content at 800px; below 360px the five primary links form three/two rows. Earlier 640px and 950px brand rules still apply where later selectors do not override them. `home.css` also has 800px and 440px rules; `current.css` has a 720px Atlas fallback.

The common generated source block is `<!-- CURRENT-SITE:START -->…END`. Its compact disclosure styling lives in the `.current-research-compact` rules of `brand.css` with deliberately higher specificity because `current.css` loads afterward. `current.css` also contains Atlas/source-node styles, so a generic source-panel change can affect those views. `atlas-layout.css` loads last on Dependencies and owns its newer workbench layout. `explore.css`, `museum.css`, `dependencies.css` and `reference.css` retain page-specific layouts.

`reader-shell.mjs` only manages native disclosure visibility for preserved hash targets; it does not build navigation, replace history or change focus. `home.mjs` handles the legacy home section redirects. Normal navigation remains native links; the full footer map is available without JavaScript. Old source-bound IDs, dates, source pins, refusal text and status labels are deliberate content boundaries.

## Local viewing and existing browser entry points

From the source checkout, a local static server is:

```sh
python3 -m http.server 8000 --directory docs
```

Open `http://localhost:8000/site/`. The documented browser suite uses Python Playwright dependencies pinned in `tests/browser-requirements.txt`, packaged Chrome and a real sandbox:

```sh
python3 -B tools/public_shop_browser_check.py --output /workspace/research/reader-polish-20261025/public-shop-browser
python3 -B tools/current_site_browser_check.py --output /workspace/research/reader-polish-20261025/current-browser
```

The public-shop harness covers 1200×900 and 390×844 light/dark entries, reader navigation/history, keyboard focus, source refusals and overflow; additional layout cases use 1280px, 390px and 320px. It records browser executable/version/hash and checkout identity. Its packaged executable is `/opt/google/chrome/chrome`; scratch Chromium adaptation must retain the exact harness change and executable/sandbox setting as documented in `docs/site/README.md:220`. A modified local harness is local evidence, not the official CI replay. Screenshots still require visual inspection. The current-site browser harness is Atlas-oriented and is not necessary to duplicate during this reader reconnaissance.

Focused existing source tests include `tests/test_reader_experience.mjs`, `tests/test_reader_navigation.mjs`, `tests/test_workspace_navigation.mjs`, `tests/test_public_shop_frontend.mjs`, `tests/test_brand_identity.mjs`, and `tests/test_reader_links.py`. Required release/public-shop commands remain in `docs/site/README.md:33`; after site changes the release tool must run before its `--check`, and every rewritten importer must be included. Fresh captures, source-preservation evidence and verification results are recorded separately from this structural map.
