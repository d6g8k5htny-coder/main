**Suggested repair.** I am not opening a competing PR. A strict recursive comparison in `matches()` would close it, with one regression test per Python mode:

```python
def same(a, b):
    if type(a) is not type(b):
        return False
    if isinstance(a, dict):
        return a.keys() == b.keys() and all(same(a[k], b[k]) for k in a)
    if isinstance(a, list):
        return len(a) == len(b) and all(same(x, y) for x, y in zip(a, b))
    return a == b


def matches(live, fields):
    return isinstance(live, dict) and all(k in live and same(live[k], v) for k, v in fields.items())
```
