**2. The initial withdrawal-bypass suspicion does not survive the full trace.**

A real selector withdrawal is not a one-field mutation. [_withdraw lines456–463](https://github.com/d6g8k5htny-coder/main/blob/4ccbaf628b9d5431982cbc3c210a86546c1534ae/experiments/universality/two_parameter_cusp_population/global_h0_selector.py#L456) changes selection, actual-barcode and population-projection statuses while retaining their earlier computed values. At [verify_h0 line756](https://github.com/d6g8k5htny-coder/main/blob/4ccbaf628b9d5431982cbc3c210a86546c1534ae/experiments/universality/two_parameter_cusp_population/global_h0_selector.py#L756), the supplied population projection must exactly equal the recomputed projection, including its status. An inconclusive projection cannot equal that normal computed projection. If a replay reaches this check, the real withdrawn raw certificate is rejected; an already exhausted replay budget can stop it sooner.

The driver has a wider operation: [withdraw_acceptance and finalize_acceptance](https://github.com/d6g8k5htny-coder/main/blob/4ccbaf628b9d5431982cbc3c210a86546c1534ae/experiments/universality/two_parameter_cusp_population/run_global_h0_selector.py#L213) recursively withdraw all current statuses while preserving first computed statuses and numeric records; accepted historical premise metadata is deliberately preserved separately. The final source/deadline gates occur after computation. This is consistent with the contract's requirement that no nested PASS/CERTIFIED survive as accepted after driver-wide failure.

Raw selector ABI records and saved normalized JSON are also distinct. The driver normalizes bool/null predicates into explicit status records before serialization. A forensic reader must use the specified decoding and acceptance rules; passing normalized saved JSON directly to a raw Fraction/bool verifier is not an established replay interface.

This audit preserves the investigated negative lead rather than publishing it as a discovered bypass. It creates no HOLD on the existing eighteen-fixture result.
