# OP-ORG-20260918-v1.0 — Folder naming and template standard

Operational maintenance under R17 and Dylan Roy’s direct instruction. This standard governs navigation and folder structure only.

## Version

Scope: Operations. OP-ORG-20260918-v1.0; additive navigation standard under R17

No scientific disposition is changed by naming or location.

## Root prefixes

Scope: My Drive. 00 entry; 01 active research; 02 legacy; 03 personal; 04 governance; 05 foundations/history; 06 sandbox; 07 accessibility; 90 quarantine

04–07 are occupied. 08–09 remain available; do not renumber occupied roots.

## Folder prefixes

Scope: Managed organizational siblings. Use unique NN_UPPER_SNAKE_CASE prefixes within a parent. Human-readable scope suffixes may follow an em dash.

Numeric uniqueness is local to the parent. Do not rename scientific object identifiers to match folder style.

## Calendar containers

Scope: Year/month folders. YYYY / MM_MONTHNAME; example 2026 / 07_JULY

Six older month containers have been normalized, preserving their IDs and contents.

## Dated intake packages

Scope: Research events and releases. Keep ISO day or date-range prefixes with a descriptive label. These are event identities, not month-only containers.

Retain historical intake names and source paths; use YYYY-MM-DD_LABEL for new single-day packages.

## Identifier exceptions

Scope: Theorem and project tracks. T1–T5, P0.1/P0.2 and other scientific identifiers may retain their semantic names.

Organizational prefixes do not redefine research objects.

## One triage root

Scope: Drive-wide. 90_QUARANTINE_AND_TRIAGE remains the canonical intake and quarantine directory.

Do not recreate UNKNOWN or 90_UNKNOWN trees in research packages.

## Current quarantine

Scope: Triage root. 01_CONFIRMED_DUPLICATES; 02_DEFECTIVE_SCOPE_AND_REPLAY_HOLDS; 03_UNVERIFIED_AND_TRANSPORT

Read the exact Quarantine Index disposition; folder membership is not a general falsity verdict.

## Origin collections

Scope: Triage root. 10_ORIGIN_PRESERVED_REVIEW_COLLECTIONS contains the 13 prior FROM_* trees.

Keeps prior context intact while separating historical source routing from current status buckets.

## Decision work

Scope: Research register. Review Queue tracks active exact review obligations; Quarantine Index records exclusions and restoration tests.

A structural collection index is not another competing scientific review queue.

## Review scaffold

Scope: Existing 15 review containers. Template REVIEW_SCAFFOLD_V1; all 15 live child sets match its six folders.

Use the existing central template; do not recreate matching scaffolds.

## Scaffold children

Scope: REVIEW_SCAFFOLD_V1. 00_REVIEW_INSTRUCTIONS_AND_ACTION_CARDS | 01_DUPLICATE_OR_VARIANT_REVIEW | 02_CONTENT_AND_PROVENANCE_REVIEW | 03_CORRUPTION_OR_READABILITY_REVIEW | 04_CROSS_DEPENDENCY_REVIEW | 05_RETURNED_FROM_REVIEW — RESTORED

Keep name, semantic role and order together in the machine-readable template.

## T4 and T5

Scope: Thematic research tracks. Both have charters, live-state cards and supporting documents. They are not empty placeholders.

Their mathematical gates remain governed by the relevant source and current registers.

## Placeholder rule

Scope: Future empty tracks. Use PLACEHOLDER only when no charter or substantive source exists, and record what is missing.

Folder emptiness alone must not invent a scientific status.

## Historical instructions

Scope: Triage. 90_HISTORICAL_TRIAGE_MIGRATION_INDEX_2026-07-22.md is retained history. Use the current triage start page.

Its empty index and completed migration directions are not current work assignments.

## Archive namespace

Scope: Per-package archives. 99_ is a local archive/vault convention. Preserve established 02_ legacy and 05_ history root identities.

The root and local package namespaces serve different purposes.

## Stable links

Scope: Automation and indexes. Use Drive IDs and original hashes for identity. Paths and names are mutable navigation labels.

Path Changes maps prior snapshot locations to their new paths.

## Rollback

Scope: Every move/rename. Record old/new name, parent IDs, reason and readback. Check expected current state before applying the inverse.

Retain originals and sharing; no permanent deletion.

## Snapshot scope

Scope: Folder Directory / Path Changes. 17 September baseline plus targeted 18 September live metadata. Metadata basis distinguishes each row.

Recomputed descendant paths do not imply a fresh content audit of every source.

## Maintenance

Scope: Future authorized updates. Use targeted folder reads or modification deltas and rerun the structural validator on the affected scope.

No new scheduled automation or hard enforcement service is installed by this standard.

The machine-readable review template is REVIEW_SCAFFOLD_V1.json. The supplied validator checks a saved snapshot; it is not a deployed enforcement or scheduling service.
