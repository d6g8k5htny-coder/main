The insight to retain
Representation invention is the introduction of a useful definition, encoding or method that changes later search. A candidate needs an explicit meaning, a preservation argument where required, and an operational interface: when to use it, the required inputs, and the resulting transformation. Merely naming a pattern is insufficient.
Keep correctness evidence, permission for scoped reuse, empirical usefulness and novelty separate. A conservative definition adds vocabulary; it does not supply a missing estimate. In particular, defining a selected process does not establish equality with a typed process. A proof checker checks derivability relative to its assumptions; a content hash checks identity.

Use this route in future sessions
1. Start at the existing Research Home and register. Search Reusable Operations by the intended action: pin Jacobian, cone integral, Holder, selection bridge, or regular-domain tail.
2. Match the dimension, field, law, coordinate order, measure, mark window and parameter regime that matter for that operation. Missing scope stays unresolved. A fixed-r certificate does not become an all-small-r theorem.
3. Open the exact source and current controlling disposition. Compare its recorded hash using the declared extraction or frozen-body procedure. Historical headings, reading copies and metadata alone cannot establish current mathematical status.
4. Apply only the recorded transformation and its stated premises. Retain exclusions. Negative entries block the specific invalid inference; they do not erase data, ban every similarly named function, or reject a valid result in another dimension.
5. Record a real reuse or matched trial in Operation Trials. If a missing premise blocks progress, use the existing Review Queue with the exact estimate needed. Repeating a theorem statement or review without new evidence is not progress.
Measure whether the representation earns its place
Use prospective problems excluded from construction, frozen library snapshots, identical solver settings and matched budgets. Compare a fixed library, a lemma cache, and scope-aware operations. Report verified solved counts and scope errors before speed. The present 26 scope/retrieval controls are exposed development tests, not held-out usefulness trials.
For paired cost measurements, use G_n(R) = sum_j [C_L^B(x_j) - C_(L+R)^B(x_j)] - C_acquire(R) - C_maintain(R). Predeclare one cost unit or retain separate cost vectors; charge timeouts/failures by a fixed rule and report them separately. Include retrieval, checking and integration overhead. Do not silently discard failed tasks.
Operation Trials is intentionally empty. It provides fields for problem and library hashes, split, arm, budget, environment, verified outcome, costs and run evidence. Promote active retrieval only after valid use and measured benefit; retirement removes an item from default retrieval while preserving its evidence and reopening path. No item is assigned positive or negative gain by anecdote.
