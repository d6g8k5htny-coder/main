1. PURPOSE


An agent must not be trusted to have chosen the correct retrieval endpoint. It
must PROVE it, against known bytes, before it touches a frozen mathematical
target. This object is that proof.


Two Anthropic sessions (claude-opus-4-8 on 2026-07-27, claude-opus-5 on
2026-07-28) each concluded that exact byte reproduction was impossible through
the document interface. Both were wrong. A third Anthropic session
(claude-opus-5, CL-AUD-LSDER036-20260727-01) performed it correctly the same
week. Verbal confidence did not distinguish them. An executable canary does.

4. WHY THE TWO HASHES DIFFER — THE MEASURED CONVERSION LOSS


Converting the source bytes INTO a Google Doc is lossy. Measured, this run:


  FEATURE                          SURVIVES DOC CONVERSION?
  tab characters (U+0009)          NO — each replaced by 8 spaces (2 tabs lost)
  blank lines                      NO — each blank line doubled
  trailing spaces                  YES
  NFD combining sequence           YES — remains distinct from NFC
  ASCII apostrophe and quotes      YES — no smart-quote substitution
  Unicode math (lambda, nabla, integral, em-dash)  YES
  equation-like ASCII text         YES
  marker lines                     YES — exactly one standalone occurrence each


THE BINDING CONSEQUENCE:


  A Google Doc is a FAITHFUL and DETERMINISTIC carrier for a body that was
  authored in, or already stored as, a Doc — its text/plain export is stable and
  reproduces the declared hash indefinitely. LS-DER-023-v1.0 is the worked proof:
  13,795 bytes / SHA-256
  30270eb7ee793462f66d9f280ef620b0598f17edbaab7ee256c1a7e1cf50b791, reproduced
  exactly on 2026-07-28.


  A Google Doc is NOT a faithful carrier for bytes that pass THROUGH the
  conversion. Any object whose semantics depend on tabs or on exact blank-line
  structure — source code, TSV, indentation-sensitive formats, JSON with
  significant whitespace — MUST use a raw carrier. This is now measured, not
  asserted.


5. DECOYS DELIBERATELY EMBEDDED


DECOY A: a space-padded line "  BEGIN_FS2_CANARY_BODY  " OUTSIDE the body.
  Under exact full-line equality it does not match. Under a strip()-based
  matcher it produces two begin candidates and MUST fail closed. An
  implementation that silently picks one is non-conformant.
DECOY B: the begin token inside a prose sentence, outside the body.
DECOY C: the end token inside a prose sentence, outside the body.
DECOY D: the end token inside a prose sentence INSIDE the body — a
  substring-first-match extractor truncates here and produces the wrong hash.


These reproduce, deliberately, the exact defect found in LS-DER-023-v1.0, whose
freeze policy says "strictly after BEGIN_TBG3A_FROZEN_BODY" while that token
occurs twice — once in the policy prose and once as the real marker line.
Substring-first-match on LS-DER-023 yields a 13-byte object.

7. ACCEPTANCE TEST — BINDING


An agent may claim EXACT-HASH REVIEW capability only after publishing, in its
capability declaration, all six of:


  C1  FS2-CANARY-001-RAW canonical body bytes  = 475
  C2  FS2-CANARY-001-RAW canonical body SHA-256 = dbe69a65…30a2f (full)
  C3  FS2-CANARY-001-DOC canonical body bytes  = 492
  C4  FS2-CANARY-001-DOC canonical body SHA-256 = e37c53be…534f07 (full)
  C5  correct FAIL CLOSED on at least the four marker mutations in section 6
  C6  the exact tool action and export MIME type used for each carrier


Failure on any item produces exactly this verdict and nothing else:


  CANNOT PERFORM EXACT-HASH REVIEW — RETRIEVAL CANARY FAILED


The agent MUST NOT proceed to state any conclusion about a mathematical target,
including a negative or "cannot verify" conclusion about that target. A canary
failure is a statement about the agent, not about the object.

9. NON-EFFECTS


This object promotes nothing, closes no gate, approves no interface, and creates
no independence credit. Passing the canary establishes only that an agent can
retrieve bytes correctly. It says nothing about whether that agent's mathematics
is right, and a passing canary must never be cited as partial evidence for a
mathematical verdict.
