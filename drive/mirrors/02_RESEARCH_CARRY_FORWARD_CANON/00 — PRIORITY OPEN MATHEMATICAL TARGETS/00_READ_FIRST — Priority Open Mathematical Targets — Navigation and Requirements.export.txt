STANDARD NAVIGATION INSIDE EVERY TARGET
Keep 00_READ_FIRST at the target-folder root. As work accumulates, create numbered folders or files using this order:
01_SOURCE_LINKS_AND_OBJECT_CARD — exact laws, marks, definitions, domains, source IDs, and precedence.
02_ACTIVE_DERIVATIONS — current proof attempts, lemmas, dependency chains, and explicit assumptions.
03_COMPUTATION_AND_TESTS — code, immutable snapshots, manifests, numerical diagnostics, and outputs.
04_REVIEW_AND_FALSIFIERS — adversarial reviews, counterexamples, failed routes, kill logs, and unresolved objections.
05_PROMOTION_PACKAGE — final theorem statement, proof, machine successor, verifier receipt, and proposed ledger entry.
99_ARCHIVE_RESPONSES — superseded AI responses and historical candidate packages retained for provenance.
Do not create authority by folder position. A polished or newer document remains derivative until formally promoted.


MANDATORY INFORMATION FOR EVERY CONTRIBUTION
• Artifact ID, model/reviewer, creation date and time.
• Exact target and priority code.
• Files consulted, with IDs or URLs.
• Mathematical object card: measure, conditioning, marks, domain, scaling, orientation, and multiplicity.
• Claim type and current grade.
• Full dependency chain and imported assumptions.
• What is genuinely new versus reformulated.
• Proof, computation, or evidence supplied.
• Known failure modes and decisive falsifiers.
• Relation to existing canon and recommended status.
• Canonical impact: NONE / PROPOSED / PENDING VERIFICATION / APPROVED.


PROMOTION GATE
A target leaves this open-priority hub only when one of the following is recorded:
1. PROVED — complete proof under the exact object card, independently reviewed, machine dependencies updated when applicable, verifier tests passed, and governing ledger entry approved.
2. FALSIFIED — decisive counterexample, lower-order obstruction, failed uniformity, or incompatible computation recorded with reproducible evidence.
3. RESCOPED — original target shown to be misstated; corrected theorem and object card explicitly registered.
4. BLOCKED — required definitions or data unavailable, with the missing inputs listed precisely.
