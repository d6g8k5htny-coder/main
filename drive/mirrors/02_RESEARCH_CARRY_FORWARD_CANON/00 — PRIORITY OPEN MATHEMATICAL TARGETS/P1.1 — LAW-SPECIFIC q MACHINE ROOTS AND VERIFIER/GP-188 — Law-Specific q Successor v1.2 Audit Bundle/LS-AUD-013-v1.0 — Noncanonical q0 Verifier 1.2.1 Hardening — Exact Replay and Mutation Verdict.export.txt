4. STRICT JSON BOUNDARY


The predecessor used ordinary json.loads. Python's standard parser accepts repeated object keys and keeps the last value. Thus a byte stream containing two MORSE_SMALE_R0 keys could be presented differently to a human reviewer and to the verifier.


The successor uses object_pairs_hook and rejects any repeated key with


    DUPLICATE_JSON_KEY:<key>


before verify() is entered.


The full predecessor machine was mutated by inserting a second MORSE_SMALE_R0 key. Running the successor returns code one and writes a deterministic failure report containing


    INPUT_REJECTED:DUPLICATE_JSON_KEY:MORSE_SMALE_R0.


No semantic root report is generated for the malformed input. The attack cannot launder a terminal status through last-wins parsing.


5. EMPTY ALTERNATE ROUTE REPAIR


The predecessor route minimizer selected the route with the fewest blockers. An injected route


    {"route_id":"AAA_EMPTY","dependencies":[]}


therefore had zero blockers and could bypass an open route such as MORSE_SMALE_R0.


The successor requires:


- dependency_routes is a list;
- each route is an object;
- every route has a nonempty route_id;
- route IDs within one claim are unique;
- dependencies is a list;
- dependencies is nonempty;
- every route dependency is a claim, not an object or unknown ID.


The mutation now produces


    Q_TYPED_MS_RATE:ROUTE_EMPTY_DEPENDENCIES:AAA_EMPTY


and makes the machine invalid before root minimization can create a bypass.


6. CYCLE-VALIDITY DECISION


The predecessor recursion returned CYCLE:<claim> as a blocker but left report.valid=true. CL-AUD-218 classified this as a minor policy gap.


The successor adopts the following explicit policy:


    ANY DIRECTED CYCLE ACROSS BASE OR ALTERNATE-ROUTE CLAIM DEPENDENCIES IS STRUCTURALLY INVALID.


A deterministic DFS collects unique directed cycles and reports


    CYCLE:A->B->...->A.


A self-dependency mutation on EXACT_GAP_JACOBIAN therefore makes report.valid=false with


    CYCLE:EXACT_GAP_JACOBIAN->EXACT_GAP_JACOBIAN.


Rationale:
A dependency cycle is malformed evidence architecture. It is not a scientifically meaningful open state and should fail before promotion logic.


The unmodified predecessor machine is acyclic, so this policy does not change its valid root reports.
