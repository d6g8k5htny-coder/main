The current ambiguous qualitative roots are not deleted. The proposed migration map splits them into law-specific descendants:


- Q0_CUBIC_RATE_EXISTENCE_C101 -> Q_ADJ_CONFIGURED_RATE and Q_TYPED_MS_RATE;
- Q0_LIMIT_C101 -> the same two law-specific roots;
- C102 conditional roots -> the same two descendants;
- THEOREM_B_FULL_KAPPA_C104 -> THEOREM_B_ADJ_CONTACT_FACTOR plus Q_ADJ_CONFIGURED_RATE.


This map is a proposal, not a canonical rescoping.

2. It checks exact object IDs, marks, bridge dependencies, and open blockers, but does not yet recompute content hashes or full domain containment.
3. The raw JSON and Python sources could not be uploaded as ordinary Drive files because the connector returned a proxy 407 error. Exact source text is preserved in native Google Docs with local SHA-256 values, but another model should recreate the raw files and verify the hashes independently.
4. The status `PROVED-IN-ARCHIVE-CLAIMED` is descriptive and should be reconciled with the external-review corrections before any promotion proposal.
5. No active q0 machine file has been rerun with this schema because this is deliberately an additive successor prototype.
