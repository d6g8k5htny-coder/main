# Quantitative saddle-exit and sink-capture blocks


## Executive result


The endpoint gap identified in the anisotropic trapping-corridor proof can be reduced to explicit, machine-checkable inequalities.


This file proves two deterministic lemmas for a planar C^1 vector field:


1. a quantitative saddle cone lemma ensuring that a selected unstable branch leaves a hyperbolic saddle through a prescribed side while staying in a controlled cone;
2. a quantitative sink ball lemma ensuring that a neighborhood of a negative-definite equilibrium is forward invariant and every trajectory in it converges exponentially to the equilibrium.


A third proposition glues these blocks to the existing central-strip inequality. The resulting certificate is fully deterministic and does not rely on the phrase “hyperbolic continuation preserves the phase portrait.”


For the normalized cubic–quartic q0 flow, every quantity in the certificate is an explicit polynomial or eigenvalue expression in the finite-r jets. The remaining task is to choose one jet-dependent threshold and verify that its pair-Palm complement has cubic mass. GP-DER-043 supplies that probabilistic reduction once the threshold has polynomial growth.


This file does not claim that the complete jet inequalities hold on the full theorem domain. It supplies the missing endpoint theorem format and exact constants for checking a proposed event.


## 1. Notation


Let F:R^2->R^2 be C^1 near an equilibrium p, F(p)=0. Write


    J_p=DF(p).


All vector and operator norms are Euclidean. For a radius rho, define the Jacobian variation


    omega_p(rho)
      = sup_{||x-p||<=rho} ||DF(x)-J_p||_op.


For a C^2 field one may use the computable bound


    omega_p(rho) <= L_p(rho) rho,


where


    L_p(rho)=sup_{||x-p||<=rho} ||D^2F(x)||_op.


The q0 scaled flow is a gradient field in the scaled variables, so its endpoint Jacobians are symmetric. The abstract lemmas below use symmetry only to obtain an orthonormal eigenbasis and simple spectral constants.


## 2. Quantitative sink ball


### Lemma 2.1 — invariant contracting ball


Suppose J_p is symmetric and


    lambda_max(J_p) <= -lambda


for some lambda>0. If rho>0 satisfies


    omega_p(rho) <= lambda/2,


then the closed ball


    B(p,rho)


is forward invariant. Every solution starting in the ball satisfies


    ||x(t)-p|| <= exp(-lambda t/2)||x(0)-p||


and converges to p. The ball contains no other equilibrium.


### Proof


Set z=x-p. Since F(p)=0,


    F(p+z)=∫_0^1 DF(p+theta z)z dtheta.


For ||z||<=rho,


    z·F(p+z)
      =∫_0^1 z^T J_p z dtheta
       +∫_0^1 z^T[DF(p+theta z)-J_p]z dtheta
      <= -lambda||z||^2 + omega_p(rho)||z||^2
      <= -(lambda/2)||z||^2.


Therefore


    d/dt ||z||^2 <= -lambda ||z||^2.


The vector field points strictly inward on the boundary, proving invariance, and Gronwall gives the displayed contraction. A second equilibrium would produce a constant trajectory contradicting strict decay. QED.


### Computable corollary


If L_p(rho)<=L and


    rho <= lambda/(2L),


then the lemma applies. A conservative self-consistent choice is


    rho_p = min(rho_chart, lambda/(2L_chart)),


where L_chart bounds ||D^2F|| on a larger declared chart ball.


## 3. Quantitative saddle cone


Let p be a hyperbolic saddle. Assume J_p is symmetric with eigenvalues


    lambda_u>0>lambda_s


and corresponding orthonormal eigenvectors e_u,e_s. Orient e_u so its first coordinate points toward the desired exit side. In eigen-coordinates


    x-p = u e_u + v e_s,


write


    F(x)=lambda_u u e_u + lambda_s v e_s + N(u,v),


where N(0,0)=0 and DN(0,0)=0.


### Lemma 3.1 — invariant unstable cone


Fix kappa>0. Let rho>0 and epsilon=omega_p(rho). Suppose


    epsilon sqrt(1+kappa^2)(1+kappa)
      < kappa(lambda_u-lambda_s),                 (CONE-1)


and


    epsilon sqrt(1+kappa^2) < lambda_u.           (CONE-2)


Then the cone segment


    K_{kappa,rho}
      ={(u,v): 0<=u, |v|<=kappa u,
                 u^2+v^2<=rho^2}


is forward invariant except through its outer circular boundary. Along every nonzero orbit in the cone,


    udot >= [lambda_u-epsilon sqrt(1+kappa^2)]u>0.


The positively oriented local unstable branch lies in this cone for sufficiently small positive time and exits the radius-rho ball through the cone's outer boundary.


### Proof


Because ||DN||<=epsilon on the rho-ball and N(0)=0,


    ||N(u,v)||<=epsilon||(u,v)||.


On the upper cone boundary v=kappa u, define g=v-kappa u. Then


    gdot
      =lambda_s v+N_s-kappa(lambda_u u+N_u)
      =-kappa(lambda_u-lambda_s)u+N_s-kappa N_u.


The error satisfies


    N_s-kappa N_u
      <=(1+kappa)||N||
      <=epsilon(1+kappa)sqrt(1+kappa^2)u.


Condition CONE-1 gives gdot<0, so the field points into the cone. The lower boundary is identical after replacing v by -v. Moreover


    udot=lambda_u u+N_u
      >=lambda_u u-||N||
      >=[lambda_u-epsilon sqrt(1+kappa^2)]u,


which is positive by CONE-2. Thus a nonzero orbit cannot return to the vertex or exit through the cone sides; it exits through the outer boundary. Hyperbolicity gives a unique local unstable manifold tangent to e_u, so its positive branch enters every fixed cone about e_u for sufficiently small time. QED.


## 4. Conversion to a prescribed physical exit face


Let the first coordinate be X. Orient e_u so


    (e_u)_X <= -nu


for some nu>0. Because e_s is a unit vector,


    |(e_s)_X|<=1.


Inside the cone |v|<=kappa u,


    X-X(p)
      =u(e_u)_X+v(e_s)_X
      <=-(nu-kappa)u.


Therefore, whenever


    0<kappa<nu,


reaching u=u_* guarantees


    X <= X(p)-(nu-kappa)u_*.


The transverse coordinate Y satisfies


    |Y-Y(p)|
      <= ( |(e_u)_Y|+kappa )u_*.


### Corollary 4.1 — section crossing


Assume Lemma 3.1 and kappa<nu. For any desired longitudinal displacement sigma satisfying


    u_*:=sigma/(nu-kappa),
    u_* sqrt(1+kappa^2) <= rho,


and any strip half-width W satisfying


    W >= ( |(e_u)_Y|+kappa )u_*,


the selected unstable branch crosses the section


    X=X(p)-sigma


before leaving the rho-ball and does so with


    |Y-Y(p)|<=W.


This is the explicit saddle-to-central-strip handoff.


## 5. Central-to-sink gluing proposition


Let S=(1/2,0) and M=(-1/2,0). Fix endpoint widths sigma_S,sigma_M in (0,1/2) and a strip half-width W>0. Define the central rectangle


    R_c={-1/2+sigma_M <= X <= 1/2-sigma_S,
         |Y|<=W}.


Assume:


E1. The selected S branch crosses the right section X=1/2-sigma_S with |Y|<=W, as certified by Corollary 4.1.


E2. The horizontal strip |Y|<=W is forward invariant while |X|<=1/2.


E3. There is eta>0 such that


    Xdot <= -eta


throughout R_c.


E4. The left section


    {X=-1/2+sigma_M, |Y|<=W}


lies inside a contracting M-ball B(M,rho_M) supplied by Lemma 2.1; equivalently it is sufficient that


    sqrt(sigma_M^2+W^2) <= rho_M.


### Proposition 5.1 — deterministic local capture


Under E1–E4, the selected unstable branch of S enters R_c, remains in the strip, reaches the left section in time at most


    (1-sigma_S-sigma_M)/eta,


enters B(M,rho_M), and converges to M. No other equilibrium lies on the branch segment or inside the M capture ball.


### Proof


E1 supplies entry. E2 prevents exit through the horizontal faces. E3 makes X strictly decreasing and excludes critical points in R_c. The branch therefore reaches the left face within the stated time. E4 places the crossing point in the invariant contracting ball, and Lemma 2.1 gives convergence to M and uniqueness of the equilibrium there. QED.


This proposition supplies exactly the deterministic implication E_r subset A_r that was missing from the earlier qualitative continuation argument, once its hypotheses are verified for a stated jet event and a stated remainder bound.


## 6. Specialization to the normalized cubic–quartic q0 flow


The explicit scaled flow is


    Xdot = X^2-1/4+aXY+(w/2)Y^2+r P4_X,


    Ydot = (q/r)Y+(a/2)(X^2-1/4)+wXY+(z/2)Y^2+r P4_Y,


with P4 as in GP-DER-019 and GP-DER-037.


The endpoint Jacobians are exactly


    J_M=
      [[-1+r c40/12, -a/2+r c31/12],
       [-a/2+r c31/12, q/r-w/2+r c22/8]],


    J_S=
      [[ 1+r c40/12,  a/2+r c31/12],
       [ a/2+r c31/12, q/r+w/2+r c22/8]].


These are symmetric. Thus:


- the saddle eigenvalues, unstable direction, and leftward component nu are exact algebraic functions of the nine jets and r;
- the sink contraction rate lambda_M is minus the largest eigenvalue of J_M;
- the Jacobian-variation functions omega_M and omega_S are bounded from the explicit second derivatives of the scaled vector field.


For the quartic truncation, D^2F is affine in X,Y. On any declared endpoint ball it therefore has a finite explicit polynomial bound in


    |a|,|w|,|z|,r|c40|,r|c31|,r|c22|,r|c13|,r|c04|.


No qualitative structural-stability theorem is needed to evaluate E1–E4.


### 6.1 Explicit second derivatives


For reference, the nonzero second derivatives of the X channel are


    partial_XX Xdot
      =2+r[c40 X+(c31)Y],


    partial_XY Xdot
      =a+r[c31 X+c22 Y],


    partial_YY Xdot
      =w+r[c22 X+c13 Y].


The Y channel derivatives are


    partial_XX Ydot
      =a+r[c31 X+c22 Y],


    partial_XY Ydot
      =w+r[c22 X+c13 Y],


    partial_YY Ydot
      =z+r[c13 X+c04 Y].


Here the displayed quartic coefficients follow by differentiating the explicit P4 derivatives; the equality of mixed terms reflects the gradient structure.


A conservative Frobenius bound on a rectangle |X-X_p|<=rho, |Y|<=rho is obtained by bounding each displayed entry in absolute value and summing its square. This yields an explicit L_p(rho) for Lemmas 2.1 and 3.1.


### 6.2 Existing central conditions


GP-DER-037 already supplies E2 and E3. For a contraction parameter mu,


    W=F/mu,


where


    F=|a|/8+r|c31|/48,


and the strip condition


    q/r <= -C_mu


makes |Y|<=W invariant. Its longitudinal bound gives E3 whenever


    E_X(W)<sigma(1-sigma)

Thus the only genuinely new finite-Q4 checks required by Proposition 5.1 are:


- E1: the cone-certified S exit reaches X=1/2-sigma with |Y|<=W;

The same sigma may be used on both sides, but the proposition allows different endpoint widths if that improves the certificate.


## 7. Algorithmic endpoint certificate


For each typed jet vector and r, the following deterministic algorithm returns PASS or FAIL without integrating a trajectory.


INPUT:


    r, q,a,w,z,c40,c31,c22,c13,c04,
    mu, sigma_S, sigma_M.


STEP A — strip and central transit:


1. Compute F, C_mu, W=F/mu, and E_X(W).
2. Require q/r<=-C_mu.
3. Require E_X(W)<min[sigma_S(1-sigma_S), sigma_M(1-sigma_M)] if one central rectangle is used.


STEP B — saddle exit:


4. Compute J_S, its eigenvalues lambda_u>0>lambda_s, and orient e_u leftward.
5. Set nu=-(e_u)_X.
6. Choose kappa=nu/2.
7. Set the required eigen-coordinate travel


       u_*=sigma_S/(nu-kappa)=2sigma_S/nu.


8. Set


       rho_S=u_*sqrt(1+kappa^2).


9. Bound epsilon_S=omega_S(rho_S).
10. Check CONE-1 and CONE-2.
11. Check the transverse handoff


       (|(e_u)_Y|+kappa)u_* <= W.


STEP C — sink capture:


12. Compute lambda_M=-lambda_max(J_M)>0.
13. Set the required ball radius


       rho_req=sqrt(sigma_M^2+W^2).


14. Bound omega_M(rho_req).
15. Require


       omega_M(rho_req)<=lambda_M/2.


If all checks pass, Proposition 5.1 certifies local capture at M for the truncated flow.


This is intentionally conservative. Failure of the certificate does not imply noncapture.


## 8. Relation to cubic probability scaling


The certificate is suitable for GP-DER-043 if its complement can be confined by a polynomial-growth threshold


    q/r>-C_cap,r(U).


All quantities above are algebraic in the jets except the spectral functions. For symmetric 2x2 matrices, eigenvalues and eigenvector slopes have explicit square-root formulas. On regular type-margin events they admit polynomial/rational majorants. Gaussian tails can remove near-zero spectral margins and abnormally large jets at cost exp(-c/r^2) or another super-polynomial bound after a suitable r-dependent cutoff.


Therefore the intended next proof structure is:


1. define a regular-jet/type-margin event;
2. majorize the endpoint certificate by one explicit polynomial-growth C_cap,r(U);
3. apply GP-DER-043 to obtain O(r^3) for the uncertified typed mass;
4. separately bound the regular-jet complement;
5. transfer from the quartic truncation to the exact field.


This gives a finite list of obligations rather than an appeal to qualitative continuation.
