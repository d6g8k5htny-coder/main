## Executive result


AO48-DER-007's untracked nonlinear allowance can be made explicit for the compensated quartic truncation. The exact transverse vector field yields a closed forward-invariant strip condition with Gaussian-polynomial jet growth.


For the pure-cubic escape records in GP-AUD-032, the completed strip allowance resolves all three apparent rho=0 counterexamples. Their corrected threshold margins are approximately +0.988, +1.829, and +0.978, so none violates the explicit Step-(i) lemma.


This does not prove adjacency. It proves only forward confinement in Y. A separate central-transit inequality is derived below; entry from S, passage through endpoint neighborhoods, capture by M, higher-order remainder control, and far-field conversion remain open.


A second structural correction is important: a deterministic capture claim for all quartic jets must either use endpoint-typing/axial-margin hypotheses or split off a Gaussian tail event. Strong transverse contraction cannot by itself repair an axial quartic deformation. The probability proof should therefore be organized as a regular-jet event plus a super-polynomially small jet tail.

## 1. Exact truncated vector field


Write s=q/r. From GP-DER-019,


    Xdot = P3_X + r P4_X,
    Ydot = sY + P3_Y + r P4_Y,


where


    P3_X = X^2-1/4 + aXY + (w/2)Y^2,


    P3_Y = (a/2)(X^2-1/4) + wXY + (z/2)Y^2,


and


    P4_X = (c40/6)X(X^2-1/4)
           +(c31/6)(3X^2-1/4)Y
           +(c22/2)XY^2
           +(c13/6)Y^3,

           +(c22/2)X^2Y
           +(c13/2)XY^2
           +(c04/6)Y^3.


Thus


    Ydot = G(X) + A(X)Y + B(X)Y^2 + D Y^3,


with


    G(X) = (a/2)(X^2-1/4)
           + r(c31/6)X(X^2-1/4),


    A(X) = s+wX+r(c22/2)X^2,


    B(X) = z/2+r(c13/2)X,

All statements below concern this explicit truncated flow. An O(r^2) scaled-flow remainder is not silently absorbed.

## 3. Explicit invariant-strip lemma


Fix a contraction target mu>0 and define


    W_mu = F/mu.


On the rectangle


    R_mu = { |X|<=1/2, |Y|<=W_mu },


the exact derivative in the transverse direction satisfies


    partial_Y Ydot
      = s+wX+r(c22/2)X^2
        +(z+r c13 X)Y
        +r(c04/2)Y^2


and hence


    partial_Y Ydot
      <= s+|w|/2 + rho_mu,


where


    rho_mu
      = r|c22|/8
        +( |z|+r|c13|/2 ) F/mu
        +r|c04| F^2/(2 mu^2).


### Lemma


If


    s <= -|w|/2 - mu - rho_mu,


then R_mu is forward invariant for the truncated flow.


### Proof


Under the displayed condition,


    partial_Y Ydot <= -mu


throughout R_mu. At Y=0, |Ydot|=|G(X)|<=F. By the mean-value theorem, at the upper boundary Y=W_mu,


    Ydot(X,W_mu)
      <= Ydot(X,0)-mu W_mu
      <= F-F=0.


At the lower boundary Y=-W_mu,


    Ydot(X,-W_mu)
      >= Ydot(X,0)+mu W_mu
      >= -F+F=0.


The vector field points inward or tangentially at both horizontal boundaries, proving forward invariance. QED.


For mu=1 this supplies the explicit AO48 allowance


    rho_1
      = r|c22|/8
        +( |z|+r|c13|/2 )F
        +r|c04|F^2/2.


The bare rho=0 threshold omitted the generally O(|a z|) term |z|F and therefore was not a valid nonlinear strip condition.

## 5. Tunable contraction is preferable to fixing mu=1


The mu=1 strip has half-width F, which can be too wide for longitudinal monotonicity when |a| or |z| is large. Stronger negative s permits a larger contraction target mu and a narrower strip W_mu=F/mu.


The exact threshold family is


    s <= -C_mu,


where


    C_mu
      = |w|/2 + mu + r|c22|/8
        +( |z|+r|c13|/2 )F/mu
        +r|c04|F^2/(2mu^2).


For each fixed r and jet vector this has finite Gaussian-polynomial/rational growth. One may choose mu as an explicit polynomial majorant rather than optimize it. This addresses AO48-DER-007's requirement that the layer width be jet-dependent rather than uniform.


## 6. Exact central-transit criterion


Inside |Y|<=W, the longitudinal equation obeys


    Xdot <= X^2-1/4 + E_X(W),


where


    E_X(W)
      = |a|W/2 + |w|W^2/2
        +r[ |c40|/(72 sqrt(3))
             +|c31|W/12
             +|c22|W^2/4
             +|c13|W^3/6 ].


The c40 constant uses


    max_{|X|<=1/2}|X(X^2-1/4)|=1/(12 sqrt(3)).


For any sigma in (0,1/2),


    X^2-1/4 <= -sigma(1-sigma)


on


    |X|<=1/2-sigma.


Therefore, if


    E_X(W_mu) < sigma(1-sigma),


then


    Xdot<0


throughout the central rectangle


    |X|<=1/2-sigma,
    |Y|<=W_mu.


This proves finite-time monotone leftward transit through the central part of the chart, provided the branch enters that rectangle and remains in the invariant strip.


The result does not handle the two endpoint neighborhoods


    1/2-sigma < |X| <= 1/2.


Those require explicit unstable-entry and sink-capture estimates.


## 7. Necessary regular-jet or typing split


Strongly negative s controls transverse motion but does not directly suppress the axial quartic term


    r(c40/6)X(X^2-1/4).


On the axis, with the transverse forcing removed, the longitudinal factor is


    Xdot = (X^2-1/4)[1+r c40 X/6].


If |r c40| is too large, the bracket can develop an additional zero inside the chart. Endpoint typing constrains this mechanism, but a clean deterministic proof should not leave that implication implicit.


A proof package should choose one of two routes:


A. TYPED AXIAL-MARGIN ROUTE


Require explicit endpoint/axial margins such as


    1+r c40/12 >= alpha,
    1-r c40/12 >= alpha,


with alpha>0, together with the full typed Hessian inequalities including cross terms. Derive entry and capture constants on that event.


B. GAUSSIAN TAIL SPLIT


Define a regular-jet event, for example


    r|c40| <= 12(1-alpha)


plus analogous polynomial bounds on the remaining jets. Prove the deterministic implication there and estimate the complement using Gaussian tails. Since the quartic jets are Gaussian with O(1) variance, a threshold of order 1/r has probability exp(-c/r^2), negligible compared with any power of r.


This split is compatible with the desired O(r^3) bound and avoids pretending that transverse curvature alone controls arbitrary axial deformations.
