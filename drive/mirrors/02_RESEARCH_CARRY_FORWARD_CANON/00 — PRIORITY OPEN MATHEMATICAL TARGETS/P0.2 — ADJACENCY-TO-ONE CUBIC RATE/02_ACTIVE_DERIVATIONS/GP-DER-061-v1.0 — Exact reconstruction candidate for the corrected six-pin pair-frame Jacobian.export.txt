1. EXACT OBJECT


Let the two pinned locations be x_m and x_s, separated by distance r>0 in the declared longitudinal t-direction, and let s denote the transverse direction. Use the raw six-pin vector and ordering


X_r = (f(x_m), f(x_s), f_t(x_m), f_s(x_m), f_t(x_s), f_s(x_s))^T.


Define the corrected normalized pair frame


Y_r = Psi_r^corr = (V^+, V^-_corr, G_t^+, G_t^-, G_s^+, G_s^-)^T,


where


V^+ = [f(x_s)+f(x_m)]/2,
V^-_corr = [f(x_s)-f(x_m)-r(f_t(x_s)+f_t(x_m))/2]/r^3,
G_t^+ = [f_t(x_s)+f_t(x_m)]/2,
G_t^- = [f_t(x_s)-f_t(x_m)]/r,
G_s^+ = [f_s(x_s)+f_s(x_m)]/2,
G_s^- = [f_s(x_s)-f_s(x_m)]/r.


This is the definitive corrected convention displayed in File 4, equations (3.2)–(3.4). The gradient correction is essential off the pinned constraint surface; the uncorrected raw value difference contains a divergent r^(-2) f_t contribution.

3. EXACT DETERMINANT — HAND DERIVATION


Write T_r in block-upper-triangular form


T_r = [ A  B ; 0  D ],


where A consists of the first two rows and first two columns. Then


A = [ 1/2       1/2
     -r^(-3)    r^(-3) ],


so det A = r^(-3).


The lower-right four-by-four block D acts on the derivative columns ordered as
(f_t(x_m), f_s(x_m), f_t(x_s), f_s(x_s)).
After one column transposition, placing the longitudinal pair before the transverse pair, D becomes block diagonal with two copies of


B_r = [ 1/2      1/2
       -r^(-1)   r^(-1) ],


and det B_r = r^(-1).
The single column transposition contributes a minus sign, hence


det D = -[det B_r]^2 = -r^(-2).


Therefore


det T_r = det A det D = r^(-3)(-r^(-2)) = -r^(-5).


For every r>0, T_r is invertible and


|det T_r| = r^(-5).

6. DENSITY TRANSFORMATION


For Y_r=T_r X_r and y_r=T_r x_r, the change-of-variables formula gives


p_Y(y_r)=p_X(x_r)|det T_r^(-1)|=p_X(x_r)/|det T_r|.


Therefore

The sign of det T_r is irrelevant to the density; the absolute determinant is the invariant used by Kac–Rice.
