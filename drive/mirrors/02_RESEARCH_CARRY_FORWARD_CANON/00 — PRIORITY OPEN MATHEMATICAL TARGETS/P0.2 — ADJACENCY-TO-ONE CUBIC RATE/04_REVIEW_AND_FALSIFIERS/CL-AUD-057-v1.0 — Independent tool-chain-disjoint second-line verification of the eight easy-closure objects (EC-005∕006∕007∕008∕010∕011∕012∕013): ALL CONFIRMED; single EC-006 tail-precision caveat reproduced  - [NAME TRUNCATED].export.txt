1. METHOD (independence basis)
------------------------------------------------------------------
Environment: Python 3, exact arithmetic via the standard-library fractions module; numpy/scipy for floating cross-checks only. SymPy was NOT used (unavailable in this session), which makes this pass tool-chain-disjoint from GP-AUD-011 (SymPy 1.14.0) rather than a re-run of the same machinery.


Techniques:
- Gaussian-field covariances for EC-007 were REBUILT FROM THE KERNEL K(x,y)=exp(-(x^2+y^2)/2) via Cov(d^a f, d^b f) = (-1)^|b| d^(a+b) K(0), evaluated through the probabilists' Hermite-at-zero values He_n(0). The stated Sigma_PP, Sigma_JJ, Sigma_JP matrices were reproduced independently, not copied from the closure package; the regression matrix and Schur complement were then formed by exact rational Gauss-Jordan elimination.
- Polynomial identities (EC-008 determinant, EC-010 A and B) were verified by EXACT rational evaluation on integer/rational grids strictly larger than the per-variable degree. For polynomials this is a deterministic proof of identity, not statistical sampling.
- EC-011 was checked as the algebraic identity it reduces to, over 2000 random exact-rational symmetric Hessians, plus a one-line hand proof.
- EC-005 was checked in exact rational arithmetic; EC-006 and EC-012 involve transcendental/optimization content and were checked numerically (details and precision limits below).

2. RESULTS BY OBJECT
------------------------------------------------------------------
EC-005 — Canonical A2 fold-gap identity.  f_lambda(x) = -x^3/3 + lambda x.
  Critical points +/-sqrt(lambda); separation r = 2 sqrt(lambda) CONFIRMED (exact).
  Critical-value gap f(sqrt L) - f(-sqrt L) = (4/3) L^(3/2) = r^3/6 CONFIRMED (exact).


EC-006 — Planar z0(6/5) truncated second moment.  Q ~ N(-b, 2), z0(b) = E[Q^2 1{Q<0}].
  Closed form E[X^2 1{X<0}] = (mu^2+sig^2)Phi(-mu/sig) - sig*mu*phi(-mu/sig) at b=6/5 gives
    3.23097853528700485 (IEEE double), agreeing with the published constant to ~16 significant figures.
  Independent numerical quadrature gives 3.23097853528700618, agreeing to ~14 significant figures.
  PRECISION CAVEAT (reproduces CL-AUD-036): the published value carries 25 digits
    (3.230978535287004948096246569...). Digits beyond ~16 are NOT independently resolved in this
    session (no arbitrary-precision library available). The closed form and the value are confirmed
    to the precision achievable here; the deep tail is asserted, not re-verified.


EC-007 — Planar coalesced six-pin conditional jet law.  K = exp(-(x^2+y^2)/2).
  Sigma_PP, Sigma_JJ, Sigma_JP reproduced from the kernel independently — MATCH the package matrices exactly.
  Schur complement Sigma_JJ - Sigma_JP Sigma_PP^-1 Sigma_PJ = diag(2,2,2,6) CONFIRMED (exact rational).
  Regression on pins (b,0,0,0,0,2) => E[J|P] = (-b,0,0,0) CONFIRMED (exact rational).


EC-008 — Planar collision-Gram covariance determinant.
  M(c,s) rebuilt from source variances diag(2,2,2,6) and the declared Y1,Y2,Y3.
  det M = s^8 (c^2+s^2)(3c^2+s^2)/24 CONFIRMED as an exact polynomial identity (exact evaluation on a
    grid exceeding the degree in each variable). Stated closed-form entries M11,M12,M22,M33 match.


EC-010 — Declared convex-combination identities.
  Identity A: (K+8ac.eta)^2 + 64a(1-a)c^2 eta^2 = (1-a)K^2 + a(K+8c.eta)^2  == 0  CONFIRMED (exact, full grid).
  Identity B: (a0+(1-2a)eta)^2 + 4a(1-a)eta^2 = (1-a)(a0+eta)^2 + a(a0-eta)^2  == 0  CONFIRMED (exact, full grid).
  (Nonnegativity / convex-combination reading is valid only on 0 <= alpha <= 1, as the package states.)


EC-011 — Adjoint-orbit conservation.  d/dt[w . grad f(gamma)] = 0 under gamma' = grad f, w' = -H_f w.
  Reduces to (-H w) . grad f + w . (H grad f) = 0 for symmetric H — identically zero.
  CONFIRMED over 2000 random exact-rational symmetric Hessians (dims 2-4); zero residual in every case.


EC-012 — Closed strip-threshold majorant.  C(mu) = beta + mu + A/mu + B/mu^2,  muhat = sqrt(A) + (2B)^(1/3).
  Endpoint exactness CONFIRMED: B=0 => muhat=sqrt(A) is the exact minimizer; A=0 => muhat=(2B)^(1/3) is exact.
  Factor-two majorant after subtracting beta CONFIRMED: over a log-grid of (A,B) in [1e-3,1e3]^2 plus the
    axes, the worst observed ratio g(muhat)/g* was ~1.1114 — comfortably inside the factor-two guarantee
    (g = C - beta; g* the exact minimum via the positive root of mu^3 - A mu - 2B = 0). muhat is a
    closed-form surrogate, NOT the exact minimizer for general A,B>0, exactly as the package claims.


EC-013 — Elder-rule defect dichotomy.  {D(M) != S} subset of Pi_r union Gamma_r.
  Not a numeric object; verified by independent logical reconstruction of the case split:
    Case 1 (M dies below f(S)) => interceptor saddle S' with f(S)<f(S')<f(M) => Pi_r.
    Case 2a (arms already connected above S) => first connecting saddle in (f(S),f(M)) => Pi_r.
    Case 2b (arms merge at S but M survives by the elder rule) => competitor birth-max N,
      f(S)<f(N)<f(M) => Gamma_r.
  The three cases exhaust {D(M)!=S}. Argument is valid UNDER the declared Morse, distinct-critical-value,
    and Morse-Smale hypotheses. The word CONDITIONAL is load-bearing and retained.
