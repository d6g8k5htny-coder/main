1. The μ* optimizer — unique, bracketed, residual-checkable (P0)
GP-REG-079 §2 defines C_μ = |w|/2 + μ + r|c22|/8 + A/μ + B/μ², W_μ = F/μ, with F = |a|/8 + r|c31|/48, A = (|z|+r|c13|/2)F, B = r|c04|F²/2. Stationarity dC/dμ = 1 − A/μ² − 2B/μ³ = 0 gives the frozen cubic


μ³ − Aμ − 2B = 0.


Claim (proven). For A,B ≥ 0 not both zero the positive root μ* is unique and lies in the closed bracket [ max(√A, (2B)^{1/3}), √A + (2B)^{1/3} ].


Proof. g(μ)=μ³−Aμ−2B has g(0)=−2B ≤ 0, g(+∞)=+∞, and g′=3μ²−A has a single positive zero, so g is decreasing-then-increasing on μ>0 with g(0)≤0 — exactly one positive root. Writing u=√A, v=(2B)^{1/3}: g(u)=u³−u·u²−2B=−2B ≤ 0 and g(v)=2B−A·v−2B=−Av ≤ 0, so μ* ≥ max(u,v); and g(u+v)=(u+v)³−u²(u+v)−v³ = 2u²v+3uv² = uv(2u+3v) ≥ 0, so μ* ≤ u+v. ∎ The upper end u+v is exactly EC-012's explicit near-optimizer μ̂ = √A + (2B)^{1/3}, so this design inherits EC-012's terminal-closed majorant rather than re-opening it. Degenerate case A=B=0 (⇔ |a|,r|c31|-driven F=0, or |z|,|c13|,|c04| all zero): the frozen rule is the EC-012 A=B=0 bypass, C_* = |w|/2 + r|c22|/8 (no interior μ); an implementation MUST declare this branch and MUST NOT substitute μ=1 (that is negative control NC2). Bisection on the bracket to residual |g(μ*)| ≤ 10⁻¹² is reproducible and the residual is a mandatory receipt field (GP-DATA-080 §3).


Constant-reduction note (Q asked in GP-PRP-078 §6). C_* is monotone increasing in each of |a|,|w|,|z|,|c··| and in r; there is no slack to "reduce a constant without changing the event," because C_* is already the exact infimum over μ (EC-012). 3. Weakest cone/handoff chain S_r → T_r (conditions P1–P4, T5)
The gap GP-REG-079 §4 flags is that T_r is NOT S_r plus a scalar inequality: it needs genuine exact-branch ENTRY through an S-side section and transit while staying in the strip. The weakest deterministic sufficient package I can derive:


P1 — cone contains the unstable germ. The selected unstable eigenvector at S has exact slope bound σ_u = |B_S| / (A_S − D_S) (the quadratic-root identity of CL-AUD-049 §3.7; A_S − D_S > 0 under S_r because D_S = s + w/2 + rc22/8 ≤ −C_* + w/2 + rc22/8 < 0 < A_S). Require the design cone half-aperture κ_p ≥ 2σ_u (factor 2 gives a nonzero-measure cone around the germ, not a knife edge).


P2 — cone forward-invariance under the degree-four remainder. Let ξ = 1/2 − X (distance M-ward from S). On the cone {0 ≤ ξ ≤ σ, |Y| ≤ κ_p ξ} the boundary flux condition is κ_p(Ẋ-contraction − G_X) ≥ G_Y, i.e. κ_p·(C_* + 1 − σ − G_X) ≥ G_Y, where G_X, G_Y are the explicit remainder envelopes (polynomials in κ_p, σ, |jets|, r listed in the reference implementation §A). κ_p is taken as the least fixed point of κ ↦ max( 2σ_u, G_Y(κ)/(C_*+1−σ−G_X(κ)) ); it exists when the denominator stays positive, which S_r plus σ < 1/2 guarantees for the admissible set of §6.


P3 — handoff into the half-strip (identity, not estimate). At cone exit ξ = σ the branch has |Y| ≤ κ_p·σ; require κ_p·σ ≤ W_/2. This is the practical-r analogue of CL-AUD-049 §3.11's exact κσ = W/4 handoff, now with the optimized W_ and the design κ_p rather than the REG_r κ. It is the binding constraint (CL-RSP-050's "binding edge" is here, not at the strip): it says the cone must be narrow enough that its exit lands inside half the invariant strip.


P4 — no premature longitudinal stall. G_X < 1 − σ (the M-ward drift C_* + (X²−1/4) stays negative across the cone), so the branch actually reaches ξ = σ rather than turning.


T5 — central transit (GP-REG-079 §4 inequality). E_X(W_) < σ(1−σ) with E_X(W)=|a|W/2+|w|W²/2+r[|c40|/(72√3)+|c31|W/12+|c22|W²/4+|c13|W³/6]. This is the exact-field transit allowance; it is the same functional CL-AUD-049 §3.3–3.4 bounded, evaluated at W_.
