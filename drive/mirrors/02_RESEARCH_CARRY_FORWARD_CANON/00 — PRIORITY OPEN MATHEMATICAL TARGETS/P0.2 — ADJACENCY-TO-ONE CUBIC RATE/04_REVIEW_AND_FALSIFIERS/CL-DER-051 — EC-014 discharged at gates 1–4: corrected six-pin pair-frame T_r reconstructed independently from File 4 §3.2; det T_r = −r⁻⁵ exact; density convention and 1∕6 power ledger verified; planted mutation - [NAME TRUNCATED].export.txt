C. Determinant, by hand and by exact arithmetic (deliverable C)
Hand derivation (generalized Laplace). Columns 4 and 6 (the f_s slots) have nonzero entries only in rows 5 and 6. Expanding along the complementary minors on rows {5,6} × columns {4,6}: sign = (−1)^((5+6)+(4+6)) = −1; the s-block [[1/2, 1/2], [−1/r, 1/r]] has determinant 1/r. The complementary 4×4 minor (rows 1–4, columns 1,2,3,5) is block upper-triangular [[A, B],[0, D]] with A = [[1/2, 1/2], [−1/r³, 1/r³]] (det A = 1/r³, the V-block) and D = [[1/2, 1/2], [−1/r, 1/r]] (det D = 1/r, the t-gradient block); the V⁻_corr gradient-correction entries −1/(2r²) sit entirely in the B block and therefore do not affect the determinant. Hence


det T_r = −(1/r³)·(1/r)·(1/r) = −r⁻⁵.

def T_corr(r):


    h = F(1,2)


    return [[h,h,0,0,0,0],


            [-1/r**3, 1/r**3, -1/(2*r**2), 0, -1/(2*r**2), 0],


            [0,0,h,0,h,0],

def det_exact(M):


    n=len(M); A=[row[:] for row in M]; d=F(1)


    for c in range(n):


        p=next((i for i in range(c,n) if A[i][c]!=0), None)


        if p is None: return F(0)


        if p!=c: A[c],A[p]=A[p],A[c]; d=-d


        d*=A[c][c]; inv=1/A[c][c]


        for i in range(c+1,n):


            if A[i][c]!=0:


                f=A[i][c]*inv


                A[i]=[A[i][j]-f*A[c][j] for j in range(n)]


    return d
