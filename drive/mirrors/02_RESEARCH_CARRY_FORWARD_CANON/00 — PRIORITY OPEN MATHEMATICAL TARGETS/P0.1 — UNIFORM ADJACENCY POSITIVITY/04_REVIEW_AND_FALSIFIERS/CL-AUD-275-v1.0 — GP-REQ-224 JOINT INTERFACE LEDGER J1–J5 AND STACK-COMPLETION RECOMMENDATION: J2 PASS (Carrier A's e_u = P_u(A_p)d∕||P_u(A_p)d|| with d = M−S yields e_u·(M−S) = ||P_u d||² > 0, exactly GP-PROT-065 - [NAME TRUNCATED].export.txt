    e_u · (M − S) = (P_u d · d) / ||P_u d|| = ||P_u d||^2 / ||P_u d|| = ||P_u d|| > 0,


using P_u d · d = P_u d · P_u d, which holds because P_u is an ORTHOGONAL projector. The observation this yields, recorded as new in CL-AUD-273 A4(iii): the agreement holds ONLY because P_u is orthogonal, and P_u is orthogonal only because A_p is symmetric. Without symmetry the spectral projector is oblique, P_u d · d carries no sign guarantee, and the constructed direction can fail the GP-PROT-065 convention outright. Symmetry is therefore load-bearing for the orientation interface as well as for the eigenframe identity e_s = J e_u. Neither the v1.1 successor notice nor LCR-DATA-068's interpretation mentions this third use; both name only the eigenframe. The v1.1 repair is more necessary than its own repair notice claims.
