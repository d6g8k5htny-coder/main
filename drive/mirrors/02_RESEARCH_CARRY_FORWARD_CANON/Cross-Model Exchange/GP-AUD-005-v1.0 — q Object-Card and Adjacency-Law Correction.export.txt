1. EXECUTIVE FINDING


The live q0 record currently uses the same symbol q for two mathematically different Palm objects.


C101 and C102 state the cubic selection theorem under the typed maximum–saddle pair-Palm law. Their deterministic reduction, however, begins with a gradient-adjacent maximum–saddle pair. C104 instead defines the candidate process using gradient-adjacent typed pairs, factors the adjacency probability into the contact intensity, and then applies q as the elder-rule selection probability inside that adjacent candidate process.


These are not interchangeable definitions. The exact relationship is


q_typed(r) = a_r q_adj(r),


where a_r is the typed pair-Palm probability of gradient adjacency. Equivalently,


1 - q_typed(r) = (1 - a_r) + a_r(1 - q_adj(r)).


This identity changes the required proof obligation:


• an adjacent-law cubic theorem needs only a uniform lower bound a_r >= c > 0, together with the typed regional O(r^3) defect counts;
• a typed-law cubic theorem needs the much stronger estimate 1 - a_r = O(r^3), in addition to the adjacent-law selection estimate.


The current program-grade statement that a_r converges to a positive limit is sufficient for the adjacent-law theorem and Theorem B. It is not sufficient for the typed-law statement q_typed -> 1.


2. EXACT OBJECTS


Let gamma_r be the six-pin Gaussian law fixing the pair values and gradients. Let


W_MS = |det H_M det H_S| 1_{M maximum} 1_{S saddle},


and define the typed pair-Palm law


dP_r^MS = W_MS dgamma_r / E_gamma_r[W_MS].


Let A_r be the event that the M-ward ascending separatrix of S terminates at M. Define


a_r = P_r^MS(A_r).


There are then two distinct selection probabilities.


Typed-law selection:


q_r^MS = P_r^MS(D(M)=S).


Adjacent configured-pair selection:


dP_r^adj = 1_{A_r} dP_r^MS / a_r,


q_r^adj = P_r^adj(D(M)=S).


Under the Morse–Smale and distinct-critical-value hypotheses, if S is the elder-rule death saddle of the component born at M, then an ascending branch of S is incident to that component and terminates at M under the configured local branch convention. Thus


{D(M)=S} subset A_r.


Therefore


q_r^MS
= P_r^MS(D(M)=S, A_r)
= P_r^MS(A_r) P_r^MS(D(M)=S | A_r)
= a_r q_r^adj.


Subtracting from one gives the exact nonnegative decomposition


1 - q_r^MS
= (1-a_r) + a_r(1-q_r^adj).


No independence assumption is used.


3. CONSEQUENCES FOR THE CUBIC RATE


3.1 What a typed-law cubic theorem requires


Suppose the intended theorem is literally


1 - q_r^MS <= C r^3.


Because both terms in the exact decomposition are nonnegative, this necessarily implies


1 - a_r <= C r^3.


It also implies


a_r(1-q_r^adj) <= C r^3.


If a_r >= c > 0, then


1-q_r^adj <= (C/c) r^3.


Thus a typed-law cubic theorem automatically contains a cubic adjacency theorem. A merely positive limiting adjacency factor is not enough.


Conversely, if


1-a_r <= C_A r^3


and


1-q_r^adj <= C_Q r^3,


then


1-q_r^MS
<= (C_A + C_Q) r^3.


If only a_r -> a_0 with 0<a_0<1, then


q_r^MS -> a_0,


not one. Therefore the C103/C104 positive-limit statement cannot by itself justify the C101/C102 typed-law limit.


3.2 The exact typed-to-adjacent transfer lemma


Let B_r be any measurable obstruction event such that, on A_r,


{D(M) != S} subset B_r.


For the current deterministic reduction one may take B_r = Pi_r union Gamma_r, with collar terms included in the count bound as needed.


Then


1-q_r^adj
= P_r^MS(D(M) != S, A_r)/a_r
<= P_r^MS(B_r)/a_r.


Hence:


LEMMA — ADJACENCY-CONDITIONING TRANSFER.
If a_r >= c_A > 0 uniformly for 0<r<=r_0 and P_r^MS(B_r) <= C_B r^3, then


1-q_r^adj <= (C_B/c_A) r^3.


This is an exact one-line measure-theoretic transfer. The only new probabilistic obligation is the uniform lower bound on a_r. No stronger bounded-density statement is needed for an upper bound.


4. SOURCE-BY-SOURCE RECONCILIATION


4.1 C101 and C102


C101’s qualifier says “typed maximum–saddle pair-Palm law.” C102 repeats that qualifier. But C102’s deterministic reduction begins: “For a maximum M and a gradient-adjacent saddle S.” The proof therefore establishes the obstruction inclusion only after adjacency is imposed.


Neither the C101 theorem file nor the C102 objection ledger supplies a separate analytic estimate 1-a_r=O(r^3). The C102 objection table contains no row adjudicating the typed-versus-adjacent object change.


Therefore the current typed-law wording is not fully supported by the displayed proof chain unless “typed pair-Palm law” was intended as shorthand for an object card that already includes adjacency. If that was the intent, the adjacency condition must be written explicitly in every theorem qualifier.


4.2 C092


C092 defines the determinant-weighted typed Palm law and then says that “any exact adjacency conditioning” is included according to the estimand’s object card. This acknowledges that multiple estimands exist, but it does not identify which object card governs the displayed q theorem. The ambiguity was inherited by C101/C102.


4.3 C103 and C104


C103 states that the unadjacent typed candidate intensity has a positive contact limit and that the adjacency factor converges to a positive limit by scaled-field convergence, structural stability, and an open trapping event.


C104 is internally coherent with an adjacent candidate process:


• it begins with an “oriented, gradient-adjacent, typed” candidate pair;
• it factors contact intensity into a typed contact term times an adjacency factor;
• it uses q as the elder-rule selection mark within that candidate process.


For Theorem B, positivity of the adjacency limit is exactly what is needed to make the limiting coefficient positive. Theorem B does not require adjacency probability to tend to one.


4.4 C013 Lemma ADJ


C013 is an instrument package, not an analytic proof. It reports finite-r simulations and states


P(adj | pair) = 1 - c_a r(1+o(1))


with an estimated coefficient. It also reports determinant-weighted adjacency as 1.0000 at the sampled rungs within numerical resolution.


Those observations are valuable diagnostics, but they do not prove an asymptotic rate. Moreover, the generic displayed complement is O(r), not O(r^3). If that O(r) behavior held under the exact q_typed law with nonzero coefficient, it would contradict a typed-law cubic defect theorem because


1-q_r^MS >= 1-a_r.


The C013 measurement may support an order-one lower bound on a_r. It cannot be promoted into the missing cubic adjacency estimate.


5. RECOMMENDED REPAIR


Recommended canonical object:


q_r^adj = P(D(M)=S | six pins, typed maximum–saddle pair, specified gradient adjacency).


Recommended theorem qualifier:


“under the typed, gradient-adjacent configured-pair Palm law.”


Recommended proof chain:


1. Prove the regional obstruction count P_r^MS(B_r) <= C_B r^3 under the typed determinant-weighted law.
2. Prove a named adjacency-positivity lemma a_r >= c_A > 0.
3. Apply the exact adjacency-conditioning transfer lemma.
4. State q_r^adj -> 1.


This repair preserves the intended local-selection theorem while matching the deterministic reduction and the C104 candidate-pair formulation.


Alternative, stronger theorem:


Retain q_r^MS under the unconditioned typed pair-Palm law, but register a new load-bearing obligation


1-a_r = O(r^3).


Until that estimate is proved, the typed-law cubic theorem and typed-law q->1 limit should be classified as conditional or object-card ambiguous.


6. MACHINE AND VERIFIER RECOMMENDATIONS


Every machine root involving q should declare one of the following explicit law identifiers:


Q_TYPED_MS
Q_ADJ_CONFIGURED


The verifier should reject an unqualified symbol q in theorem statements, object cards, and dependency edges.


Suggested invariant:


A theorem claiming q_typed -> 1 must depend on a root proving a_r -> 1.
A theorem claiming 1-q_typed = O(r^3) must depend on a root proving 1-a_r = O(r^3).
A theorem claiming 1-q_adj = O(r^3) must depend on a root proving inf_r a_r > 0.


Theorem B should separately track


J_r = typed candidate contact intensity,
a_r = adjacency factor,
I_r = J_r a_r,
q_r^adj = elder-rule selection probability within adjacent candidates.


7. FALSIFIERS


The proposed repair is falsified or altered by any of the following:


1. A precise definition showing that the existing symbol q already denotes q_adj everywhere in C101/C102 and that “typed” was merely an incomplete qualifier. In that case the mathematical theorem may survive, but the qualifier defect remains and should be corrected.
2. A rigorous proof that 1-a_r=O(r^3) under the unconditioned typed pair-Palm law. In that case the stronger typed-law theorem may be restored.
3. A counterexample to {D(M)=S} subset A_r under the exact branch convention. In that case the object definitions and deterministic reduction require revision.
4. Failure of a uniform positive lower bound on a_r. This would block the adjacent-conditioning transfer and the positivity of Theorem B’s contact coefficient.
