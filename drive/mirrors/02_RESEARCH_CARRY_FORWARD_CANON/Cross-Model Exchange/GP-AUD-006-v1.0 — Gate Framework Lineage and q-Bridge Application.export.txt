3. WHY THE q OBJECT-CARD DEFECT IS A GATE FAILURE


GP-AUD-005 derived the exact distinction


q_typed = P_MS(D(M)=S),
q_adj = P_MS(D(M)=S | A_r),
a_r = P_MS(A_r),


with


q_typed = a_r q_adj


and


1-q_typed = (1-a_r) + a_r(1-q_adj).


The Gate Framework v1.2 says that a claim established in one regime cannot be deployed in another without retaining the restriction or supplying a first-class graded bridge node. A regime includes the base measure, conditioning law, conditioning depth, and marks/types.


The q-lineage changes all of these at once:


Source regime:
• determinant-weighted typed maximum–saddle pair-Palm law;
• six value/gradient pins;
• type marks: maximum at M, saddle at S;
• no explicit gradient-adjacency conditioning.


Target regime:
• the same typed pair law additionally conditioned on A_r;
• specified gradient-adjacent branch incidence;
• the elder-rule selection estimand within adjacent configured pairs.


Using typed regional obstruction estimates directly for q_adj is therefore a MEASURE/MARK restriction transfer. It requires a bridge node. Calling both objects q conceals the restriction drop and defeats the framework’s shell checks.


4. REQUIRED FIRST-CLASS BRIDGE NODE


Recommended bridge identifier:


ADJ-CONDITIONING-TRANSFER


Kind:
MEASURE/MARK bridge; exact conditional-probability identity.


Source regime:
P_r^MS, the determinant-weighted typed six-pin maximum–saddle pair-Palm law.


Target regime:
P_r^adj = P_r^MS(. | A_r), the typed gradient-adjacent configured-pair law.


Bridge statement:
For any measurable event B_r,


P_r^adj(B_r)
=
P_r^MS(B_r ∩ A_r)/a_r,


where a_r=P_r^MS(A_r).


Specialized selection transfer:
If


{D(M) != S} ∩ A_r ⊂ B_r,


a_r >= c_A > 0,


and


P_r^MS(B_r) <= C_B r^3,


then


1-q_r^adj <= (C_B/c_A)r^3.


Dependencies:
• exact definition of P_r^MS;
• measurable adjacency event A_r;
• deterministic elder-rule obstruction inclusion on A_r;
• uniform adjacency-positivity root inf_r a_r>0;
• typed regional O(r^3) obstruction bound.


Warrant:
PROVEN-MODULO the uniform adjacency-positivity root and the regional obstruction theorem.


Falsifiers:
• a_r approaches zero;
• adjacency is not measurable under the selected object card;
• the deterministic obstruction inclusion fails under A_r;
• the regional typed bound does not control the marked event B_r.


5. SEPARATE ROOT FOR THE STRONGER TYPED THEOREM


The bridge above proves an adjacent-law theorem. It does not prove the unconditioned typed statement q_typed→1.


Recommended separate root:


ADJACENCY-TO-ONE-CUBIC


Statement:


1-a_r = O(r^3)


under the determinant-weighted typed six-pin pair-Palm law.


This root is necessary because the exact decomposition contains the nonnegative term 1-a_r. A theorem claiming


1-q_typed = O(r^3)


must depend on both:


• ADJACENCY-TO-ONE-CUBIC;
• the adjacent-law cubic selection theorem.


The reviewed record contains a program-grade positive-limit argument for a_r and finite-r C013 measurements. It does not contain a proof of ADJACENCY-TO-ONE-CUBIC.
