Required join: BOTH artifact_id and Drive file ID, with exact decision type and scope matching.


Normative rule:
- An inventory object may inherit trusted operator state only when its normalized artifact_id equals the Operator Decisions Exact Object ID AND its immutable Drive file ID equals the Operator Decisions Drive ID.
- The decision type must match the field being populated: authority, human decision, canonical impact, release permission, or other operator-only state.
