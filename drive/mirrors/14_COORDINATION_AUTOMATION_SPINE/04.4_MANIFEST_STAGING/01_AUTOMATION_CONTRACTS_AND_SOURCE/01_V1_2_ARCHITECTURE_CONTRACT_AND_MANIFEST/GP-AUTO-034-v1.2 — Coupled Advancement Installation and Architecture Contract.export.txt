This release upgrades GP-AUTO-034 from a safe indexing and manifest layer into a coupled mathematical–architectural advancement controller. 2. TRUST SEPARATION


Artifact text is never a trusted control surface. It may state claimed status, claimed authority, claimed canonical impact, claimed closure, and claimed human decision, but those values are retained only as claims.


Verified authority, human decision, canonical impact, observer activation, external-release permission, and other operator-only state are read exclusively from the protected Operator Decisions sheet. Verified closure comes from the Closure Log. Transition identity, evidence role, review independence, closure scope, and global-object alignment come from their dedicated registers.


A document cannot authorize, approve, close, promote, delete, publish, or expand its own scope.


3. GOVERNANCE REGISTERS


Transition Register records the previous and new state, exact object, exact claim or rule, evidence added and removed, evidence class, measure, regime, normalization, coordinates, review status, affected and unaffected dependencies, mathematical and architectural changes, no-change certificate, failure modes, detection tests, uncertainty removed, remaining uncertainty, human decision, and reopening condition.


No-Change Certificates demonstrate why the existing schema, verifier, register, status classes, and governance already cover a mathematical transition. Silence never substitutes for a certificate.


Review Independence records source exposure, derivation visibility, code and fixture reuse, inherited assumptions, independent route, object-definition review, algebra-only status, independent notation, observer mode, lineage access, methodological family, score, class, and status.


Evidence Lineage distinguishes primary derivations, executable receipts, raw data, formal proofs, independent reconstructions, summaries, ballots, navigation aids, register copies, and review-of-review artifacts.


Global Object Audit checks the original scientific question, exact theorem required, current theorem, target-versus-surrogate status, changes in measure, conditioning, pairing, domain, finite/limiting object, coordinates, proxy, machine-root alignment, primary-evidence inspection, conclusion, dependencies, and reopening condition.


Architecture Metrics measures outcomes rather than artifact count. Transition Alarms displays fail-closed inconsistencies. Operator Decisions is restricted to Dylan Roy’s Google account.


4. COUPLED ADVANCEMENT GATE


A material mathematical transition passes only if its object card is complete and it includes an architectural change or a valid no-change certificate. A material architectural transition passes only if it cites a concrete failure mode, uncertainty permanently removed, and detection tests.


A mathematical error transition additionally requires a named failure class, architecture-response disposition, and recurrence control. An architecture incident additionally requires downstream mathematical-contamination assessment, affected mathematical objects, and quarantine status.


Existing trusted states without a transition are marked BASELINE-PENDING. They remain visible but cannot become REFEREE-READY until a complete transition record exists. Newly detected changes without a transition produce a critical alarm.


5. FALSE-INDEPENDENCE GATE


The system computes a deterministic independence score. It penalizes visibility of the original derivation, reuse of code, reuse of fixtures, inherited assumptions, failure to reconstruct independently, failure to inspect the object definition, and algebra-only review. Independent notation and properly preserved blind-observer conditions provide limited positive weight.


High-independence status also requires an independent reconstruction, object-definition review, and a route that is not algebra-only. Model count is never used as a substitute for methodological independence.


6. PRIMARY-EVIDENCE GATE


Summaries, ballots, navigation artifacts, register copies, and review-of-review documents cannot be primary evidence. Repetition cannot increase authority. REFEREE-READY requires admissible primary evidence and at least one high-independence reconstruction.


7. CLOSURE-SCOPE GATE


Terminal closure requires the exact statement, evidence class, regime, normalization, coordinate system, broader claims remaining open, forbidden extrapolations or new failure modes, and reopening condition. Missing dimensions trigger CLOSURE_INFLATION_RISK and revoke eligibility.


8. GLOBAL-OBJECT GATE


Trusted material objects require a Global Object Audit before REFEREE-READY. SURROGATE_UNJUSTIFIED, incorrect intended object, unaligned machine roots, incomplete dependencies, or failure to inspect primary evidence produces a critical alarm.


9. OBSERVER PROTECTION


A review marked BLIND fails if the original derivation, internal conclusions, or full internal lineage were visible. Observer mode and lineage access are explicit fields so Gemini or another outside reviewer can retain deliberate distance.
