1. FAILURE MODE


GP-AUD-216 documented two recovered register incidents:


1. cached row numbers caused writes intended for DQ-007 and DQ-009 to land on other Dispatch Queue primary keys after concurrent row reordering;
2. a cached numeric sheet ID routed three intended Duplicate Flags rows into Artifact Index after sheet-grid identifiers changed.


The governing correction is:


ROW POSITION IS NOT IDENTITY.
NUMERIC SHEET ID IS NOT A STABLE NAME.


Every material register write must freshly resolve the sheet title, uniquely locate the primary-key row, assert the key and expected values immediately before mutation, and verify the destination after mutation.


2. IMPLEMENTED PROTOCOL


GP-DATA-218-v1.0 implements a runtime-agnostic guarded-update reference with an injected adapter. Its protocol is:


G1. Resolve the current sheet ID from the exact current sheet title.
G2. Fail if the title has zero or multiple matches.
G3. Build a unique header map and fail on duplicate or missing headers.
G4. Locate exactly one row by the declared primary-key header and value.
G5. Reassert the key cell immediately before mutation.
G6. Optionally assert expected pre-write field values.
G7. Prohibit primary-key mutation and unknown patch columns.
G8. Apply only named-column patches.
G9. Flush, freshly resolve the sheet title again, and re-read by primary key.
G10. Fail if the sheet ID changes, the row moves during the guarded transaction, the key changes, or any patched field differs.
G11. Emit a receipt with sheet title, resolved sheet ID, key, row, before values, after values, and verification state.
