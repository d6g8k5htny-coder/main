## What this does not establish

All seven byte-exact rows establish that this directory holds the same bytes the
2026-09-17 inventory declares for those ids, and nothing further.

**A freeze is not a proof, and a gate list is not a result.** Every gate status
above — OPEN, PARTIAL-CLOSED, BLOCKED, BLOCKED-EXTERNAL — is the source's own
word for its own state at the moment it froze, and none of these gates is
evaluated, re-run or moved by this repository. Two of the five contracts exist
precisely because an earlier freeze pinned a wrong hash; that is the sources
correcting themselves in the append-only form they declare, and this port
transcribes both the error and the correction without deciding which value is
right.

The planned-artifact lists inside these contracts name files this directory does
not hold; their presence in a plan is not evidence that they exist. No decimal
named in any of these contracts is promoted — each contract says so itself.
Mirroring is not review, replay, endorsement, promotion or acceptance, and
nothing here closes, discharges or grades any claim, premise or obligation. No
contract stored here is parsed, executed, scheduled or tested by anything in this
repository.
