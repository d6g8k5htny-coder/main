# Development and limits

The first and final baseline runs completed. No theorem-breaking counterexample was found within the finite checks; this is not an independent proof verdict. A preliminary fault example for weak-sandwich input used kappa<1 and would have tested input validation rather than the intended strict endpoint; before finalization it was replaced by K_(2,2), kappa=1, with valid theorem input types and an actual strict-upper-sandwich failure. The abandoned probe is not counted as mathematical fault detection.

No floating-point optimization was used to certify feasibility or optimality. Small LPs were solved by exact vertex enumeration on both sides and checked by exact matching certificates. Decimal diagnostics in result files are not consumed by inequalities.

The explicit many-row family has huge raw row count but small fractional width. It is not asserted to defeat every preceding small-cover method, or to be a new extremal/prize record. Its purpose is to demonstrate row-count removal with irredundancy and nonempty obstruction. The connected bipartite counterexample proves the new width cannot be universally bounded, even though those instances are trivially2-colorable.

The complete original P13 was replayed in a scratch directory, not modified. P14 changes no q0/Claude source, scientific gate, sharing permission, or external-submission status. Deployment is reported only after actual tool outcomes and raw-byte comparisons.
