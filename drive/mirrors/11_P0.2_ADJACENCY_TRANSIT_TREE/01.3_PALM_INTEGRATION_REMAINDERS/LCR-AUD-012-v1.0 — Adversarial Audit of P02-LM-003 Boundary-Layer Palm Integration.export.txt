Assume constants K,c,c_Z,K_C,K_U>0 and integers d_C,d_U,d_D exist, independent of r, such that:

|U_r(U)|<=K_U(1+||U||^{d_U}).

-C_r(U)<s<U_r(U).


Using H5 and H1,


N_r
<=Kr^5∫_{R^m}e^{-c||U||^2}

BL-A4 — Change-of-variables Jacobian.

BL-A7 — Density envelope use.

BL-A8 — Polynomial integral.

BL-A10 — Final exponent.

6. NORMALIZER-PROOF REPAIR


GP-DER-043 Lemma 3.1 states W_r/r^2 converges pointwise almost surely while the underlying law gamma_r changes with r, then invokes dominated convergence.


A correct route is either:


Route A — common Gaussian coupling:


Write J_r=m_r+L_rZ with a single standard Gaussian vector Z and choose continuous covariance square roots L_r. Under continuous m_r,Sigma_r and positive-definite limit, J_r->J_0 almost surely. Then the typed normalized weight converges outside the null q=0 boundary, and a uniform polynomial moment bound gives dominated convergence/uniform integrability.


Route B — weak convergence plus uniform integrability:


Continuous Gaussian parameters give J_r=>J_0. The typed weight map converges off the null type boundary. Uniform polynomial moments give uniform integrability. Therefore expectations converge.


The normalizer conclusion survives. P02-LM-003 avoids entangling this repair by assuming H2 directly.


7. FALSIFICATION ATTEMPTS


F1 — Remove the maximum type mark.


Then there is no automatic polynomial upper bound on s. The q-range need not shrink like r, so the cubic power may fail. This confirms the typed mark is load-bearing.


F2 — Reverse the denominator bound.


Using Z_r<=Cr^2 cannot upper-bound N_r/Z_r. The theorem correctly requires a lower normalizer bound.


F3 — Let C_r grow exponentially in ||U||^2 with rate exceeding the density decay.


The U integral can diverge. Polynomial growth is load-bearing.


F4 — Use normalized rather than physical endpoint Hessians without restoring r^4.


The power ledger changes. The theorem explicitly assumes the physical determinant weight after q=rs.


F5 — Treat a finite-Q4 deterministic event as exact-field adjacency.


That is an object-identity error outside this lemma. The theorem bounds only the event actually supplied.


F6 — Allow the density envelope constant to diverge with r.


Uniformity is lost. H1 excludes this.


No counterexample was found under H1–H5.
