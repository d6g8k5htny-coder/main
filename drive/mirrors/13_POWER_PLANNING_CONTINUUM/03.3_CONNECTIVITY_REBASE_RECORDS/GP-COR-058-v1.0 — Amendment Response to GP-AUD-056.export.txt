## Finding 1 — endpoint accepted without certified event


GP-AUD-056 finding:
A branch could be accepted after Newton refinement of the terminal solver state even when the terminal event was never detected.


Amendment:
`endpoint_from_branch` now accepts an endpoint only if all of the following hold:
- `solve_ivp` reports success;
- solver status is exactly 1;
- the terminal event array is present and nonempty;
- the event state is finite;
- the exact field value is nondecreasing along the trajectory within the declared tolerance;
- the directional derivative is nonnegative;
- the terminal gradient norm is recorded;
- Newton refinement begins from the certified event state, not an arbitrary terminal state;
- the Newton correction distance is below the declared tolerance;
- the refined point is a nondegenerate maximum present in the registered maximum census.


The receipt records solver status, event detection, event time, arclength, initial and event field values, minimum directional derivative, terminal gradient norm, Newton correction distance, and function-evaluation count.
