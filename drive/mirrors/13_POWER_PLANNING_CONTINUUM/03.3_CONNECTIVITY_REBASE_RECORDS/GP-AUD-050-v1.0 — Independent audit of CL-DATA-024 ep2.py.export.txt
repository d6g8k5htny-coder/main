## 4. Object-identity and validation defects


### 4.1 The branch walker is not the exact-field separatrix flow
The critical field `Fx` uses Fourier modes down to amplitude cutoff 1e-13 and is normalized. The ascent-direction field `Fa` is reconstructed separately with cutoff 1e-8. The endpoint walk follows the normalized gradient of `Fa`, not the exact gradient of `Fx`, for 70 fixed steps of size 0.05 before a Newton snap. Therefore the code does not integrate exact unstable separatrices of the target field. Spectral truncation can alter basin boundaries and endpoint identity.


### 4.2 No adaptive integration or convergence certificate
The walk uses a fixed step and fixed iteration count. There is no step-halving test, adaptive solver, trajectory-error estimate, or endpoint stability test under cutoff and step refinement.


### 4.3 Unresolved branches are excluded
Saddles with either unresolved endpoint are skipped by `if not res[si]: continue`. The source reports the 90% endpoint gate failed on roughly one-third of fields. Excluding unresolved saddles can alter both bar counts and the fitted lifetime distribution. The code contains no missingness analysis proving that exclusion is unbiased.


### 4.4 V1, V2, and V3 are printed, not enforced
The program computes Euler count, endpoint percentage, and the comparison `bars` versus `max-1`, but has no assertion, exception, fail-closed exit, or structured gate result. A failed field can still contribute bars and the pooled fit. The header’s statement that V1/V2 held is not an executable property of this file.


### 4.5 Critical-set completeness is not certified by the implementation
Critical points are found from a fixed 64x64 Newton seed lattice, deduplicated after rounding coordinates to 1e-6, with fixed iteration and gradient tolerances. This is a numerical census, not a proof that all critical points were found. The post-hoc comparison to an eight-neighbor census is outside this source and is not emitted as a machine-checkable V4 receipt.


### 4.6 The fit is pooled and selected
The estimator pools bars across fields after unresolved saddles are excluded. It does not preserve field clusters for uncertainty estimation. The source itself correctly labels the value a bulk range exponent and says the small-L windows are underpowered; it does not establish the asymptotic law.


### 4.7 Reproducibility metadata are incomplete
The script has no dependency/version lock, environment receipt, CLI validation, per-field JSON output, source/output hash binding, checkpointing, or resumable execution.
