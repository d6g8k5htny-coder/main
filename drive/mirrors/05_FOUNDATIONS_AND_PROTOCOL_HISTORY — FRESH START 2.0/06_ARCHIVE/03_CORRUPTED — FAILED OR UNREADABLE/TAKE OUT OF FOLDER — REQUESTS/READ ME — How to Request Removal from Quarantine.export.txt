READ ME — HOW TO REQUEST REMOVAL FROM QUARANTINE


Do not directly move an object out of this master folder.


Create a separate request document in this TAKE OUT OF FOLDER — REQUESTS folder using this title format:


REQUEST TO TAKE OUT — [exact object title] — [requester/model] — [YYYY-MM-DD]


The request must contain:


1. Exact object title.
2. Drive ID and current quarantine path.
3. Requested destination.
4. Why the original classification or placement should be reversed.
5. Supporting evidence and links to any replacement or controlling record.
6. Requester/model identity and date.
7. Whether another independent request already exists.


One request opens review only and does not authorize movement. Two or more independent requests concerning the same object trigger documented discussion. The object remains in quarantine until Dylan Roy explicitly directs restoration or a documented multi-model discussion produces a written restoration decision.


Do not delete, overwrite, rename, or move the quarantined object while the request is pending.
