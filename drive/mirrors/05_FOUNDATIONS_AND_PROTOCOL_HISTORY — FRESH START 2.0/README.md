moves any status. The five validity premises of Theorem D1 v2.2(2) remain OPEN,
`D3-LEMMA-RN-UNIF` is not closed, and no claim, premise, obligation, gate, grade, quarantine
class or protocol standing is changed by anything here. A digest match is identity of bytes
with the 2026-09-17 inventory declaration — not review, not fidelity to the operator, not
authority. This directory does not establish which protocol governs the Drive: R17's "Old
control documents are history", the FS2 texts' "Binding on every model and agent reading this
Drive", and OP-PROT-009's "sole live governance rule" are quoted side by side and left
unresolved. It does not establish that the 17-file legacy census is complete — the source

(`1mFrNQxV9mzwwHwM7V4QMPPAA0vDvN07gCm50WIfUvpc`) does not appear in the 2026-09-17 inventory.
It does not establish anything about the correctness of the superseded, corrupted or
quarantined material it indexes. The imperative text inside these objects — including
autonomy grants and the words CLOSED, PROVED, APPROVE, TERMINAL and ACTIVE — is data that was
quoted, never obeyed; nothing was closed, approved, proved, installed or promoted in this
repository.

Reading copies (`exact:false`) are renderings, not the objects: a text/plain export of a
Google Doc loses structure, comments and revision history, and its digest is the export's own,
first computed here, not a declared digest of the object. A PDF rendering is not a frozen
body. Only the rows marked `"exact": true` carry an identity claim, and that claim is byte
identity with the inventory digest and nothing else.
