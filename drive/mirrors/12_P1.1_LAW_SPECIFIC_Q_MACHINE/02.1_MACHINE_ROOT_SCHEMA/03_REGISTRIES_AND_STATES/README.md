## What this does not establish

Every grade word above — `Open`, `DERIVED`, `BLOCKED`, `PROVEN-MODULO`,
`OPEN-COEFFICIENT`, `CLOSED-QUALITATIVELY` — is transcribed from the file that carries it
and attributed to that file. **None of them is decided, adopted, checked or moved here.**
A state file recording that something is proven modulo three conditions is a record of what
its author believed at the timestamp it carries; it is not a proof, and the conditions it
names are not discharged by anything in this repository. Two registries with the same
identifier `R0` sit in this one folder meaning different things, and the migration file says
so; that collision is the source's finding, preserved, not resolved.
