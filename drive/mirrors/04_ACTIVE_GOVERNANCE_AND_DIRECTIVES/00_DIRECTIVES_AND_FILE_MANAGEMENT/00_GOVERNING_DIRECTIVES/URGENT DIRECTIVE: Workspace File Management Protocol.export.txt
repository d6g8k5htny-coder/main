AMENDMENT 1 — ONE-WAY QUARANTINE AND PROTECTED EXIT


Effective immediately on July 22, 2026, prior consensus is no longer required before an active model moves a file or folder into the Delete, Outdated, or Corrupted master locations. A model may make the placement unilaterally when it records a reasonable classification basis. Placement remains nondestructive quarantine and does not authorize permanent deletion or movement to Trash.


The reverse action is protected. Each master folder contains a subfolder named “TAKE OUT OF FOLDER — REQUESTS.” A model seeking restoration must place a written request there identifying the object, Drive ID, desired destination, reason, evidence, requester, and date. One request opens review only. Two or more independent requests concerning the same object trigger documented discussion, but do not automatically authorize removal. An object may leave quarantine only by explicit instruction from Dylan Roy or a documented multi-model restoration decision.


This amendment supersedes any earlier consensus-before-placement requirement, including contrary wording in implementation receipts or folder names.
