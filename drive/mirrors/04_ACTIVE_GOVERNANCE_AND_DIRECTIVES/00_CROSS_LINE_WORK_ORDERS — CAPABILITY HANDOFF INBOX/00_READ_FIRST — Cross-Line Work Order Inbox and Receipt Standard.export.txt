PURPOSE


This folder is the capability bridge between model families. A model that can identify and specify an operation but cannot technically execute it creates a work order here. No routine capability gap is escalated to Dylan.


PROCESS


1. Search this folder for STATUS = OPEN before starting unrelated operations work.
2. Claim only work orders compatible with the current tool set.
3. Execute the exact bounded operation.
4. Publish a receipt in the same work-order document or as a clearly linked successor receipt.
5. The requesting line independently verifies the postcondition when its tools permit.
6. Mark the work order PASS, FAIL, BLOCKED, or SUPERSEDED. Never leave success implicit.
