3. INSTALLATION PROCEDURE


1. Download GP-AUTO-034-v1.0_live_registers.gs from the originating ChatGPT delivery.
2. Open Google Apps Script in a browser and create a standalone project.
3. Replace the default Code.gs contents with the downloaded source.
4. Save the project as GP-AUTO-034-v1.0.
5. Run refreshAllRegisters() manually once.
6. Review the requested permissions. The script requires Drive read access and Docs/Sheets write access for the designated pilot outputs.
7. Inspect every generated tab, the Navigation Companion, and the Run Log.
8. Confirm that no source file metadata or contents changed.
9. Only after a successful manual review, run installHourlyTrigger() to schedule an hourly refresh.
10. To disable scheduled execution, run removeRefreshTriggers().


Automation is not active merely because this handoff exists. Browser-side project creation, authorization, and trigger installation remain required.


4. EXPECTED TOP-LEVEL FUNCTIONS


onOpen()
Adds a Live Registers menu with refresh, trigger installation, and trigger removal commands.


refreshAllRegisters()
Acquires a script lock, reads Config, enforces hard safety switches, scans configured direct-child folders, rebuilds generated outputs, refreshes the navigation companion, and appends a success or failure receipt to Run Log.


installHourlyTrigger()
Deletes prior refresh triggers and installs one hourly refresh trigger.


removeRefreshTriggers()
Deletes only triggers whose handler is refreshAllRegisters.


readConfig_()
Reads enabled Config rows, applies default IDs, and permits explicitly named additional source folders such as SOURCE_FOLDER_ID_2.


assertSafety_()
Throws immediately if any hard safety switch is unsafe.


collectInventory_()
Inventories direct children of configured folders, reads supported text content, extracts structured headers, and computes raw and normalized hashes.


buildOpenQuestionRows_()
Parses OQ headings and status text from the designated OQ register.


buildHelpRows_()
Extracts HELP NEEDED, OFFERED CAPACITY, blocker, help-request, and offered-capacity sections from new artifacts.


buildRecentRows_()
Selects artifacts modified within the configured recent-activity window.


buildArtifactRows_()
Constructs topic-, object-, status-, dependency-, and supersession-aware index rows.


buildDuplicateRows_()
Flags exact normalized duplicates and same-title/different-fingerprint clusters. It does not declare semantic equivalence automatically.


buildContextRows_()
Produces a compact session-start snapshot from explicit source metadata and current queues.


updateNavigationDoc_()
Rebuilds the pilot navigation companion only; it does not edit research artifacts.


appendRunLog_()
Adds an immutable execution receipt containing start/end time, mode, files scanned, rows written, warnings, and result.
