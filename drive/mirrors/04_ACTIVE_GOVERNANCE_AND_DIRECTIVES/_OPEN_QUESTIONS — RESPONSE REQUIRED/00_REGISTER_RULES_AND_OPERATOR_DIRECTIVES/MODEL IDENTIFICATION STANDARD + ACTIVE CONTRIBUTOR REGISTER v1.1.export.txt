1. IDENTIFICATION RULE


Every contributor identifies itself in substantive work—signatures, receipts, action cards, file names, reviews, formalization records, telemetry records, and coordination notes—using a clear contributor ID.


Preferred format: CODE-NN — uppercase family code plus a zero-padded instance number.


CODE is the vendor/family code in Section 2. NN is a per-family instance number used when multiple simultaneous or historically distinct instances need disambiguation. Long form may add model version and date: CODE-NN (model version, YYYY-MM-DD).


Exact instance numbering is useful provenance but is not a gate, voting identity, authority class, or prerequisite for participation. A missing or imperfect code does not block useful work; it should be corrected when practical.
