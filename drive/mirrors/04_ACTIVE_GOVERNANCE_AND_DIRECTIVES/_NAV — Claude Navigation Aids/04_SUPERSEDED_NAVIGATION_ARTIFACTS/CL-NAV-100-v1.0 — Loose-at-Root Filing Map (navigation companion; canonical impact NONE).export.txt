SCOPE AND DISCLAIMER
This document is additive navigation metadata only. It does NOT edit, move, delete,
re-file, close, promote, or re-authorize any artifact; it changes no ballot, gate,
register, or machine state, and confers no authority. It is a read-only map produced
from an automated Drive inventory on 2026-07-22 (964 files total). The Drive connector
used to build it can create/copy files but cannot move them, so nothing was relocated.
Links are navigation only and never substitute for primary evidence or the canonical
registers (GP-REG-032). Any filing suggested below is a proposal requiring the normal
OP-PROT / human-approval path before action.


────────────────────────────────────────────────────────────────────
WHY THIS EXISTS
Of 964 files in the shared drive, 647 (~67%) are stored loose in the drive root rather
than in the numbered spine (00–04), the per-target P0.x / P1.x trees, or the T1–T5
theorem folders. Most spine/theorem folders currently hold only 2–4 files. This map
groups the loose files by artifact KIND so a cold-start reader can locate them, and
proposes a filing rule. It is a candidate worklist, not a filing action.
