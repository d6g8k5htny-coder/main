COUNTABLE BOREL GLOBALIZATION, SELECTOR-INDEPENDENCE, AND PALM-ADMISSIBILITY LEMMA


1. ABSTRACT SETTING
Let E be a separable metric space with its Borel sigma algebra, let O subset E be Borel, and let Y be a compact metric space. Fix m in Y.


Assume:
A1. O has a countable Borel cover U_1,U_2,... .
A2. For every j there is a continuous map b_j:U_j->Y.
A3. There is a jointly continuous global flow map
    Phi:E x R x Y -> Y,
where for each p in E the map (t,x)->Phi(p,t,x) is a complete flow.
A4. For every p in O, every local selector value b_j(p) that is defined lies on one declared connected selected flow branch C_p.
A5. C_p is a connected one-dimensional invariant manifold on which the generating vector field is nonzero.


The application will take E to be the exact C^3 six-pin field fiber or its ambient C^3 field space, Y to be the side-24 torus, m=M_r, O=O_r, and the b_j to be the local positive unstable-branch points supplied by LCR-DER-057.


2. COUNTABLE PIECEWISE-BOREL SELECTOR
Define
    B_1=U_1,
    B_j=U_j minus union_{i<j} U_i,  j>=2.
Then every B_j is Borel, the B_j are pairwise disjoint, and their union is O.


Define b:O->Y by
    b(p)=b_j(p)  when p in B_j.
For every open set V subset Y,
    b^{-1}(V)=union_j [B_j intersect b_j^{-1}(V)].
Each term is Borel because b_j is continuous on U_j and B_j subset U_j is Borel. The union is countable. Hence b is Borel measurable.


No compatibility of b_i and b_j on overlaps is required for measurability because the B_j form a disjoint priority partition.


3. ONE-DIMENSIONAL BRANCH IS ONE FLOW ORBIT
Fix p in O. The flow orbits partition C_p. Because the generating vector field is nonzero on C_p, the flow-box theorem gives, around every point of C_p, a one-dimensional coordinate in which the flow is translation. Therefore each orbit is open in C_p.


A connected space cannot be partitioned into two or more nonempty disjoint open sets. Hence C_p consists of one flow orbit.


Consequently, if x,x' lie in C_p, there is a finite real number tau such that
    x'=Phi(p,tau,x).
In particular any two local selector values on the declared selected branch differ by a finite flow-time shift.


4. SELECTOR-INDEPENDENCE OF FORWARD CONVERGENCE
Let b and b' be two Borel selectors satisfying A4. For each p in O, Section 3 gives a finite tau(p) with
    b'(p)=Phi(p,tau(p),b(p)).
The function tau need not be measurable.


For every t,
    Phi(p,t,b'(p))=Phi(p,t+tau(p),b(p)).
A finite translation of the time parameter does not change whether a trajectory converges to m as t->infinity. Therefore
    lim_{t->infinity} Phi(p,t,b(p))=m
if and only if
    lim_{t->infinity} Phi(p,t,b'(p))=m.
Thus the convergence event depends only on the selected branch, not on the auxiliary countable cover or local point.


5. BOREL MAP INTO PATH SPACE
Let
    C_+=C([0,infinity),Y)
with the compact-open topology. Since Y is compact metric, C_+ is a separable metrizable space. Its Borel sigma algebra is generated by the evaluation maps at nonnegative rational times.


Define Gamma:O->C_+ by
    Gamma(p)(t)=Phi(p,t,b(p)).
For every fixed rational q>=0, the map
    p -> Gamma(p)(q)=Phi(p,q,b(p))
is Borel, because b is Borel and (p,x)->Phi(p,q,x) is continuous.


Since the rational evaluation maps generate the Borel sigma algebra of C_+, Gamma is Borel measurable.


6. BOREL SET OF PATHS CONVERGING TO m
Define
    C_m={gamma in C_+: lim_{t->infinity} gamma(t)=m}.
Let Q_+ be the nonnegative rationals. Then
    C_m
      = intersection_{k>=1}
          union_{N>=1}
            intersection_{q in Q_+, q>=N}
              {gamma: d(gamma(q),m)<=1/k}.


For fixed q and k, the set in braces is closed because evaluation at q is continuous. The displayed expression is countable, so C_m is Borel.


To verify equality, first suppose gamma(t)->m. For every k there is N such that d(gamma(t),m)<=1/k for all t>=N, hence the rational-time condition holds.


Conversely, suppose the rational-time condition holds. Fix k and choose N as displayed. For any real t>=N, choose rationals q_n>=N with q_n->t. Continuity of gamma and closedness of the distance bound give d(gamma(t),m)<=1/k. Since this holds eventually for every k, gamma(t)->m.


7. BOREL ADJACENCY EVENT
Define
    A={p in O: Gamma(p) in C_m}.
Since Gamma and C_m are Borel, A is Borel in O. If O is Borel in E, then A is Borel in E after assigning failure on E minus O.


By Section 4, A is independent of the chosen priority cover and local selector family, provided all local values lie on the same declared selected branch.


8. CERTIFICATE COMPATIBILITY
Suppose E_cert subset O is a Borel event and the deterministic certificate proves that, for every p in E_cert, the same declared selected branch enters an invariant neighborhood of m and converges to m. Then
    E_cert subset A.
This is an inclusion of Borel events. Failure of the sufficient certificate is not identified with A^c; only the forward implication is used.


9. BOREL WEIGHT AND EXACT PALM ADMISSIBILITY
Let mu be a Borel probability measure on E. Let W:E->[0,infinity) be Borel and integrable, and set
    Z=integral W dmu.
Assume
    0<Z<infinity.
Define the weighted probability measure P by
    dP/dmu=W/Z.


For the Borel event A,
    P(A)=integral W 1_A dmu / Z
is well defined.


No indicator 1_A is inserted into W when defining P. The event A remains the event whose probability is evaluated. Therefore the weighted base law does not condition on adjacency.

11. THEOREM
Under A1–A5, a countable family of local continuous points on one declared connected one-dimensional flow branch globalizes to a Borel selected point. The forward-convergence event to m is Borel and independent of the local selector. Any Borel integrable weight with finite positive normalizer defines a weighted probability of that event by the exact Radon–Nikodym quotient.


Applied to the exact side-24 six-pin Gaussian field, LCR-DER-057 plus the strict typed/nonorthogonal domain and exact flow give the measurable selected branch and Borel adjacency event required by P01-MEAS-001 / P02-LM-013.
