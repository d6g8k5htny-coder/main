P02-LM-003 — EXACT CONDITIONAL DETERMINANT-WEIGHTED POLYNOMIAL BOUNDARY-LAYER INTEGRATION


1. SETTING


Fix an integer m>=1 and a number r_0 in (0,1]. For every r in (0,r_0], let gamma_r be a probability measure on R x R^m that is absolutely continuous with respect to Lebesgue measure dq dU, with a jointly measurable density phi_r(q,U).


Let W_r:R x R^m->[0,infinity) be measurable and define


    Z_r = integral_{R x R^m} W_r(q,U) phi_r(q,U) dq dU.


Assume 0<Z_r<infinity and define the determinant-weighted probability measure P_r by


    dP_r(q,U) = Z_r^{-1} W_r(q,U) dgamma_r(q,U).


Let B_r be a measurable event in R x R^m. Let


    C_r:R^m->[0,infinity),
    U_r:R^m->R


be measurable functions. For each U define the possibly empty, nonoriented interval


    I_r(U) = {s in R : -C_r(U)<s<U_r(U)}.


If U_r(U)<=-C_r(U), then I_r(U) is empty.


2. HYPOTHESES


Assume there exist constants


    K_phi>0, c_phi>0, c_Z>0,
    K_C>0, K_U>0, K_D>0,


and nonnegative integers d_C,d_U,d_D, all independent of r, such that the following hold for every r in (0,r_0].


H1 — UNIFORM DENSITY ENVELOPE.
For every (q,U) in R x R^m,


    phi_r(q,U) <= K_phi exp(-c_phi ||U||^2).


H2 — NORMALIZER LOWER BOUND.


    Z_r >= c_Z r^2.


H3 — TYPED BAD-EVENT BOUNDARY INCLUSION.
For gamma_r-almost every (q,U) satisfying W_r(q,U)>0,


    (q,U) in B_r


implies


    q/r in I_r(U).


Equivalently, on the part of B_r that can contribute determinant-weighted mass,


    -C_r(U)<q/r<U_r(U).


H4 — POLYNOMIAL ENDPOINT GROWTH.
For every U in R^m,


    0<=C_r(U)<=K_C(1+||U||^{d_C}),


    |U_r(U)|<=K_U(1+||U||^{d_U}).


H5 — PHYSICAL DETERMINANT-WEIGHT SCALING ON THE RELEVANT LAYER.
For every U in R^m and every s in I_r(U),


    W_r(rs,U)
      <= r^4 K_D (1+|s|+||U||)^{d_D}.


3. THEOREM


Under H1–H5, there exists a finite constant K_B, depending only on


    m, r_0, K_phi, c_phi, c_Z,
    K_C, K_U, K_D, d_C, d_U, d_D,


and not on r, such that


    P_r(B_r) <= K_B r^3


for every r in (0,r_0].


No independence assumption is imposed. The intervals I_r(U) may be empty. No numerical or optimal value of K_B is asserted.


4. PROOF


Define the unnormalized determinant-weighted bad mass


    N_r
      = integral W_r(q,U) 1_{B_r}(q,U)
          phi_r(q,U) dq dU.


Because W_r>=0, H3 gives the pointwise almost-everywhere domination


    W_r(q,U) 1_{B_r}(q,U)
      <= W_r(q,U) 1_{I_r(U)}(q/r).


This remains true when I_r(U) is empty: both the right-hand indicator and every possible contributing bad-event point vanish.


By Tonelli's theorem and the change of variables q=rs at fixed r and U, with dq=r ds,


    N_r
      <= r integral_{R^m}
           integral_{I_r(U)}
             W_r(rs,U) phi_r(rs,U) ds dU.


Apply H1 and H5:


    N_r
      <= K_phi K_D r^5
         integral_{R^m} exp(-c_phi||U||^2) J_r(U) dU,


where


    J_r(U)
      = integral_{I_r(U)}
          (1+|s|+||U||)^{d_D} ds.


The integral defining J_r is an ordinary Lebesgue integral over the set I_r(U), not an oriented integral from -C_r(U) to U_r(U). Therefore J_r(U)=0 whenever the interval is empty.


It remains to bound J_r uniformly by a polynomial in ||U||.


Set


    d = max{1,d_C,d_U},
    t = ||U||,
    K_A = 2 max{1,K_C,K_U}.


Since every nonnegative power t^j with j<=d satisfies


    t^j <= 1+t^d,


H4 implies


    C_r(U)<=K_A(1+t^d),
    |U_r(U)|<=K_A(1+t^d).


Let


    A(U)=K_A(1+t^d).


Then


    I_r(U) subset [-A(U),A(U)]


and its Lebesgue length satisfies


    |I_r(U)|<=2A(U).


For every s in I_r(U), using t<=1+t^d,


    1+|s|+t
      <= 1+A(U)+t
      <= (K_A+2)(1+t^d).


Consequently


    J_r(U)
      <= 2K_A (K_A+2)^{d_D}
          (1+t^d)^{d_D+1}.


Let n=d_D+1 and M=dn. Since n>=1,


    (1+t^d)^n
      <= 2^{n-1}(1+t^{dn})
      = 2^{d_D}(1+t^M).


Thus


    J_r(U)<=K_P(1+||U||^M),


where the finite constant


    K_P
      = 2K_A (K_A+2)^{d_D} 2^{d_D}


is independent of r.


The Gaussian polynomial moment


    G_{m,M,c_phi}
      = integral_{R^m}
          exp(-c_phi||U||^2)(1+||U||^M)dU


is finite. Therefore


    N_r <= K_N r^5,


with


    K_N
      = K_phi K_D K_P G_{m,M,c_phi}<infinity.


Finally, by H2,


    P_r(B_r)
      = N_r/Z_r
      <= (K_N r^5)/(c_Z r^2)
      = K_B r^3,


where


    K_B=K_N/c_Z<infinity.


This proves the theorem. QED.


5. POWER AND DIRECTION LEDGER


- Boundary-layer substitution: q=rs.
- Jacobian: dq=r ds.
- Physical determinant-weight upper bound: r^4.
- Unnormalized bad mass: O(r^5).
- Normalizer lower bound: Z_r>=c_Zr^2.
- Weighted probability: O(r^5)/Omega(r^2)=O(r^3).


The lower bound on Z_r is load-bearing because the theorem is an upper bound on N_r/Z_r. Replacing H2 with an upper bound on Z_r would not prove the conclusion.


6. EDGE CASES


EMPTY INTERVAL.
When U_r(U)<=-C_r(U), the set I_r(U) is empty and contributes zero. No oriented-integral sign convention is used.


ZERO OR VANISHING WEIGHT.
Points with W_r=0 contribute nothing, so H3 is required only on the positive-weight support, gamma_r-almost everywhere.


STRICT VERSUS NONSTRICT ENDPOINTS.
Replacing either strict endpoint inequality by a nonstrict one changes only boundary sets in the s-integration and does not affect the estimate. The theorem retains strict inequalities to match the intended typed application.


DEGREES EQUAL TO ZERO.
The proof permits d_C=d_U=d_D=0. The auxiliary exponent d is forced to be at least one only to simplify the uniform polynomial comparison.


NO INDEPENDENCE.
No factorization of B_r, W_r, q, or U is used.


NO GAUSSIAN q-TAIL REQUIRED.
The density envelope need not decay in q because H3 confines q to an r-scaled interval whose endpoints grow at most polynomially in U.
