1. RESOLVED PUBLICATION RULE


Machine-readable support carriers MUST be non-Google-native raw files. New native-Google-Doc or Base64-inside-Doc machine carriers are prohibited.


Required formats:
- application/json for JSON carriers;
- text/plain for checksums.sha256 and line-oriented normalization/checksum records;
- another raw MIME type only when explicitly defined by a numbered standard revision.


The four human-readable capsule elements may remain native Google Docs and use declared native-export hashing.

3. WRITE-THEN-READ TRANSACTION


A carrier is not published merely because an upload call returns success. Before final title, indexing, manifest inclusion, validation credit, or dependent-receipt generation, the publishing line must:


1. Generate the canonical bytes before upload.
2. Compute expected byte count and SHA-256.
3. Upload as a raw file with conversion disabled.
4. Confirm returned Drive ID and raw MIME type.
5. Freshly download that exact Drive ID.
6. Recompute observed byte count and SHA-256.
7. Require exact byte-count equality and exact hash equality.
8. Parse or validate the payload format.
9. Record the upload and fresh-download receipt.


Any failure is a WRITE-FAULT or ROUNDTRIP-FAULT. Preserve the object, visibly label it failed, route it to corrupted provenance, and give it zero evidence, validation, manifest, root-hash, or sealing credit.


4. DEPENDENCY ORDER


Publish and verify in this order:


A. independent leaf carriers;
B. canonical manifest generated only from verified leaf IDs, MIME types, bytes and hashes;
C. fresh round-trip verification of the manifest;
D. checksums, root receipt and validation summary generated only from the verified manifest and leaf set;
E. fresh round-trip verification of every dependent carrier;
F. package-level independent review;
G. SEALED only after an APPROVE verdict and every TRC-STANDARD sealing box passes.


No ROOT_SHA256 may be computed or accepted from intended local payloads, filenames, unverified uploads, malformed carriers or native-Doc shells.
